# 术语与默认值对照表

写文档前先查这张表，避免同一个东西在不同页面叫不同名字、同一个参数写出不同数值。

数据来源：固件 Web 界面截图（`Docs/docs/**/images/`）与各页面现有说明。固件改版后请同步更新本表。

## 一、术语（一律用"统一叫法"）

| 统一叫法 | 不要写成 | 依据 |
|---|---|---|
| 被控设备 | 目标主机、主机、远程端 | 快速开始的术语表 |
| 控制端 | 客户端、本地电脑 | 快速开始的术语表 |
| 未使能 | 已禁用、已关闭、关闭状态 | 键盘/鼠标菜单「状态」实际文案；网络卡片也是「网络未使能」 |
| 已连接 / 未连接 | 连线、断开 | 菜单「状态」栏实际文案 |
| 按键 A / 按键 B | A 键、B 键 | 物理按键页 |
| 配网模式 | 配网热点、配置模式 | 临时热点，SSID 固定 `flexkvm-conf` |
| AP 热点 | 热点、WiFi 热点 | 常驻热点，默认 SSID `FlexKVM-AP`；两者不是同一个热点 |
| 直连模式 | 直连、网线直连模式 | OLED 前缀 S |
| 远程画面 | 远程桌面、屏幕 | 菜单栏按钮是「画面」 |
| 画质四档：低 / 中 / 高 / 极高 | 超高、最佳、最高 | 远程画面菜单实际文案（截图 `guide/remote/images/screen/remote_menu.webp`） |
| 图片质量 | 截图质量、截图画质 | 截图设置实际文案，仅 JPG 生效 |
| 视频质量 | 录制画质、录像质量 | 录像设置实际文案 |
| 恢复出厂模式（卡片名）/ 恢复出厂设置（页面名） | 恢复出厂、重置设备 | 卡片描述「此操作将删除所有配置并恢复出厂设置」 |
| 存储管理（页面名）/ 镜像（菜单名） | 存储卡管理、TF 卡页 | 两者都在讲这个功能，首次出现时点明对应关系 |
| TF 卡 | MicroSD 卡、存储卡、SD 卡 | |
| 更新日志 | 变更日志、CHANGELOG | 导航名 |

## 二、默认值

| 参数 | 值 | 备注 |
|---|---|---|
| AP 热点 SSID / 密码 | `FlexKVM-AP` / `12345678` | 可在 AP 配置里改 |
| AP 信道 / 最大连接数 / 5G 频段 / WiFi6 | 6（可选 AUTO）/ 3 / 关闭 / 关闭 | |
| 配网热点 SSID / 密码 | `flexkvm-conf` / OLED 上的 8 位随机数字 | 保存后自动关闭 |
| 配网 / AP 热点管理地址 | `192.168.10.1`（OLED 前缀 A） | OLED 示例 `A192.168.10.1` |
| 直连模式地址 | 设备 `192.168.100.1`，客户端 `192.168.100.2~254`（前缀 S） | 电脑网口需 DHCP |
| 有线网络前缀 | `E`；获取中显示 `E Loading...` | 超过 20 秒未获取按排查表处理 |
| 管理员账号：用户名 / 密码 | 4~32 位（字母、数字、下划线、点、连字符）/ 8~32 位可打印 ASCII，无空格 | |
| 2FA 备用码 | 10 个，每个 8 位；每个只能用一次；二维码 10 分钟内需确认 | |
| 时间校准阈值 | 与当前时间偏差超过 60 秒时，连接后弹校准提示 | 小于 60 秒不提示，页面无手动设置时间入口 |
| NTP 时间源上限 | 5 个 | 可标记「首选」 |
| 远程画面画质预估带宽 | ~256 Kbps / ~2 Mbps / ~4 Mbps / ~8 Mbps | 实时预览，受画面内容影响 |
| 录像文件码率 | 1 / 2 / 4 / 8 Mbps | 与上一行不是同一处设置，别混用 |
| UART 默认参数 | 115200 8N1 | |
| 审计日志条数上限 / 时间基准 | 10000 条 / UTC | 每页 50 条 |
| 系统日志保留 | 最多 20 条 | |

## 三、按键行为（权威页：`Docs/docs/guide/interaction/button.md`）

| 按键 | 操作 | 结果 |
|---|---|---|
| 按键 A | 短按 | 循环切换 OLED 子页面 |
| 按键 A | 长按 1~3 秒后释放 | 进入配网模式 |
| 按键 A | 长按超 3 秒后释放 | 返回主界面（取消配网） |
| 按键 B | 短按 | 从子页面返回主界面 |
| 按键 B | 长按 1~3 秒后释放 | 切换直连模式 |
| 按键 B | 长按 3~5 秒后释放 | 切换 WiFi ↔ AP 热点 |
| 按键 B | 长按 5 秒后释放 | 返回主界面（取消操作） |
| 复位按键 | 短按 | 强制重启，不丢配置 |
| 恢复出厂按键 | 按住 1 秒起倒计时，15 秒归零后松开 | 恢复出厂；中途松开即取消 |

## 四、改页面时的自检

1. 同一个东西是否用了本表"统一叫法"？
2. 同一个参数在不同页面的数值、单位、前后缀是否一致？
3. 是否与权威页（物理按键、AP 热点、存储管理等）冲突？冲突时以权威页为准，同时改另一页。
4. 新增档位名或默认值时，先从 `Docs/docs/**/images/` 的界面截图确认实际文案，再写正文，并把新条目补进本表。
