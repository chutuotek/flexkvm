# 远程传文件

被控设备要装驱动、传脚本、拿日志——你不在设备旁边。FlexKVM 能把 TF 卡变成被控设备的"远程 U 盘"或"虚拟光驱"，文件双向传输。

---

## 开始之前

| 你需要 | 说明 |
|--------|------|
| FlexKVM 已联网，能正常看到远程画面 | → [快速入门](../../quick_start/index.md) |
| TF 卡（MicroSD） | 放要传输的文件 |
| 读卡器 | 把文件从电脑写入 TF 卡（也可以直接用浏览器上传） |

---

## 先看你要传什么

| 模式 | 被控设备看到什么 | 适合传 |
|------|-----------------|--------|
| **分区共享** | 一个 U 盘 | 任意文件：驱动包、脚本、固件、日志 |
| **文件共享** | 一个光驱 | 系统 ISO 镜像、驱动光盘镜像 |

> 两种模式互斥——同一时间只能开一种。

---

## 方式一：分区共享（传任意文件）

把整个 TF 卡分区导出为 USB 存储设备，被控设备能读到分区里的所有文件，也能往里写。

### 1. 准备文件

**方法 A：电脑预加载（文件多、体积大时用）**

TF 卡插电脑 → 格式化为 exFAT → 把文件拖进去 → 拔出。

**方法 B：浏览器上传（临时传几个小文件）**

TF 卡插 FlexKVM → 挂载分区 → 在文件列表点**上传** → 从本机选文件。

### 2. 共享给被控设备

FlexKVM 顶栏点**镜像**图标 → 选 TF 卡分区 → 点**共享**。

> **验证**：被控设备的资源管理器（Windows）或桌面（macOS）出现一个新的 USB 存储设备。

> 如果分区当前已挂载（你能看到文件列表），需要先点**卸载**再共享。

### 3. 在被控设备上操作

- **Windows**：自动分配盘符，资源管理器里能看到
- **Linux**：自动挂载到 `/media/` 或 `/mnt/`
- **macOS**：桌面出现外接磁盘图标

和用普通 U 盘一样——复制、粘贴、打开、写入。

### 4. 用完了

1. 先在**被控设备**上弹出 USB 设备（右键 → 弹出）
2. 再回 FlexKVM 镜像界面点**取消共享**

> 别跳过第 1 步。直接取消共享可能导致文件损坏。
>
> 整盘共享、分区挂载、只读保护、安全移除的完整操作 → [存储管理](../peripherals/disk.md)

## 方式二：文件共享（传 ISO 镜像）

把单个 `.iso` 或 `.img` 文件变成虚拟光驱，被控设备识别为 CD-ROM——用来装系统、传驱动光盘镜像。

### 1. 准备镜像文件

把 `.iso` / `.img` 放入 TF 卡（电脑预加载或浏览器上传都行）。

### 2. 挂载并共享

1. TF 卡插 FlexKVM → 顶栏点**镜像**图标
2. 选分区 → 点**挂载** → 文件列表出现
3. 勾选要共享的 `.iso` / `.img` 文件 → 点**共享文件**

> **验证**：被控设备出现一个光驱设备。Windows 会自动播放，BIOS 里可选择从它启动。
>
> 文件格式要求、挂载失败排查 → [存储管理](../peripherals/disk.md)

## 常见场景速查

| 你要做什么 | 用哪种 | 传什么 |
|-----------|:---:|--------|
| 装驱动 | 分区共享 | 驱动安装包 |
| 传诊断脚本 | 分区共享 | `.bat` / `.sh` / `.ps1` |
| 从被控设备拿日志 | 分区共享 | 被控设备写入 → FlexKVM 下载 |
| 远程重装系统 | 文件共享 | ISO 系统镜像 |
| 传驱动光盘 | 文件共享 | `.iso` 驱动光盘 |
