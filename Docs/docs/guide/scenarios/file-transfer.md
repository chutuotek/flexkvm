# 远程传文件

被控设备需要装驱动、传脚本、拿日志文件，但人不在设备旁边。通过 TF 卡和 USB 导出功能，FlexKVM 能把 TF 卡变成被控设备的"远程 U 盘"或"远程光驱"。

## 前置条件

| 你需要 | 说明 |
|--------|------|
| FlexKVM 已正常联网 | 参考 [快速入门](../../quick_start/index.md) |
| TF 卡（MicroSD） | 存放要传输的文件，最高支持 512GB |
| 读卡器 | 电脑上把文件写入 TF 卡（或直接用浏览器上传） |

---

## 两种共享模式

FlexKVM 支持两种 USB 导出模式，选哪个取决于你要传什么：

| 模式 | 导出内容 | 被控设备识别为 | 适用场景 |
|------|----------|---------------|----------|
| **分区共享（Mass Storage）** | 整个 TF 卡分区 | 一个 USB 外接 U 盘 | 传任意文件：驱动包、脚本、固件、日志 |
| **文件共享（CD-ROM）** | 单个 `.iso` 或 `.img` 文件 | 一个虚拟光驱 | 传系统安装镜像、驱动光盘镜像 |

> 两种模式互斥——同一时间只能开启一种。

---

## 方式一：分区共享（传任意文件）

将整个 TF 卡分区导出为 USB 大容量存储设备，被控设备能看到分区内的**所有文件**。

### 1. 准备文件

**方法 A：电脑预加载（适合大批量文件）**

将 TF 卡插入电脑读卡器，格式化为 exFAT（推荐）或 FAT32，把文件复制进去。

**方法 B：浏览器直接上传（适合临时传几个文件）**

将 TF 卡插入 FlexKVM，挂载分区后，在文件列表中点击 **上传** 按钮，从本机选择文件上传。

> 如果 TF 卡是新卡或格式不兼容，先在电脑上格式化为 exFAT。

### 2. 共享分区

在 FlexKVM 工具栏中点击 **硬盘挂载** 图标，进入镜像管理界面：

![镜像菜单](../toolbar/images/disk/web-image-menu.webp)

1. 在"选择分区"下拉框中选中 TF 卡分区
2. 点击 **共享** 按钮

被控设备会立即识别到一个新的 USB 存储设备，打开就能看到分区内的全部文件。

> 如果分区当前已挂载（能看到文件列表），需要先点击 **卸载**，再选择分区 → 共享。

### 3. 在被控设备上操作

打开被控设备的远程桌面：

- **Windows**：自动分配盘符，资源管理器中可见
- **Linux**：自动挂载到 `/media/` 或 `/mnt/`
- **macOS**：桌面上出现外接磁盘图标

像用普通 U 盘一样复制、粘贴、打开文件。被控设备也可以把文件**写入**这个 U 盘——比如保存日志文件后，在 FlexKVM 端下载回来。

### 4. 停止共享

1. 在**被控设备**上弹出 USB 设备（右键 → 弹出/安全移除）
2. 回到 FlexKVM 工具栏中的硬盘挂载界面
3. 点击 **取消共享**

> 不要跳过被控设备端的弹出步骤。直接取消共享可能导致文件损坏。

---

## 方式二：文件共享（传 ISO 镜像）

将单个 `.iso` 或 `.img` 文件导出为虚拟 CD-ROM 光驱，被控设备会把它识别为一个光驱设备。

### 1. 准备镜像文件

将 `.iso` 或 `.img` 镜像文件放入 TF 卡（可通过电脑预加载或浏览器上传）。

### 2. 挂载并选择文件

1. TF 卡插入 FlexKVM，点击工具栏 **硬盘挂载** 图标
2. 选择 TF 卡分区，点击 **挂载**
3. 在文件列表中勾选要导出的 `.iso` / `.img` 文件
4. 点击 **共享文件**

### 3. 使用虚拟光驱

被控设备会识别到一个新的光驱设备。在 Windows 中会自动播放，在 BIOS 中可选择从该光驱启动——这正是远程重装系统的核心步骤。

---

## 常见场景速查

| 你要做什么 | 用哪种方式 | 传什么 |
|-----------|-----------|--------|
| 给被控设备装驱动 | 分区共享 | 网卡驱动、显卡驱动安装包 |
| 传诊断脚本 | 分区共享 | `.bat` / `.sh` / `.ps1` 脚本 |
| 传固件升级包 | 分区共享 | `.tar` / `.img` 固件文件 |
| 从被控设备拿日志 | 分区共享 | 被控设备写入 → FlexKVM 下载 |
| 远程重装系统 | 文件共享 | ISO 系统镜像 |
| 传驱动光盘镜像 | 文件共享 | `.iso` 驱动光盘 |

详细操作说明见 [硬盘挂载](../toolbar/disk.md)。
