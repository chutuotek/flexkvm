# 外网远程访问

人在公司、设备在家？出差要管机房的服务器？FlexKVM 不靠公网 IP、不靠路由器配置——**热点直连**和 **Tailscale 组网**两种方案，几分钟就能从外面安全连上。

---

## 先看你要用哪种

| 你在哪 | 用哪个 | 一句话 |
|--------|--------|--------|
| 在设备旁边，但现场没网 | **热点直连** | FlexKVM 自建 WiFi 6 热点，手机连上就管 |
| 人在外面，设备在机房/家里 | **Tailscale 组网** | 免费 VPN，端到端加密，能上网就能连 |

> 推荐先试热点直连（零配置、即开即用），以后有需要再配 Tailscale。

---

## 方案一：WiFi 6 热点直连

现场没网、客户网络不让接、机柜还没拉线——FlexKVM 自己变成 WiFi 6 热点，你的手机或笔记本直接连上来就能操作。

### 操作步骤

1. 给 FlexKVM 上电（USB Type-C，5V/1A）
2. 长按设备上的**按键 B** 约 3~5 秒，OLED 显示热点图标后松开（按键 B 长按分三阶段，1~3 秒先闪过 ETH SERVER/CLIENT 预览，忽略它继续按住即可进入第二阶段）
3. 手机或电脑搜 WiFi，找到 `FlexKVM-AP`
4. 输入密码 `12345678` 连接
5. 浏览器打开 `https://192.168.4.1`（热点模式的固定管理地址）
6. 登录 → 远程画面出现

> **验证**：OLED 状态栏显示热点图标，IP 地址前缀为 `A`（如 `A192.168.4.1`）。

### 用完了

在 **设置 → 网络 → 热点模式** 里关掉热点，或者再长按按键 B 3~5 秒切回 WiFi。不关的话热点一直开着，耗电也占着信道。

> SSID、密码、频段、信道、最大客户端数等全部配置项 → [热点模式](../network/ap.md)

## 方案二：Tailscale 异地组网

Tailscale 把你的所有设备组成一个加密的虚拟局域网——不需要公网 IP、不用配路由器端口转发、免费版支持 100 台设备。

> 数据是点对点加密直传的，不经过 Tailscale 服务器。国内部分网络环境下首次连接可能稍慢，连上之后就稳定了。

### 步骤 1：注册 Tailscale

去 [tailscale.com](https://tailscale.com) 注册一个账号（支持 Google / GitHub / 微软账号）。

在你的操作端电脑或手机上也安装 Tailscale 客户端，登录同一个账号。

### 步骤 2：在 FlexKVM 上启用

进 Web 界面 → 设置 → **应用中心**，找到 Tailscale 区块：

1. 打开 Tailscale 开关 → 服务启动
2. 点 **登录状态** → 界面显示一条登录链接
3. 浏览器打开链接 → 授权设备加入你的 Tailscale 网络

> **验证**：界面显示 Tailscale IP（通常是 `100.x.x.x`）和**在线**状态。
>
> 登录/登出、连接信息、故障排查 → [Tailscale](../network/tailscale.md)

### 步骤 3：从外网访问

在你外面的电脑或手机上，确保 Tailscale 客户端在运行、已登录同一账号。

然后：

- **Web 界面**：浏览器打开 `https://<FlexKVM 的 Tailscale IP>`
- **SSH**：`ssh <用户名>@<FlexKVM 的 Tailscale IP>`

就像在同一个局域网一样。

### 验证一下

把手机 WiFi 关掉，用 4G/5G 流量 → 打开浏览器访问 FlexKVM 的 Tailscale IP → 能看到登录页就成功了。

## 常见问题

**热点直连连不上？**

→ 确认按键 B 长按了 3~5 秒（OLED 出现热点图标才算）。搜不到的话试试手动添加 WiFi，SSID 是 `FlexKVM-AP`。

**Tailscale 连不上？**

→ 确认 FlexKVM 能上网（有线或 WiFi 已连接）。确认两端都登录了**同一个** Tailscale 账号。在 FlexKVM 的 Tailscale 页面看状态是不是**在线**。

**有公网 IP，可以用端口转发吗？**

→ 可以，端口转发 + DDNS 也行。但 Tailscale 更简单也更安全——不用暴露端口到公网。
