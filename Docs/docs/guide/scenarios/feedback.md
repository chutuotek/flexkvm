# 问题反馈与建议

遇到问题了？有功能想法？跟着这个流程操作，你得到答案更快，开发者也能更快定位问题。

## 第二步：收集诊断信息

如果自查没解决，提交反馈前准备好以下信息，能帮开发者快速定位：

### 必备信息

| 信息 | 在哪看 |
|------|--------|
| **FlexKVM 固件版本** | Web 界面 → 设置 → 关于，或 OLED 显示 |
| **操作系统版本** | 你操作电脑的系统版本 |
| **浏览器版本** | Chrome/Edge/Firefox 的版本号 |
| **问题发生时间** | 大概什么时间发生的 |
| **复现频率** | 单次 / 偶尔 / 稳定复现 |
| **问题描述** | 什么场景下触发、具体现象是什么 |

### 系统日志

在 Web 界面 → 设置 → 维护，导出：
- 后端日志
- Web 日志

> 在问题发生后**立即导出**日志，不要重启设备后再导出——重启会清掉关键信息。

日志导出说明详见 [系统日志](../settings/maintenance/log.md)。

### 截图或录屏

截一张出问题时的画面，比文字描述更直观。如果问题涉及操作步骤，录一段屏幕视频更好。

## 第三步：提交反馈

### Bug 反馈

| 渠道 | 适合 | 地址 |
|------|------|------|
| GitHub Issue | 公开跟踪、有账号即可 | [github.com/chutuotek/flexkvm/issues](https://github.com/chutuotek/flexkvm/issues) |
| Gitee Issue | 国内用户、访问更快 | [gitee.com/chutuotek/flexkvm/issues](https://gitee.com/chutuotek/flexkvm/issues) |
| 邮箱 | 涉及隐私信息 | [feedback@chutuotek.com](mailto:feedback@chutuotek.com) |

提交 Issue 时选择对应的标签：**bug**（Bug 反馈）、**documentation**（文档问题）、**enhancement**（功能建议）。

### 怎么写好 Bug 反馈

好的反馈和不好的反馈，对开发者的定位效率天差地别。来看两个例子：

**❌ 不好的反馈：**

> 远程桌面画面卡住了，重启也不行，快修一下。

开发者看到这个：不知道版本、不知道怎么触发、不知道日志在哪——只能追问，一来一回好几天过去了。

**✅ 好的反馈（直接抄这个格式）：**

```
FlexKVM 版本：v0.1.2（设置 → 关于 → 系统版本）
操作系统版本：Windows 11 23H2
浏览器版本：Chrome 148.0.7778.178（地址栏输入 chrome://version 查看）
出现时间：2026-05-25 14:30
出现频率：每次远程装机时必现

复现步骤：
1. 挂载 Win11 ISO，通过 ATX 重启被控设备
2. 进入 BIOS 后选择从 USB 启动
3. 安装界面出现后约 10 秒，远程画面冻结
4. 刷新浏览器后恢复，但 10 秒后再次冻结

已尝试的排查：
- 重启 FlexKVM  → 无效
- 更换 Chrome / Edge / Firefox → 均复现
- 更换 HDMI 线 → 无效
- 降低画质到最低档 → 无效

附件：系统日志（admin_20260525.log）、冻结时截图
```

**为什么这个例子好？**

| 要素 | 作用 |
|------|------|
| 版本、系统、浏览器 | 开发者能判断是否和特定版本有关，是否已修复 |
| 精确复现步骤 1→2→3→4 | 开发者可以照着走一遍，稳定复现的问题几乎必修 |
| "每次必现" | 不会被当成偶发问题搁置 |
| 已尝试的排查 | 避免开发者回复"你试试重启/换浏览器"的无效往返 |
| 附件带了日志 | 日志里有精确的时间线和错误堆栈，比任何文字描述都准 |

> **小技巧**：写复现步骤时，想象你在教一个从没用过 FlexKVM 的人操作。每一步都写清楚——"挂载 ISO 然后重启"不叫清楚，"进入设置 → 升级 → 离线升级 → 上传 ISO → 回到桌面 → 点击 ATX 电源 → 重启 → 等待 OLED 显示 BIOS 画面"才叫清楚。

### 功能建议

有好想法？可以畅所欲言，不限于下面这些方向：

- 希望支持的功能（如 NFS 远程挂载、更多分辨率、SNMP 监控等）
- 现有功能的改进（如虚拟键盘拖拽、快捷键优化等）
- 你在其他类似产品上用过的体验

> 功能建议不需要完整方案，一句话描述也行。你的需求可能会在后续版本中实现。
