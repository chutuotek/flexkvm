# 远程开关机

人在外面，被控设备关机了——FlexKVM 用两种方式让你远程控制电源：**ATX 控制器**（物理接线，像亲手按机箱按钮）和 **WoL 网络唤醒**（纯软件，发个数据包就能唤醒）。

> **只想用 WoL 唤醒，不想拆机箱？** 直接跳到 [步骤 3](#步骤-3配置网络唤醒-wol)。前提：被控设备插了网线，且 BIOS 里 WoL 已开启。

---

## 开始之前

| 你需要 | 说明 |
|--------|------|
| FlexKVM 已联网，能正常访问 Web 界面 | → [快速入门](../../quick_start/index.md) |
| ATX 控制器 | 包装里有，用来物理控制电源 |
| ATX 杜邦线 | 包装里有，连接主板插针 |
| 十字螺丝刀 | 拆机箱用（如果主板插针位置不方便操作） |

## 步骤 1：安装 ATX 控制器

> 💡 本步骤为简化指引。完整引脚定义、两种接线方法图解、拓展安装 → [ATX 电源控制](../peripherals/atx.md)

### 1.1 找到主板电源插针

打开机箱，在主板上找到**前置面板插针区**——就是机箱电源键和重启键背后连的那排针脚。通常在主板的右下角，旁边印着 `JFP1`、`F_PANEL` 或 `PANEL`。

你需要用到两对插针：

| 插针 | 主板标识 | 作用 |
|------|----------|------|
| 电源开关 | `PWR_SW`、`PWRBTN` | 短接一下 = 按电源键 |
| 复位开关 | `RST_SW`、`RESET` | 短接一下 = 按重启键 |

> 找不到？翻主板说明书"前置面板接口"那章，或搜主板型号 + `front panel pinout`。

### 1.2 连接杜邦线

用杜邦线把 ATX 控制器的两个通道连到主板对应的插针上：

- 通道 1 → 电源开关插针
- 通道 2 → 复位开关插针

杜邦线不分正负极，插牢就行。

### 1.3 连到 FlexKVM

把 ATX 控制器的 Type-C 排线插进 FlexKVM 的 **ATX 接口**。

> **验证**：OLED 状态栏出现 ATX 图标。ATX 控制器上的电源指示灯亮起。

## 步骤 2：在 Web 界面控制电源

在 FlexKVM 顶栏点**外设**图标，展开 ATX 面板：

| 你要做什么 | 操作 |
|-----------|------|
| 开机 | 点电源键 → **短按** |
| 正常关机 | 点电源键 → **短按**（由操作系统响应） |
| 强制关机 | 点电源键 → **长按**约 4 秒 |
| 重启 | 点复位键 |

> ⚠️ 强制关机和复位可能导致数据丢失。系统还有响应时，优先用短按正常关机。

面板顶部的两个指示灯同步显示被控设备状态：🟢 电源灯（运行中）/ 🟡 硬盘灯闪烁（读写中）。

> 长按关机时长、指示灯含义、拓展安装 → [ATX 电源控制](../peripherals/atx.md)

## 步骤 3：配置网络唤醒 (WoL)

ATX 管物理开关，WoL 管网络唤醒——两个配合能覆盖所有场景：

- 设备关机了 → WoL 唤醒
- 设备开机了 → ATX 关机或重启
- 系统卡死了 → ATX 强制关机，再 WoL 唤醒

### 3.1 在 BIOS 中开启 WoL

通过 FlexKVM 远程画面进被控设备的 BIOS（开机时按 Del / F2），找到这些选项并开启：

| BIOS 选项 | 设为 |
|-----------|:---:|
| Wake on LAN / WOL | Enabled |
| PCIe Wake / Power On By PCI-E | Enabled |
| ErP / EuP Ready | **Disabled**（这个必须关，否则 WoL 不工作） |

> 大多数主板路径：**Advanced → Power Management**。保存退出后正常关机，网口灯应该保持亮或闪烁——说明 WoL 生效了。

### 3.2 添加 WoL 设备

在 FlexKVM 顶栏点**网络唤醒**图标：

1. 点 **+** 添加设备
2. 填设备名称（如 `OfficePC`，只支持英文和数字）和 MAC 地址（如 `AA:BB:CC:DD:EE:FF`）
3. 确认保存

> MAC 地址在哪看？Windows：`ipconfig /all` 里的"物理地址"。Linux：`ip addr`。

### 3.3 唤醒

在 WoL 设备列表里点闪电图标 → FlexKVM 发送 Magic Packet → 设备唤醒。

> WoL 只对有**有线网口**的设备有效。WiFi 连接的设备不支持。
>
> 添加/删除设备、多设备管理 → [网络唤醒 (WoL)](../network/wol.md)

## 常见问题

| 问题 | 最可能的原因 | 先试这个 |
|------|-------------|---------|
| 点开机没反应 | 杜邦线没接牢或插错位置 | 检查主板插针，确认外设面板里显示 `atx` |
| WoL 唤不醒 | BIOS 里 ErP 没关 | 进 BIOS 确认 ErP 是 Disabled |
| 关机后马上又开机了 | BIOS 里开了"断电后自动开机" | 进 BIOS → 电源管理 → 关掉 Restore on AC Power Loss |
| ATX 控制器不识别 | Type-C 排线松了 | 重新插拔，确认 OLED 上 ATX 图标出现 |
