# 日常运维

设备已经跑起来了。这篇覆盖日常你会反复做的几件事——每月花 5 分钟就够了。

---

## 升级固件

固件更新带来新功能和安全修复，建议每月检查一次。

| 方式 | 什么时候用 | 需要什么 |
|------|-----------|---------|
| 在线升级 | 设备能上网 | 网络畅通 |
| 离线升级 | 设备没网 | TF 卡 + 电脑下载固件包 |

### 在线升级

进 Web 界面 → 设置 → 升级：

1. 选**下载源**（国内选 Gitee，海外选 GitHub）
2. 点**检查更新**
3. 有新版本 → 点**下载安装包** → 等待下载和校验
4. 点**立即升级** → 输入密码确认

> **验证**：升级过程中 OLED 显示升级图标，🔴 警告灯快速闪烁。完成后设备自动重启，OLED 重新显示 IP。
>
> ⚠️ **升级前务必用独立电源适配器供电。** 升级中断电可能导致设备变砖，修复很麻烦。
>
> 测试版固件、下载源切换、更新日志查看 → [在线升级](../maintenance/upgrade-online.md)

### 离线升级

设备没联网：在电脑上从 [FlexKVM 发布页](https://github.com/chutuotek/flexkvm/releases) 下载固件包（`.tar`）→ 放入 TF 卡 → 插进 FlexKVM → 升级界面选离线升级 → 上传 → 开始。

> SHA-256 校验、固件包格式要求 → [离线升级](../maintenance/upgrade-offline.md)

## 审计日志

Web 界面 → 设置 → 维护 → 审计。记录所有关键操作：谁登录了、执行了什么命令、改了什么配置。

> 多用户环境或生产系统，每月导出一次留档。详细说明见 [审计日志](../security/audit.md)。

---

## 重启设备

设备反应慢、画面卡？先试试重启——能解决大部分临时问题。

- **Web 界面**：设置 → 维护 → 重启 → 确认。约 20~30 秒后 OLED 重新显示 IP 即可连接。
- **硬件**：短按设备上的**复位按键**，立即重启，不丢配置。

> 重启不会清除任何数据、配置、账户。放心用。
>
> 硬件按键位置和操作细节 → [重启设备](../maintenance/reboot.md)

---

## 恢复出厂设置

忘了密码、转让设备、配置混乱想重新来过——恢复到出厂状态。

**怎么操作**：用卡针按住 FlexKVM 上的**恢复出厂按键**（RST 孔），OLED 显示倒计时，约 15 秒归零后松开。

> ⚠️ **会清除所有数据**：账户、密码、WiFi 配置、2FA 密钥、自定义设置。固件版本不会降级。
>
> 也可以通过 Web 界面或 SSH 操作，SSH 支持保留/清除日志两种级别 → [恢复出厂设置](../maintenance/factory-reset.md)

## 月度检查清单

设备稳定运行后，每月花 5 分钟：

| 操作 | 目的 |
|------|------|
| 检查一次固件更新 | 安全修复和新功能 |
| 导出审计日志 | 留档备查 |
| 确认远程访问正常 | 避免关键时刻连不上 |

> 出问题时，**先导出系统日志再重启**——日志能帮开发者定位根因。导出方法见 [问题反馈与建议](feedback.md)。日常运维不用管系统日志，只看审计日志就行。
