# 日常运维

设备已经跑起来了，这篇覆盖日常你会反复做的事：升级固件、审计记录、重启恢复。

---

## 升级固件

FlexKVM 固件分两种升级方式：


| 方式     | 适用场景                | 前提                   |
| ---------- | ------------------------- | ------------------------ |
| 在线升级 | 设备能上网              | 网络畅通               |
| 离线升级 | 设备没联网 / 网络不稳定 | TF 卡 + 电脑下载固件包 |

### 在线升级

进 Web 界面 → 设置 → 升级，在在线升级区域：

1. 选择**下载源**（国内用户选 Gitee，海外选 GitHub）
2. 点击**检查更新**
3. 有新版本则点击**下载安装包**，等待下载和校验
4. 点击**立即升级**，输入密码确认

升级过程中：

- OLED 显示升级图标
- 🔴 警告灯快速闪烁
- 升级完成后设备自动重启

> **升级前务必用独立电源适配器供电！** 升级中断电可能导致设备变砖，需要 TTL 串口才能恢复。

### 离线升级

如果设备没联网，在电脑上下载固件包放入 TF 卡，插入设备后在升级界面选择离线升级。

详细操作见 [离线升级](../settings/upgrade/ota_offline.md) 和 [在线升级](../settings/upgrade/ota_online.md)。

## 审计日志

Web 界面 → 设置 → 维护 → 审计，可以查看和导出审计记录。

审计日志记录所有关键操作：谁在什么时候登录、执行了什么命令、配置了什么变更。

> 如果设备涉及多人使用或处于生产环境，建议定期导出审计日志留档。详细说明见 [审计](../settings/maintenance/audit.md)。

---

## 重启设备

Web 界面 → 设置 → 维护 → 重启。重启大约需要 20~30 秒，期间无法访问 Web 界面，等待 OLED 重新显示 IP 后即可重新连接。

重启可以解决大部分临时性问题（比如画面卡住、响应变慢），先试重启再看是否需要进一步排查。

---

## 恢复出厂设置

当你需要彻底重置设备时——比如忘了管理员密码、转让设备、或者系统配置混乱想重新开始：

**操作方法**：用卡针或细物按压 FlexKVM 上的**恢复出厂按键**（RST 孔），按住约 5 秒直到 OLED 有反应后松开。

恢复出厂后会清除：

- 所有账户和密码
- 网络配置（WiFi 密码等）
- 自定义设置

> 固件版本不会降级，恢复出厂只清除配置数据。

详细说明见 [重启与重置](../settings/maintenance/power_reset.md)。

## 日常运维清单

对已经稳定运行的设备，建议定期：


| 频率       | 操作                 | 目的                 |
| ------------ | ---------------------- | ---------------------- |
| 每月       | 检查一次固件更新     | 获取新功能和安全修复 |
| 每月       | 导出审计日志         | 留档备查             |
| 每次变更后 | 确认远程访问正常     | 避免关键时候连不上   |
| 出问题时   | 先导出系统日志再重启 | 日志能帮助定位根因   |

> 系统日志主要用于反馈 Bug 时帮助开发者定位问题。日常运维只需关注审计日志。导出系统日志的方法见 [问题反馈与建议](feedback.md)。
