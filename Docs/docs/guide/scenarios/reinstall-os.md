# 远程重装系统

被控设备崩溃了、要重装系统、或者想换一个操作系统——不需要搬显示器键盘到机器旁边。这个流程覆盖从准备镜像到系统安装完成的全过程。

## 前置条件

| 你需要 | 说明 |
|--------|------|
| FlexKVM 已正常联网 | 参考 [快速入门](../../quick_start/index.md) |
| TF 卡（MicroSD） | 存放系统 ISO 镜像，建议 ≥ 16GB |
| 读卡器 | 电脑上把 ISO 写入 TF 卡用 |
| ATX 控制器已连接 | 远程控制开关机和重启，接线见 [外设](../peripherals/atx.md) |
| 系统 ISO 镜像 | 你要安装的操作系统镜像文件 |

---

## 步骤 1：准备 ISO 镜像

### 1.1 格式化 TF 卡

将 TF 卡插入电脑读卡器，格式化为 **exFAT**（推荐，无 4GB 单文件限制）或 **FAT32**。

| 文件系统 | 适用场景 | 单文件限制 |
|----------|----------|------------|
| exFAT | 大 ISO（≥4GB），推荐 | 无限制 |
| FAT32 | 小 ISO | 单文件最大 4GB |

### 1.2 放入 ISO 文件

将系统 ISO 镜像文件复制到 TF 卡中。

### 1.3 插入 TF 卡

将 TF 卡插入 FlexKVM 的 TF 卡槽。在 Web 界面菜单栏点击镜像图标，确认 TF 卡已被识别（能看到分区信息）。

> TF 卡没识别？检查文件系统格式是否为 FAT32/exFAT/ext4。NTFS 仅支持读取，建议用 exFAT。

---

## 步骤 2：挂载 ISO 为虚拟光驱

### 2.1 挂载分区

在镜像菜单中选择 TF 卡分区，点击**挂载**。挂载后能看到分区内的文件列表。

### 2.2 共享 ISO 文件

在文件列表中勾选你放入的系统 ISO 文件，点击**共享文件**。这会把 ISO 导出为虚拟 CD-ROM 光驱，被控设备会把它识别为一个 USB 光驱设备。

> 如果共享列表已有不需要的项目，先取消再重新共享。

详细操作参考 [镜像](../storage/disk.md)。

> **验证**：被控设备在 BIOS/UEFI 的启动项中能看到 USB CD-ROM 设备。

---

## 步骤 3：重启进入 BIOS

### 3.1 重启被控设备

在 Web 界面菜单栏点击电源图标，点击复位键**短按**重启被控设备。

<!-- 截图待补充 ![电源按键](../../../images/atx/web-atx-power.webp) -->

### 3.2 进入 BIOS

重启时密切关注远程画面——屏幕一亮就要赶紧按 BIOS 热键：

| 常见品牌 | BIOS 热键 |
|----------|-----------|
| Dell | F2 |
| HP | F10 或 Esc |
| Lenovo | F1 或 F2 |
| ASUS / Gigabyte / MSI 等 DIY 主板 | Delete |
| 服务器（Supermicro 等） | Delete 或 F2 |

> **热键按了没反应？** 检查两点：
> 1. 键盘设置中的**被控系统**是否选对（Windows/Linux/MacOS）
> 2. 如果处于全屏模式，ESC 键被浏览器拦截了，需要先退出全屏再操作，或者使用映射的 ESC（默认 Right Ctrl），参见 [Esc 映射](../input/keyboard.md#esc映射)

> **画面黑屏错过了？** 再点一次复位键短按重启，在重启画面亮起前就开始连续按 BIOS 热键。

---

## 步骤 4：设置从虚拟光驱启动

进入 BIOS 后：

1. 找到 **Boot**（启动）选项卡
2. 将 USB CD-ROM 或 USB Device 设为第一启动项
3. 保存并退出（通常是 F10 保存退出）

不同主板的 BIOS 界面差异很大，核心目标就一个：**让系统从 FlexKVM 虚拟的 USB 光驱启动，而不是从硬盘启动**。

---

## 步骤 5：安装系统

保存 BIOS 设置后，被控设备会从虚拟光驱启动，进入系统安装界面。此时你可以：

- 在浏览器中直接操作安装过程（鼠标 + 键盘，全程远程）
- 遇到文字输入（如用户名、密码），可以用键盘菜单中的**粘贴文本**输入 ASCII 字符

安装过程中系统可能会自动重启几次，每次重启后注意：
- 如果又进了安装界面 → 说明 BIOS 启动顺序没变，这是正常的，继续安装流程即可
- 安装完成后需要**回到 BIOS 把启动项改回硬盘**，否则每次重启都进安装界面

### 装完系统后

系统安装完成后：

1. 检查被控设备能否正常通过 FlexKVM 远程控制（键鼠是否正常）
2. 在镜像菜单中**取消共享**ISO 文件
3. 进入 BIOS 把第一启动项改回硬盘

---

## 常见问题

**Q: BIOS 里看不到虚拟光驱？**

确认 ISO 文件已正确共享（Web 界面镜像菜单中能看到已共享的文件），确认 TF 卡文件系统兼容。

**Q: 安装到一半网络断了怎么办？**

安装过程在 FlexKVM 和被控设备之间进行，不需要 FlexKVM 联网。只要 FlexKVM 不断电、和被控设备的 USB + HDMI 连接不中断，安装可以正常继续。安装完成后网络恢复即可重新访问 Web 界面。

**Q: 被控设备没有 ATX 控制器能重装系统吗？**

可以。没有 ATX 就手动按被控设备的电源键来开关机和重启，其余流程完全一样。缺点是你人在设备旁边。
