# 远程重装系统

系统崩了、想换操作系统、或者新装一台机器——不需要搬显示器键盘过去。这个流程从头走到尾，每步告诉你做完该看到什么，踩过的坑也标出来了。

> 全程大约 30~60 分钟，取决于 ISO 大小和安装速度。

---

## 开始之前

| 你需要 | 说明 |
|--------|------|
| FlexKVM 已联网，能正常看到远程画面 | 还没搞定？→ [快速入门](../../quick_start/index.md) |
| TF 卡（MicroSD），建议 ≥ 16GB | 用来放系统 ISO 镜像 |
| 读卡器 | 把 ISO 从电脑写入 TF 卡 |
| ATX 控制器已接线 | 远程重启被控设备进 BIOS 用。没接也行——手动按被控设备电源键，其余步骤一样 |
| 系统 ISO 镜像 | 你要装的那个操作系统的镜像文件 |

---

## 步骤 1：把 ISO 镜像放入 TF 卡

> 💡 本步骤为简化指引。TF 卡管理、分区挂载、文件上传的完整操作 → [存储管理](../storage/disk.md)

### 1.1 格式化 TF 卡

把 TF 卡插入电脑读卡器，格式化为 **exFAT**。

| 文件系统 | 什么时候用 |
|----------|-----------|
| exFAT | **推荐**。ISO 超过 4GB 必选 |
| FAT32 | ISO 小于 4GB 时可用 |

### 1.2 复制 ISO 文件

把下载好的系统 ISO 镜像文件拖进 TF 卡。

### 1.3 插入 FlexKVM

把 TF 卡插入 FlexKVM 侧面的卡槽（金属触点朝向电源灯，推进去听到咔嗒声）。

> **验证**：在 Web 界面顶栏点镜像图标，弹出菜单里应该能看到 TF 卡的分区信息。没看到？→ 确认 TF 卡格式是 exFAT 或 FAT32，NTFS 只能读不能写。

---

## 步骤 2：把 ISO 挂载为虚拟光驱

> 💡 本步骤为简化指引。整盘共享、分区共享、安全移除 TF 卡的完整流程 → [存储管理](../storage/disk.md)

### 2.1 挂载分区

在镜像菜单里选中 TF 卡分区 → 点 **挂载**。

> **验证**：右侧出现文件列表，顶部显示分区总容量和已用容量。能看到你刚放进去的 ISO 文件。

### 2.2 共享为光驱

勾选那个 ISO 文件 → 点 **共享文件**。

> **验证**：被控设备会把它识别成一个 USB 光驱。进 BIOS 的启动项菜单里应该能看到一个 USB CD-ROM 设备。

> 共享列表里如果有之前残留的项目，先取消再重新共享。

---

## 步骤 3：重启并进入 BIOS

### 3.1 重启被控设备

在 FlexKVM 顶栏点电源图标 → 点复位键**短按**，被控设备开始重启。

### 3.2 按热键进 BIOS

**远程画面有 1~2 秒延迟——别等画面出现再按。** 点完复位键后立刻开始连续按 BIOS 热键，直到看到 BIOS 界面：

| 品牌 | 热键 |
|------|:----:|
| Dell | F2 |
| HP | F10 或 Esc |
| Lenovo | F1 或 F2 |
| ASUS / 技嘉 / 微星等 DIY 主板 | Delete |
| 服务器（Supermicro 等） | Delete 或 F2 |

> **按了没反应？** 查两件事：
> 1. 键盘设置里**被控系统**选对了吗（Windows / Linux / macOS）
> 2. 全屏模式下 Esc 被浏览器拦截了——退出全屏再按，或者用映射的 Esc 键（默认 Right Ctrl）
>
> **黑屏错过了？** 再点一次复位键短按，这次在画面亮之前就开始连续按。

---

## 步骤 4：设为从光驱启动

进了 BIOS 之后：

1. 找到 **Boot**（启动）选项卡
2. 把 USB CD-ROM 或 USB Device 拖到第一启动项
3. 保存退出（通常按 F10）

不同主板的 BIOS 界面差异很大，但目标就一个：**让系统从虚拟光驱启动，不是从硬盘。**

---

## 步骤 5：安装系统

保存 BIOS 后设备从虚拟光驱启动，进入系统安装界面。接下来：

- 直接在浏览器里操作——鼠标和键盘全程可用
- 需要输入用户名、密码时，用键盘菜单里的**粘贴文本**（只支持英文和数字）

安装过程中系统会自动重启几次：
- 重启后又进了安装界面 → 正常，BIOS 启动顺序没变，继续安装
- 装完之后 → **回到 BIOS 把启动项改回硬盘**（是的，要再进一次 BIOS），否则每次重启都回安装界面。改回来后，在镜像菜单里**取消共享**那个 ISO 文件。

---

## 常见问题

**BIOS 里看不到虚拟光驱？**

→ ISO 文件没共享成功。去镜像菜单确认文件是 `已共享` 状态，确认 TF 卡格式兼容。

**安装到一半网络断了怎么办？**

→ 安装过程在 FlexKVM 和被控设备之间进行，**不需要 FlexKVM 联网**。只要 FlexKVM 不断电、USB 和 HDMI 线不松，安装继续。网络恢复后再连上 Web 界面就行。

> ⚠️ 安装过程**不要开关鼠标、键盘或音频**。这些操作会让 USB 短暂断开，虚拟光驱跟着断，安装会失败。
