# TF 卡与存储

FlexKVM 通过 TF 卡（MicroSD）提供本地存储扩展，支持文件管理、虚拟光驱和 USB 导出功能。

## TF 卡规格

| 项目 | 要求 |
|------|------|
| 卡类型 | MicroSD（TF）卡 |
| 文件系统 | FAT32 / exFAT / ext4 |

> 如果 TF 卡插上没反应，可能是文件系统不支持。NTFS 只能读取不能写入。建议格式化为 FAT32 或 exFAT。

## 物理接口

TF 卡槽位于设备侧面。装入时请确保金属触点朝向正确（通常朝向设备内部），推入听到咔嗒声即可。

> 接口电气规格请参考 [接口说明](../product/interface.md#tf-卡槽)。

## 确认识别

插入 TF 卡后可通过以下方式确认是否被识别：

| 方式 | 说明 |
|------|------|
| OLED 显示屏 | 设备启动时或插入后，OLED 会显示存储状态 |
| Web 界面 | 菜单栏中的**镜像图标**显示为硬盘图标（非红叉），点击后可查看分区信息 |

## 文件管理

TF 卡的文件浏览、上传、下载等 Web 界面操作需要先将分区**挂载**，详细操作见 [ISO 镜像挂载](../storage/disk.md)。

## 安全移除

需要取出 TF 卡时，先在 Web 界面的镜像菜单中**卸载**已挂载的分区，再从卡槽中拔出。
