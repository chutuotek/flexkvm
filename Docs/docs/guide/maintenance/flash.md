# 线刷镜像

!!! warning "本页文档编写中，暂不能按此页操作"

    线刷所需的工具与操作步骤尚未发布。设备目前无法启动时，请直接[提交反馈](../../community/feedback/index.md)并附上设备序列号，由技术支持协助恢复，不要自行尝试刷写。

当设备无法正常启动时，可通过线刷方式重新烧录固件。

## 适用场景

- 固件升级过程中断电导致设备变砖
- 系统文件损坏无法正常启动
- 需要刷写特定版本固件

## 设备无法启动怎么办

本页步骤完成前，按以下顺序处理：

1. 先尝试[重启设备](reboot.md)与[恢复出厂设置](factory-reset.md)
2. 仍无法启动时，记录**设备序列号**（在[关于设备](../system/about.md)页或机身标签上）
3. [提交反馈](../../community/feedback/index.md)并附序列号，说明无法启动前的操作（如升级中断电）
