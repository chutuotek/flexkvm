# Flash Firmware

!!! warning "This page is still being written — don't follow it yet"

    The required tools and steps aren't published yet. If your device won't boot, [submit feedback](../../community/feedback/index.en.md) with the device serial number and let support help you recover — don't attempt to flash it yourself.

When the device cannot boot normally, you can re-flash the firmware via USB.

## When to Use

- Power loss during firmware upgrade resulting in a bricked device
- Corrupted system files preventing normal boot
- Need to flash a specific firmware version

## If the Device Won't Boot

Until this page is complete, work through the following:

1. First try [Reboot](reboot.md) and [Factory Reset](factory-reset.md)
2. If it still won't boot, note the **device serial number** (on the [About Device](../system/about.md) page or the label on the unit)
3. [Submit feedback](../../community/feedback/index.en.md) with the serial number and describe what you did before it failed to boot (e.g. power loss during an upgrade)
