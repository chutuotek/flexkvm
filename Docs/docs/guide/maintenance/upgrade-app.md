# 应用管理

FlexKVM 上的 **Tailscale**、**ZeroTier**、**frp 内网穿透**都是以「应用」的形式装在设备上的，各自可以独立下载、更新与卸载——[在线升级](upgrade-online.md)管系统固件，应用管理管这几个应用，两者互不影响。

> 入口：设置 → 应用 → 点开某个应用卡片最下方的**应用管理**行

![应用管理](./images/app_mgmt.webp)

每张卡片上的「应用管理」是**各自独立**的一行：点哪张卡片，管的就是哪个应用。卡片上还会用状态文字同步这个应用当前的情况，比如「应用管理(已是最新)」「应用管理(未安装)」。

> **WireGuard 不在其列**：它由内核提供、随固件固化，没有可下载的应用包，卡片上也没有「应用管理」入口——跟着系统固件一起升级即可。

## 下载源

选择应用安装包的下载地址：

- **Gitee** — 默认源，国内用户速度快
- **GitHub** — 海外用户

> 只有这两个下载源。切到某个源上找不到应用包时，换另一个源再试。
>
> 切换下载源后，已下载的安装包会被清除，需要重新检查更新。

## 检查更新

点**检查更新**，系统从当前下载源拉取该应用的最新版本信息，行下方显示上次检查时间。**没检查过时点下载/安装是没用的**——包的版本、大小、校验值都要靠这一步拿到。

> **验证**：
>
> - 有更新 → 行上显示"可更新"，并出现**更新说明**入口（点开看更新内容）
> - 没有 → 显示"已是最新"
> - 未检查过或上次检查失败 → 提示"点击"检查更新"查看应用状态"

## 应用状态

| 状态 | 含义 |
|------|------|
| 未安装 | 设备上未安装该应用，可以直接下载安装 |
| 可更新 | 远程有新版本，可查看**更新说明**后再下载 |
| 已是最新 | 已安装版本为最新 |
| 与当前固件不兼容 | 新版本要求更高的固件，行上显示"需要固件 X 及以上版本"，下载按钮置灰 |
| 版本无法比较 | 本地或远端版本号格式无法比较，按钮变为**覆盖安装**，副标题提示"本地或远端版本号格式无法比较,可覆盖安装当前版本" |
| 未检查更新 | 尚未检查过，或上次检查失败 |

## 下载 & 安装

1. 点**下载**，显示下载进度、速度和剩余时间（形如「速度: 158.81KB/s | 剩余: 1秒」），可随时取消

   ![下载中](./images/app_mgmt_downloading.webp)

2. 下载完成后自动校验安装包完整性（显示"校验安装包中..."），校验通过后按钮变为**立即安装**，副标题"安装包已就绪,点击安装"

   ![安装包已就绪](./images/app_mgmt_ready.webp)

3. 点**立即安装**，应用自动完成安装并重启服务

> **验证**：安装完成后卡片上的状态变为"已是最新"，开关行副标题显示新版本号。

- 应用更新**不需要重启设备**，安装失败自动回滚到旧版本
- 同一时刻只允许一个更新任务：正在下载或安装时再点会提示"有其它更新任务正在进行,请稍后再试"
- 安装不可中途取消（下载可以）——进入安装后会一路跑到换入成功或回滚完成

## 卸载

应用已安装时，弹窗最下方会多出一行**卸载应用**（副标题"删除该应用的文件并停止其服务"）：

![卸载应用](./images/app_mgmt_uninstall.webp)

点它会先弹二次确认：

> 卸载后应用文件会被删除、服务会停止，需要时可以重新安装。确定卸载？

确认后显示"卸载中,请稍候..."，完成后提示"应用已卸载"。**不可取消**，进入后会跑到删完或失败为止。

- 卸载会把该应用的开关置回**关闭**，并停掉它的服务
- **配置不会跟着被删**：应用的登录状态、网络与隧道配置都存在应用目录之外；重新安装后启用即可继续用
- 卸载后卡片回到"应用未安装"的形态，想再用就按上面的下载 & 安装流程装回来

## 更新失败了？

| 现象 | 可能原因 | 先试这个 |
|------|----------|---------|
| 检查更新失败 | 网络不通或下载源不可用 | 切换下载源，或稍后重试 |
| 下载失败 | 网络不稳 | 切换下载源后重新下载 |
| 安装包校验失败 | 下载包损坏 | 重新下载 |
| 存储空间不足 | TF 卡/存储写满 | 清理存储后重试 |
| 与当前固件不兼容 | 固件版本过低 | 先[在线升级](upgrade-online.md) |
| 提示"有其它更新任务正在进行" | 已有一个检查/下载/安装任务在跑 | 等当前任务结束，或先取消下载 |
| 找不到**卸载应用**这一行 | 该应用当前未安装 | 未安装就无需卸载；确认卡片上没有"应用未安装"提示 |
