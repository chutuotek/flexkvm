# 应用更新

FlexKVM 上安装的应用（如 Tailscale）需要单独更新——[固件升级](upgrade-online.md)管系统，应用更新管应用，两者互不影响。

进 Web 界面 → 设置 → **应用中心** → 应用更新。

## 下载源

选择应用安装包的下载地址：

- **GitCode** — 默认源，国内用户速度快
- Gitee — 国内用户，速度快
- GitHub — 海外用户

> 切换下载源后，已下载的安装包会被清除，需要重新检查更新。

## 检查更新

点**检查更新**，系统从当前下载源拉取每个应用的最新版本信息，页面显示上次检查时间。

> **验证**：
>
> - 有更新 → 应用卡片显示"发现新版本 vX.X.X"和更新内容
> - 没有 → 显示"已是最新"
> - 未检查过或检查失败 → 显示"未检查更新"

## 应用状态

| 状态 | 含义 |
|------|------|
| 未安装 | 设备上未安装该应用 |
| 发现新版本 | 远程有新版本，显示最新版本号和更新内容 |
| 已是最新 | 已安装版本为最新 |
| 需要OTA升级系统 | 新版本要求更高的固件版本，需先[升级固件](upgrade-online.md) |
| 未检查更新 | 尚未检查过，或上次检查失败 |

## 下载 & 安装

1. 应用卡片点**下载**，显示下载进度、速度和剩余时间，可随时取消
2. 下载完成后自动校验安装包完整性（显示"校验安装包中..."），校验通过后按钮变为**立即安装**
3. 点**立即安装**，应用自动完成安装并重启服务

> **验证**：安装完成后应用卡片显示新版本号，状态变为"已是最新"。

应用更新**不需要重启设备**，安装失败会自动回滚到旧版本。

## 更新失败了？

| 现象 | 可能原因 | 先试这个 |
|------|----------|---------|
| 检查更新失败 | 网络不通或下载源不可用 | 切换下载源，或稍后重试 |
| 下载失败 | 网络不稳 | 切换下载源后重新下载 |
| 校验失败 | 下载包损坏 | 重新下载 |
| 应用不兼容 | 固件版本过低 | 先[升级固件](upgrade-online.md) |
