# 重启设备

设备反应慢、画面卡？先试重启——能解决大部分临时问题。

## 软件重启

进设置 → 维护 → 点"重启设备"卡片 → 确认。

![重启界面](images/setting_reset.webp)

![重启设备](./images/setting_reboot_comfirm.webp)

> 约 20~30 秒后 OLED 重新显示 IP，即可重新连接。不丢任何配置。

## 硬件复位

系统卡死、网络配置错到连不上？短按设备上的**复位按键**，立即重启，不丢配置。
