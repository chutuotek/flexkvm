# 恢复出厂设置

将 FlexKVM 恢复至出厂状态，**清除所有数据**。

> 恢复出厂设置会删除设备上的所有数据，包括用户名、密码、2FA 密钥、设备配置等，请谨慎操作。
>
> 硬件重置和软件重置会保留审计日志，SSH 重置可以通过命令在重置的时候移除审计日志。

## 硬件重置

如果无法进入 Web 界面，可以使用设备上的**恢复出厂按键**。

| 操作 | 功能 | 适用场景 |
|:----:|:----|---------|
| 长按恢复出厂按键 15 秒 | 恢复出厂设置 | 设备转让、配置混乱无法修复、忘记密码 |

> 长按 15 秒后清除所有配置（网络、账户、证书等），操作前请确保已备份必要信息。无法远程操作，需物理接触设备。
>
> OLED 屏幕正常情况下会有倒计时提示，倒计时到0s的时候可以松手就会进行重置

详见[物理按键](../interaction/button.md)。

## 软件重置

进入"设置" → "维护"：

![恢复出厂界面](images/setting_reset.webp)

在"重启与重置"组中点击"恢复出厂设置"卡片，弹出确认验证框：

![恢复出厂设置](./images/setting_reset_comfirm.webp)

输入密码（如已开启 2FA，需输入验证码），点击"确定"，设备恢复出厂设置。

## SSH 重置

通过 SSH 远程登录设备后，可执行恢复出厂命令。SSH 提供两种重置级别：

| 命令 | 说明 | 效果 |
|------|------|------|
| `reset` | 标准恢复出厂 | 清除所有配置，**保留系统日志** |
| `reset all` | 深度恢复出厂 | **清除所有数据**（含日志），完全恢复至出厂状态 |

操作步骤：

1. SSH 登录设备：`ssh <用户名>@<设备IP>`
2. 根据需要输入 `reset` 或 `reset all`
3. 确认操作后需要输入密码或者2FA验证身份
4. 设备自动执行重置并重启

> `reset`会保留审计记录，`reset all` 会删除审计记录，一般情况下使用 `reset` 即可。

详见 [SSH 远程访问](../security/ssh.md#系统管理)。

### 重置过程

恢复出厂设置过程中，OLED 显示恢复出厂图标，🟢 状态灯和 🔴 警告灯同时快速闪烁。
