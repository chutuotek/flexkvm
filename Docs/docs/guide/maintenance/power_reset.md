# 重启与重置

点击"设置"按钮，进入设置界面，点击“维护”按钮，进入维护界面，如图所示：

![维护界面](./images/maintenance_ui.webp)

可以看到重启与重置在第三个组中，有两个卡片：

- 重启设备
- 恢复出厂设置

## 重启设备

点击"重启设备"卡片，会弹出确认框，如图所示：

![重启设备](./images/reboot.webp)

点击"重启设备"卡片，会弹出确认对话框，如图所示：

## 恢复出厂设置

点击"恢复出厂设置"卡片，会弹出确认验证框

![恢复出厂设置](./images/refactor.webp)

输入密码(如果开启了2FA,需要输入2FA码)后，点击"确定"按钮，设备会恢复出厂模式。

> 注意：恢复出厂模式会删除设备上的所有数据，包括但不限于用户名、密码、2FA密钥、设备信息等，请谨慎操作。

### 设备端

恢复出厂模式的时候，设备的屏幕会显示一个恢复出厂的图标，红灯和绿灯会进行快速的闪烁。
