# 系统日志

> 提示: 系统日志是系统运行过程中产生的日志，主要用于设备厂商排查系统问题。用户不需要关注系统日志，除非系统出现异常。

点击"设置"按钮，进入设置界面，点击“维护”按钮，进入维护界面，如图所示：

![维护界面](./images/maintenance_ui.webp)

可以看到系统日志在第二个组中，有两个卡片：

- 日志管理
- WEB日志

## 日志管理

点击“日志管理”卡片，会弹出一个日志框，如图所示：

![日志管理界面](./images/maintenance_log.webp)

可以看到日志框里面会有日志数量，以及每个日志的开始时间，结束时间，状态及下载按键。

- 日志数量最多为20个日志记录，每个日志是每次系统软件启动时产生的日志，当你重启，断电，软件崩溃等都会产生新的日志。

状态分为三种：

- 录制中(蓝色)：表示正在录制日志。
- 正常(绿色)：表示已经录制完成，并且没有异常。
- 异常(红色)：表示已经录制完成，系统出现了奔溃状态。

当点击了“下载”按钮后，会弹出一个文件管理的窗口，你需要选择一个目录，将日志文件下载到该目录中，如图所示：

![下载界面](./images/maintenance_log_filesave.webp)

然后就会看到下载的按钮下面出现进度条，进度条会显示当前的进度，如图所示：

![文件下载进度条](./images/maintenance_log_progress.webp)

当进度条到达100%且校验通过后，表示文件下载完成，你可以在刚刚选择的目录中找到该文件，文件命名方式为"log-YYYY-MM-DDTHH-MM-SS.tar.gz" 

- YYYY: 年
- MM: 月
- DD: 日
- HH: 时
- MM: 分
- SS: 秒

例如：log-2026-05-19T09-22-08.tar.gz

## WEB日志

这个时用来下载当前浏览器的日志的，用于设备厂商进行调试的。

点击“WEB日志”卡片，会自动下载日志文件到下载目录中，名字叫“flexkvm-web-xxxxxxxxx.log” ,其中xxxxx为时间戳
