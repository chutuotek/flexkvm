# 键盘

![键盘按键](./images/keyboard/web-keyboard-button.webp)

- 上图菜单栏中的红色框框为键盘按键，左边的图标为一个简化的键盘图标，当前图标表示为键盘正常运行。

## 键盘按键

键盘按键的图标会根据当前键盘状态而改变，会有已连接和未连接两种状态。

![键盘按键区别](./images/keyboard/web-keyboard-button-diff.webp)

如上图所示，左边的图标表示键盘已连接，右边的图标表示键盘未连接。

## 键盘菜单

在菜单栏中，点击键盘按键会弹出键盘菜单，如下图所示：

![键盘菜单](./images/keyboard/web-keyboard-menu.webp)

可以看到，屏幕菜单中包含了以下选项：

- 状态
- 粘贴文本
- 快捷键
- Esc 映射
- 被控系统
- 虚拟键盘
- 关闭&开启

### 状态

显示当前键盘状态：

| 状态 | 说明 |
|------|------|
| 已连接 | 键盘已成功连接，可以正常使用 |
| 未连接 | 键盘未连接到被控主机 |
| 未使能 | 键盘已被手动关闭，需点击"开启"重新启用 |

### 被控系统

用来配置键盘和快捷键的模式，不同的系统对应的悬浮键盘，快捷键这些会有所不同。

默认为 **Windows**，建议用户根据自己的被控主机系统进行选择，可以选择以下系统：

- **Windows**
- **Linux**
- **MacOS**

### 粘贴文本

默认是收起的状态，点击之后会展开，如下图所示：

![粘贴文本](./images/keyboard/web-keyboard-paste-text.webp)

会有一个输入框，你可以在输入框中添加你想要粘贴的文本，然后点击粘贴按钮，即可将文本粘贴到被控机器上。

> 注意：只能输入ASSCII字符，不能输入中文。

### 快捷键

默认是收起的状态，点击之后会展开，如下图所示：

![快捷键](./images/keyboard/web-keyboard-shortcut.webp)

快捷键会根据"被控系统"的不同而发生改变，请选择你当前被控主机的系统。

可以看到快捷键功能区有两部分组成：

- 上面部分的按键是开启或者关闭快捷键悬浮窗
- 下面的部分的按键时快捷键，点击快捷键会发送快捷键到被控主机。

快捷键悬浮窗是这样的：

![快捷键悬浮窗](./images/keyboard/web-keyboard-shortcut-window.webp)

- 标题栏显示当前快捷键对应的系统
- 按住标题栏可以拖动快捷键悬浮窗
- 点击关闭按钮可以关闭快捷键悬浮窗

### 虚拟键盘

点击之后，显示画面中会弹出一个虚拟键盘，如下图所示：

![虚拟键盘](./images/keyboard/web-keyboard-virtual-keyboard.webp)

虚拟键盘有两种模式：

- 单键
- 组合键

#### 单键

按下任意一个按键，即可发送对应的按键。比如说：

- 按下A键，那么就会发送A键。
- 按下Ctrl键，那么就会发送Ctrl键。
- 按下Ctrl+A键，那么就会发送Ctrl+A键。

#### 组合键

以下的按键为修饰键：

- **Ctrl**
- **Alt**
- **Shift**
- **Win**

- 修饰键在虚拟键盘中可以进行组合使用，
- 当你点击这修饰键时，并不会发送修饰键，而是标记了修饰键，你可以看到修饰键会在虚拟键盘中的颜色变深色，再次点击修饰键，颜色会变浅色，表示取消标记。

当你点击非修饰键时，会发送非修饰键和之前标记的修饰键，例如：

- 先点击**ctrl**键(颜色变深色)，然后点击**A**，那么会发送**Ctrl+A**组合键。
- 先点击**ctrl**键(颜色变深色)，然后点击**shift**键(颜色变深色)，然后点击**A**，那么会发送**Ctrl+Shift+A**组合键。

### Esc映射

因为浏览器的一些限制，在相对模式和全屏模式下，esc按键变成了全屏退出和相对模式退出，所以需要对esc按键进行映射。

默认会根据当前浏览器的主机系统来进行自动映射：

- Windows系统和Linux系统会映射为 **Right Ctrl**
- MacOS系统会映射为 **Right Opthion**

除此之外用户也可以手动选择映射：

- **Right Ctrl**
- **Right Opthion**
- **Pause**
- **禁用**

### 关闭&开启

- 当键盘的状态为**已连接**或者**未连接**时，点击这个选项会关闭键盘，键盘的状态会变成**未使能**，
- 当键盘的状态为**未使能**时，点击这个选项会开启键盘，键盘的状态会变成**已连接**或者**未连接**。
