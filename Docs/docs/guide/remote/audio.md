# 音频

FlexKVM 通过 USB 虚拟声卡（UAC）在被控主机和你的浏览器之间双向传声音——主机的系统声音传回你的电脑，你的麦克风传给主机。开启后被控主机会出现一个叫 **FlexKVM Audio** 的音频设备。

> 开关音频时 USB 短暂断开重连，鼠标、键盘和磁盘挂载会短暂失效后恢复。这是正常现象。

## 音频状态

顶栏音频图标反映状态：

| 图标 | 含义 |
|------|------|
| ![](../icon/audio/audio-lines.svg) | 麦克风和扬声器都开了 |
| ![](../icon/audio/mic.svg) | 只开了麦克风 |
| ![](../icon/audio/volume2.svg) | 只开了扬声器 |
| ![](../icon/audio/audio-lines-off.svg) | 已关闭或未连接 |

## 音频菜单

点音频图标弹出菜单。

### 状态

| 状态 | 说明 |
|------|------|
| 已连接 | 正常 |
| 未连接 | 刷新页面或重新连接远程画面可恢复 |
| 已禁用 | 音频功能关了 |

### 音频开关

总开关。打开后被控主机出现 FlexKVM Audio 设备，关掉后声卡移除、麦克风和扬声器都停。

### 麦克风

打开后，你电脑的麦克风声音传给被控主机。

> 首次使用浏览器会弹权限请求，点"允许"。

### 扬声器

打开后，你能听到被控主机的声音。

## 被控主机设置

音频开关打开后，进被控主机的系统声音设置：

| 用途 | 选择设备 |
|------|----------|
| 播放声音（听到主机声音） | **FlexKVM Audio** 设为默认播放设备 |
| 录制声音（对主机说话） | **FlexKVM Audio** 设为默认录音设备 |

- **Windows**：右键系统托盘扬声器 → 声音设置 → 选输出/输入
- **macOS**：系统设置 → 声音 → 输出/输入
- **Linux**：系统设置 → 声音 → 输出/输入

---

## 常见问题

**麦克风没声音？** → ① 浏览器有麦克风权限吗？② 总开关和麦克风开关都开了？③ 主机录音设备选了 FlexKVM Audio？

**扬声器没声音？** → ① 总开关和扬声器开关都开了？② 主机播放设备选了 FlexKVM Audio？③ 主机有音频输出吗？

**有杂音或延迟？** → 网络传输的正常现象。改善网络环境试试。
