# 鼠标

![鼠标按键](./images/mouse/web-mouse-button.webp)

- 上图菜单栏中的红色框框为鼠标按键，左边的图标为一个简化的鼠标图标，当前图标表示为鼠标正常运行。

## 鼠标按键

鼠标按键的图标会根据当前鼠标状态而改变，会有已连接和未连接两种状态。

![鼠标按键区别](./images/mouse/web-mouse-button-diff.webp)

如上图所示，左边的图标表示鼠标已连接，右边的图标表示鼠标未连接。

## 鼠标菜单

在菜单栏中，点击鼠标按键会弹出鼠标菜单，如下图所示：

![鼠标菜单](./images/mouse/web-mouse-menu.webp)

可以看到，屏幕菜单中包含了以下选项：

- 状态
- 防休止
- 模式
- 滚动速率
- 滚动反转
- 关闭&开启

### 状态

显示当前鼠标状态：

| 状态 | 说明 |
|------|------|
| 已连接 | 鼠标已成功连接，可以正常使用 |
| 未连接 | 鼠标未连接到被控主机 |
| 未使能 | 鼠标已被手动关闭，需点击"开启"重新启用 |

### 防休止

这个功能可以用来防止被控机器进入休眠状态，启用之后，鼠标会每隔2分钟会微微操作一下鼠标，避免被控机器进入休眠状态。

> 提示： 这个功能开启之后，不管有没有开启或者关闭网页，都会每隔2分钟操作一下鼠标，所以如果不需要这个功能，建议关闭这个功能。

### 模式

鼠标模式会有两种模式：

- 相对模式
- 绝对模式

> 提示: 这两种模式各有优缺点，具体使用哪种模式，可以根据自己的需求来选择。

#### 绝对模式

绝对模式是将这个画面做一个映射，鼠标在画面中的移动会映射到被控机器的鼠标移动，鼠标移动到画面的哪里，被控机器的鼠标就会移动到那里。

优点：

- 移动精准，指哪打哪
- 不会受鼠标dpi的影响。
- 相比相对模式，控制更简单，不需要点击画面，鼠标就可以直接控制。

缺点:

- 仅适合单屏幕使用，如果受控主机有多个屏幕，受控主机的鼠标不会和画面中的鼠标同步。
- 在远程主机上面玩游戏又可能会不兼容这个模式，因为游戏会检测鼠标的移动，如果鼠标移动和画面中的鼠标不一致，游戏会认为鼠标被外接，会断开游戏，所以不建议在远程主机上玩游戏。

**鼠标隐藏**

启用之后，当鼠标移动到网页的非菜单栏区域时，鼠标会自动隐藏，这样可以避免远程画面中出现两个鼠标指针。

#### 相对模式

相对模式的话，控制会稍微有点麻烦：

- 设置之后，需要用户点击远程画面，这时候会真正进入相对模式的控制，这时候移动的话就可以在远程主机上移动鼠标了。
- 退出相对模式的话，只需要按键盘的`Esc`键即可。如果再次点击远程画面，就可以再次进入相对模式。

优点：

- 可以在多屏幕中使用，受控主机的鼠标会同步到画面中的鼠标。
- 在远程主机上玩fps游戏，像正常的鼠标一样。

缺点：

- 操作起来稍微麻烦一点，需要点击画面，然后移动鼠标，退出的话需要按`Esc`键。
- 鼠标移动的精准度受鼠标dpi的影响，如果dpi太低，鼠标移动的速度会变慢，dpi太高，鼠标移动的速度会变快。

**灵敏度**

在相对模式中，可以调节鼠标的灵敏度，比如：

- 0.2表示鼠标移动速度为原来的五分之一
- 1.0表示鼠标移动速度为原来的速度
- 2.0表示鼠标移动速度为原来的两倍

调节范围为0.2~3.0，步进为0.2。

> 注意：在相对模式下会占用esc键，导致原来的esc键失效。因此，在键盘菜单栏中可以设置esc键的映射，将esc键映射到其他键上。请参照[Esc 映射](./keyboard.md#esc映射)中的说明。默认为 ``RightCtrl``。

### 滚动速率

表示鼠标滚动的速度为原来的数值倍，比如：

- 0.5表示鼠标滚动速度为原来的一半
- 1.0表示鼠标滚动速度为原来的速度
- 2.0表示鼠标滚动速度为原来的两倍

调节范围为0.5~3.0，步进为0.5。

### 滚动反转

启用之后，鼠标滚动方向会反转，比如向上滚动会变成向下滚动，向下滚动会变成向上滚动。

### 关闭&开启

- 当鼠标的状态为**已连接**或者**未连接**时，点击这个选项会关闭鼠标，鼠标的状态会变成**未使能**，
- 当鼠标的状态为**未使能**时，点击这个选项会开启鼠标，鼠标的状态会变成**已连接**或者**未连接**。
