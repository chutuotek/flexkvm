# ATX 电源控制

通过 FlexKVM 远程控制被控主机的电源——开机、关机、强制关机和重启，就像亲手按下机箱上的按钮一样。

> **前提条件**：需要安装 ATX 硬件模块并正确接线。如果还没安装，请先阅读 [ATX 硬件接线](../hardware/atx-wiring.md)。

## 打开 ATX 控制

1. 在菜单栏点击**外设图标**（插头图标）
2. 打开**开关**启用外设功能
3. 如果 ATX 模块连接正常，外设图标会变成电源图标，设备名称显示为 `atx`

![外设菜单](./images/atx/web-interface-menu.webp)

## 状态灯

启用 ATX 后，菜单顶部会显示两个灯：


| 指示灯          | 颜色                     | 含义                   |
| ----------------- | -------------------------- | ------------------------ |
| 电源灯（Power） | 🟢 绿色      | 被控主机正在运行       |
| 硬盘灯（HDD）   | 🟡 黄色闪烁 | 被控主机硬盘有读写活动 |

## 电源按键

控制被控主机的电源开关，分为短按和长按：


| 操作 | 效果                | 默认时长 |
| ------ | --------------------- | :--------: |
| 短按 | 正常开机 / 正常关机 |  200ms  |
| 长按 | 强制断电关机        |   2 秒   |

![电源按键](./images/atx/web-atx-power.webp)

点击卡片右侧的箭头展开，可以调整按键时长：


| 参数 |    范围    | 步进 | 单位 |
| ------ | :----------: | :----: | :----: |
| 短按 | 100 ~ 1000 | 100 | 毫秒 |
| 长按 |   1 ~ 10   |  1  |  秒  |

## 复位按键

控制被控主机的复位（重启），同样分为短按和长按：


| 操作 | 效果     | 默认时长 |
| ------ | ---------- | :--------: |
| 短按 | 正常重启 |  200ms  |
| 长按 | 强制复位 |   2 秒   |

![复位按键](./images/atx/web-atx-reset.webp)

展开后可调整时长，参数范围与电源按键相同。

> 如果短按无效，可以尝试逐步增加时长。不同主板的响应时间有差异。

## 常用操作


| 目的     | 操作                                                 |
| ---------- | ------------------------------------------------------ |
| 开机     | 点击电源键 →**短按**                                |
| 正常关机 | 点击电源键 →**短按**（由系统响应关机信号）          |
| 强制关机 | 点击电源键 →**长按**（约 2 秒，模拟按住电源键不放） |
| 重启     | 点击复位键 →**短按**                                |

> :warning: 强制关机和强制复位可能导致未保存的数据丢失。只要系统还有响应，请优先用短按正常关机。
