# ATX 电源控制

ATX 电源控制功能允许通过 FlexKVM 远程控制被控主机的电源开关和复位操作，需要连接 ATX 电源控制模块。

## 硬件安装

ATX 电源控制需要配合 ATX 硬件模块使用。安装前请准备以下物品：

| 物品 | 说明 |
|------|------|
| ATX 控制器 | 包装内附带，带有排线 |
| ATX 杜邦线 | 包装内附带，用于连接主板插针 |
| 十字螺丝刀 | 用于打开机箱（如需要） |

### 接线步骤

#### 1. 确认主板插针位置

在主板上找到以下插针（通常位于主板右下角，靠近 CPU 插槽或 24pin 电源接口附近）：

| 插针名称 | 标识 | 说明 |
|----------|------|------|
| 电源开关 | PWR_SW、PWRBTN、PWRBTN# | 控制电源开关 |
| 复位开关 | RST_SW、RESET、RST# | 控制系统复位 |

> 提示：主板插针位置和标识因主板型号而异，请参考主板说明书中的"前置面板接口"或"JFP1"章节。

#### 2. 连接 ATX 控制器

将 ATX 控制器的排线连接到 FlexKVM 的 **ATX 控制接口 [6]**（USB Type-C 接口）。

#### 3. 连接主板插针

使用杜邦线将 ATX 控制器连接到主板插针：

| ATX 控制器 | 主板插针 | 说明 |
|------------|----------|------|
| PWR SW | PWR_SW | 电源开关信号 |
| RST SW | RST_SW | 复位开关信号 |
| GND | GND | 接地（可选，部分主板需要） |

接线时注意：

- **正负极**：通常无正负极区分，但部分主板可能需要按特定方向连接
- **原有开关**：可以与机箱原有的电源/复位开关并联，不影响机箱按键的正常使用
- **断电操作**：建议在主板断电状态下进行接线

> 警告：接线错误可能导致无法开机或误触发复位，请仔细核对插针标识后再连接。

#### 4. 验证连接

接线完成后，FlexKVM 通电并启动，在 Web 界面的外设菜单中应能看到 ATX 设备。如果显示设备名称为 `atx`，说明连接成功。

> 注意：ATX 模块属于 FlexKVM 外设（Interface）的一部分。进入菜单栏，点击外设图标，打开外设菜单：

## 启用外设

ATX 模块属于 FlexKVM 外设（Interface）的一部分。进入菜单栏，点击外设图标，打开外设菜单：

![外设菜单](./images/atx/web-interface-menu.webp)

点击"开关"启用外设功能。当 ATX 模块正确连接后，外设图标会变为电源图标，设备名称显示为 `atx`。

## 电源按键

电源按键用于控制被控主机的电源开关，支持短按和长按两种操作：

| 操作 | 说明 | 默认值 |
|------|------|:---:|
| 短按 | 模拟短按电源键，通常用于开机 / 正常关机 | 200ms |
| 长按 | 模拟长按电源键，通常用于强制关机 | 2000ms |

![电源按键](./images/atx/web-atx-power.webp)

点击卡片的展开箭头可以调整按键时长：

| 参数 | 调节范围 | 步进 | 单位 |
|------|:---:|:---:|:---:|
| 短按 | 50 ~ 1000 | 100 | ms |
| 长按 | 1000 ~ 10000 | 1000 | ms |

## 复位按键

复位按键用于控制被控主机的复位（Reset）操作：

| 操作 | 说明 | 默认值 |
|------|------|:---:|
| 短按 | 模拟短按复位键，通常用于正常重启 | 200ms |
| 长按 | 模拟长按复位键，通常用于强制复位 | 2000ms |

![复位按键](./images/atx/web-atx-reset.webp)

> 提示：不同主板的按键行为可能有差异。如果短按无法正常触发操作，可以尝试适当增加按键时长。

## 使用建议

- **开机**：点击电源键"短按"，模拟按下机箱电源键
- **正常关机**：点击电源键"短按"，由操作系统响应关机信号
- **强制关机**：点击电源键"长按"（默认 2 秒），模拟长按电源键强制断电
- **重启**：点击复位键"短按"，触发主板复位信号

> 警告：强制关机和强制复位可能导致数据丢失，请优先尝试正常关机。
