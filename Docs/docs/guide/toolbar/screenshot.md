# 截图

将当前远程画面保存为图片文件，适合保存关键画面留档。

![截图按键](./images/screenshot/web-screenshot.webp)

## 使用方法

点击菜单栏中的截图按键，当前远程画面会立即保存到浏览器的下载目录中。

- 截图成功：页面顶部弹出"截图成功"提示
- 截图失败（如没有视频画面）：页面顶部弹出错误提示

## 文件命名

文件名格式：`flexkvm-screenshot-YYYY-MM-DDTHH-MM-SS.{扩展名}`

例如：`flexkvm-screenshot-2026-05-12T21-44-20.png`

## 截图设置

在 **设置 → 系统 → 截图** 中调整格式和画质（[查看设置说明](../settings/system/screenshot.md)）：

| 设置 | 选项 | 说明 |
|------|------|------|
| 格式 | PNG / JPG | PNG 画质最好，文件较大；JPG 文件较小 |
| 画质 | 低 / 中 / 高 / 最佳 | 仅对 JPG 生效 |

## 常见问题

**点击截图没反应？**
→ 检查浏览器是否拦截了下载。查看浏览器下载列表或下载设置。

**截图画面和当前画面不一致？**
→ 这是正常现象——截图捕获的是点击瞬间的画面。如需连续记录，请使用 [录像](./record.md) 功能。
