# 显示

![显示按键](./images/screen/web-screen-button.webp)

菜单栏中的屏幕按键，图标为显示器样式，表示显示已连接。连接成功后，菜单栏下方显示远程画面。

## 屏幕按键

屏幕按键图标根据显示状态变化，分为连接成功和连接失败两种状态：

![显示按键区别](./images/screen/web-screen-button-diff.webp)

左侧为连接成功，右侧为连接失败。

> HDMI 未接入或远程主机进入休眠状态时，显示连接失败。

## 远程画面

远程画面位于菜单栏下方，尺寸随窗口大小自适应：

![网页较高画面](./images/screen/web-screen-long.webp)

![网页较宽画面](./images/screen/web-screen-fat.webp)

- HDMI 未接入时，画面显示"远程画面未连接"：

![HDMI没有接入画面提示](./images/screen/web-screen-hdmi-out.webp)

- 远程主机休眠或 HDMI 信号丢失时，画面显示"主机休眠中或者主机信号丢失"：

![信号丢失画面提示](./images/screen/web-screen-suspend.webp)

## 屏幕菜单

点击菜单栏中的屏幕按键，弹出屏幕菜单：

![屏幕菜单](./images/screen/web-screen-menu.webp)

菜单包含以下选项：

- 当前状态
- 分辨率
- EDID
- 码率控制模式
- 画质
- 重新连接

### 当前状态

显示连接状态，有三种：

- 已连接
- 信号丢失
- 未连接

> 主机休眠时显示"信号丢失"。

### 分辨率

显示当前连接的分辨率：

- **1920x1080@60Hz**：分辨率为 1920x1080，刷新率 60Hz
- **-1x-1@-1fps**：分辨率未知，一般为 HDMI 未接入或主机休眠

### EDID

EDID 选择器用于切换 EDID 配置，预设两个选项：

- **default**
- **1080p**

![EDID](./images/screen/web-screen-edid.webp)

> 在设置中添加自定义 EDID 配置后，下拉选项会出现"custom"。详见 [EDID 配置](../system/edid.md)。

**default** 为默认 EDID 配置，支持以下分辨率：

| 分辨率 | 刷新率 |
| :---: | :---: |
| 1920x1080 | 60Hz |
| 1920x1080 | 50Hz |
| 1920x1080 | 30Hz |
| 1920x1080 | 25Hz |
| 1280x720 | 120Hz |
| 1280x720 | 60Hz |
| 1280x720 | 50Hz |
| 1280x720 | 30Hz |
| 1280x720 | 25Hz |
| 1024x768 | 60Hz |
| 800x600 | 60Hz |
| 640x480 | 60Hz |

### 码率控制模式

支持两种码率控制模式，默认为 VBR：

- **VBR**（变码率）：码率随画面变化动态调整，画面变化大时码率增大，变化小时码率减小
- **CBR**（定码率）：码率固定，根据设定值恒定输出

### 画质

画质分为四档：

| 画质 | 码率 | 画面质量 |
|------|------|----------|
| 低 | 最低 | 最差 |
| 中 | 中等 | 中等 |
| 高 | 高 | 好 |
| 极高 | 最高 | 最好 |

> 根据网络环境选择合适的画质。画质越高，码率越大，画面质量越好。

### 重新连接

断开当前连接并重新建立，适用于画面卡顿时尝试恢复。

## 全屏

快捷键 **F11** 可快速进入和退出全屏模式。

![全屏](./images/screen/web-screen-full.webp)

全屏按键位于菜单栏最右侧，点击后全屏显示远程画面：

![全屏](./images/screen/web-screen-fullscreen.webp)

按 `Esc` 或 `F11` 退出全屏。

> 浏览器限制下，全屏模式中 `Esc` 键无法发送给远程主机。可在键盘菜单中设置 Esc 映射，参见 [Esc 映射](./keyboard.md#esc映射)，默认为 `RightCtrl`。
