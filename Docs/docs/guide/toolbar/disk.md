# 硬盘挂载

将 TF 卡中的文件挂载到 FlexKVM，或通过 USB 导出给被控主机使用。常用于：

- 将系统安装镜像导出为虚拟光驱，给被控主机重装系统
- 在 TF 卡和被控主机之间传输文件

![镜像菜单](./images/disk/web-image-menu.webp)

## 菜单栏图标

| 图标 | 含义 |
|------|------|
| 硬盘图标 | TF 卡已插入 |
| 硬盘斜线图标 | TF 卡未插入 |
| 服务器图标 | 正在进行 USB 导出 |

## TF 卡要求

| 项目 | 要求 |
|------|------|
| 卡类型 | MicroSD（TF）卡 |
| 容量 | 最高 512GB |
| 文件系统 | FAT32 / exFAT / ext4 |

> 如果 TF 卡插上没反应，可能是文件系统不支持。NTFS 只能读取不能写入。建议格式化为 FAT32 或 exFAT。

## 典型操作流程

### 场景一：给被控主机重装系统

```
插入TF卡 → 选分区 → 点击"挂载" → 上传 .iso 镜像 → 勾选镜像 → 点击"导出文件" → 被控主机从光驱启动
```

### 场景二：在 TF 卡和被控主机之间传文件

```
插入TF卡 → 选分区 → 点击"挂载" → 上传文件 或 勾选文件下载
```

## 操作指南

### 选择目标

在分区下拉框中选操作对象：

| 选项 | 能做什么 |
|------|----------|
| 整盘 | 只能导出整个 TF 卡给被控主机 |
| 分区（如 sda1） | 可挂载后管理文件，或导出整个分区 |

### 导出只读

开启后，被控主机只能读取导出的存储设备，不能写入。建议保持开启，防止被控主机意外修改 TF 卡内容。

### 挂载分区

选一个分区，点击"挂载"。挂载后：

- 显示分区名和已用/总容量
- 文件列表显示分区内所有文件
- 可以上传、下载、删除文件

![分区已挂载](./images/disk/web-tf-mounted.webp)

### 文件操作

| 操作 | 说明 |
|------|------|
| 上传 | 上传文件到分区，进度条显示上传进度和速度 |
| 下载 | 勾选文件后下载到本地，进度条显示下载进度和速度 |
| 删除 | 删除勾选的文件（不可恢复） |
| 刷新 | 刷新文件列表 |

### 导出

- **整盘/分区导出**：未挂载时，选目标后点"导出"，被控主机识别为 U 盘。
- **单文件导出**：挂载后勾选一个 `.img` 或 `.iso` 文件，点"导出文件"，被控主机识别为光驱。
- **取消导出**：导出过程中点"取消导出"停止。

## 常见问题

**TF 卡插上没反应？**
→ 检查文件系统是否支持。FAT32 和 exFAT 兼容性最好。

**导出的光驱被控主机不识别？**
→ 确认文件是 `.img` 或 `.iso` 格式。其他格式无法作为光驱导出。

**上传到一半断了？**
→ 刷新页面后重新上传，断点续传暂不支持。
