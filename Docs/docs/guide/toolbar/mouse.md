# 鼠标

控制被控主机的鼠标指针，支持不同的操作模式和灵敏度调节。

![鼠标按键](./images/mouse/mouse_ui.webp)

## 鼠标按键

菜单栏中的鼠标按键图标反映当前状态：

- **鼠标图标**：鼠标已连接
- **鼠标禁用图标**：鼠标未连接或被关闭

## 鼠标菜单

点击鼠标按键弹出菜单：

![鼠标菜单](./images/mouse/mouse_button.webp)

### 状态

| 状态 | 说明 |
|------|------|
| 已连接 | 可以正常控制被控主机鼠标 |
| 未连接 | 鼠标未连接到被控主机 |
| 未使能 | 已手动关闭，点击"开启"恢复 |

### 防休止

开启后，鼠标会每隔一段时间自动微移，防止被控主机因检测不到鼠标活动而进入休眠。

> 此功能在网页打开或关闭时都会执行。如不需要，建议关闭。

### 模式

两种鼠标控制方式，各有适用场景：

**绝对模式**（默认）：画面点到哪里，被控主机鼠标就在哪里。

- :white_check_mark: 移动精准，无需点击画面即可控制
- :white_check_mark: 不受鼠标 DPI 影响
- :x: 仅适合单屏幕
- :x: 部分游戏可能不兼容

![绝对模式](./images/mouse/mouse_abs.webp)

**鼠标隐藏**：开启后鼠标移入画面区域自动隐藏，避免画面中出现两个鼠标指针。

**相对模式**：像操作本地电脑一样移动被控主机鼠标。

- :white_check_mark: 支持多屏幕
- :white_check_mark: 兼容游戏等需要原始鼠标输入的应用
- :x: 需要先点击画面进入控制
- :x: 精准度受鼠标 DPI 影响

![相对模式](./images/mouse/mouse_rel.webp)

操作方式：
1. 点击远程画面进入控制（浏览器会请求锁定鼠标指针）
2. 移动鼠标控制被控主机
3. 按 `Esc` 退出控制

> 相对模式下 `Esc` 被占用。需要发送 `Esc` 键？参见 [Esc 映射](./keyboard.md#esc映射)。

**灵敏度**（仅相对模式）：调节鼠标移动速度。

| 值 | 效果 |
|:---:|------|
| 0.2 | 最慢 |
| 1.0 | 正常速度 |
| 3.0 | 最快 |

调节范围 0.2 ~ 3.0，步进 0.2。

### 滚动速率

调节鼠标滚轮的滚动速度。

| 值 | 效果 |
|:---:|------|
| 0.5 | 最慢 |
| 1.0 | 正常速度 |
| 3.0 | 最快 |

调节范围 0.5 ~ 3.0，步进 0.5。

### 滚动反转

开启后滚轮方向反转：向上滚变成向下，向下滚变成向上。

### 关闭与开启

- 状态为**已连接**或**未连接**时，点击"关闭"，状态变为**未使能**
- 状态为**未使能**时，点击"开启"，状态恢复

## 常见问题

**相对模式下鼠标出不来？**
→ 按 `Esc` 键退出相对模式。

**绝对模式下鼠标位置不准？**
→ 检查被控主机是否为多屏幕。绝对模式仅适合单屏幕使用。
