# LED 指示灯

FlexKVM 设备上有三个指示灯，分别反映系统供电、连接状态和网络状态。

## 🔴 电源灯 — 供电状态

红色指示灯，反映设备供电情况：

| 状态 | 含义 |
|:----:|------|
| 常亮 | 设备已接通电源 |
| 灭 | 设备未供电 |

## 🟢 状态灯 — 设备连接状态

绿色指示灯，反映 HDMI 和 USB 的连接情况：

| 状态 | 频率 | 含义 |
|:----:|:----:|------|
| 常亮 | — | 设备正常运行，HDMI 视频信号已锁定 |
| 慢闪 | 1 次/秒 | HDMI 输入信号丢失，请检查 HDMI 线缆及前端设备连接 |
| 快闪 | 4 次/秒 | USB 数据通道未连接，请检查 USB 数据线 |
| 常灭 | — | 系统没有正常启动 |

> 优先级：快闪 > 慢闪 > 常亮。例如 USB 和 HDMI 都未连接时显示快闪。

## 🔴 警告灯 — 网络和系统状态

红色指示灯，反映网络连接和系统异常：

| 状态 | 频率 | 含义 |
|:----:|:----:|------|
| 常灭 | — | 网络已连接，一切正常 |
| 慢闪 | 1 次/秒 | 网络未连接（WiFi 与以太网均不可用），或处于热点配网模式 |
| 快闪 | 4 次/秒 | 正在进行 OTA 固件升级，请勿断电 |
| 常亮 | — | 系统发生严重错误，请检查设备或联系技术支持 |

## 组合状态

| 现象 | 含义 |
|:----|------|
| 🟢 状态灯 + 🔴 警告灯**同时快闪** | 设备正在执行恢复出厂设置 |

## 设置

🟢 状态灯 和 🔴 警告灯支持关闭，以减少光污染。

进入 **设置 → 系统**，找到 LED 设置区块。

![LED 设置](./images/led/setting_led.webp)

- 默认开启状态，关闭后所有指示灯熄灭，适合夜间或需要减少光污染的场合。
