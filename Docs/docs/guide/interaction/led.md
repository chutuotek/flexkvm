# LED 指示灯

FlexKVM 有三个指示灯，分别反映供电、连接和网络状态。🟢 状态灯和 🔴 警告灯可以在设置中关闭（减少光污染）。

## 🔴 电源灯 — 供电状态

| 状态 | 含义 |
|:---:|------|
| 常亮 | 已通电 |
| 灭 | 未供电 |

## 🟢 状态灯 — 连接状态

反映 HDMI 和 USB 的连接情况：

| 状态 | 频率 | 含义 |
|:---:|:---:|------|
| 常亮 | — | 正常，HDMI 已锁定 |
| 慢闪 | 1次/秒 | HDMI 信号丢失 |
| 快闪 | 4次/秒 | USB 未连接 |
| 常灭 | — | 系统没启动 |

> 优先级：快闪 > 慢闪 > 常亮。USB 和 HDMI 都未连时显示快闪。

## 🔴 警告灯 — 网络和系统状态

| 状态 | 频率 | 含义 |
|:---:|:---:|------|
| 常灭 | — | 网络已连，正常 |
| 慢闪 | 1次/秒 | 网络未连，或处于热点配网模式 |
| 快闪 | 4次/秒 | OTA 升级中，别断电 |
| 常亮 | — | 系统严重错误，重启或联系技术支持 |

## 组合状态

| 现象 | 含义 |
|:---|------|
| 🟢 状态灯 + 🔴 警告灯**同时快闪** | 正在恢复出厂设置 |

## 关闭指示灯

进设置 → 系统 → LED 设置。

![LED 设置](./images/led/setting_led.webp)

关掉后所有指示灯熄灭，适合夜间或减少光污染。开关不影响设备运行。
