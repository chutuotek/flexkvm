# OLED 屏幕

FlexKVM 配备一块单色 OLED 显示屏（128x64 分辨率），用于显示设备状态、网络信息和当前工作模式。

## 显示特性

设备通电后 OLED 依次显示：

1. **开机 logo** — "楚拓电子"品牌标志，约 20 秒后进入状态界面
2. **设备状态界面** — 显示 HDMI、USB 连接状态及网络信息
3. **休眠** — 无操作后自动息屏（默认 60 秒），按任意按键或调整设置唤醒

## 状态参考

### 网络图标

OLED 状态栏上的网络图标反映接口连接状态：

| 图标状态 | 含义 |
|:--------:|------|
| X 消失 | 对应接口已成功连接 |
| 显示 X | 对应接口未连接 |

### IP 地址前缀

OLED 显示的 IP 地址使用字母前缀标识接口类型：

| 显示格式 | 接口 | 说明 |
|:--------:|:----:|------|
| **E**xxx.xxx.xxx.xxx | 以太网 | E = Ethernet |
| **W**xxx.xxx.xxx.xxx | WiFi | W = Wireless |
| **A**xxx.xxx.xxx.xxx | AP 热点 | A = Access Point |

### 加载状态

接口正在获取 IP 地址时会显示 Loading 提示：

| 显示 | 含义 | 超时处理 |
|:----:|------|:--------:|
| **E Loading...** | 以太网正在获取 IP | 超过 10 秒未获取到请检查网线连接 |
| **W Loading...** | WiFi 正在获取 IP | 超过 10 秒未获取到请检查 WiFi 连接 |

### 配网模式

长按按键 A 进入配网模式时，OLED 显示热点名称、随机密码和 IP 地址 `192.168.10.1`。详见[配网模式](../network/provision.md)。

## 设置

进入 **设置 → 系统**，找到 OLED 屏幕设置区块。

![OLED 设置](../system/images/oled/setting_oled.webp)

### 亮度

拖动滑块调节 OLED 屏幕亮度。

| 参数 | 说明 |
|:---:|------|
| 调节范围 | 1 ~ 10 档 |
| 生效方式 | 实时生效 |

亮度越高屏幕越清晰，但也越耗电。建议根据使用环境选择合适亮度。

### 休眠时间

OLED 屏幕在无操作后自动关闭的时间。

| 参数 | 说明 |
|:---:|------|
| 可选值 | 10s / 30s / 60s / 120s / 300s / 600s |
| 生效方式 | 选择后即时生效 |

### 唤醒屏幕

屏幕息屏后，可以通过以下方式唤醒：

- **按设备按键**：按下 FlexKVM 设备上的物理按键，屏幕立即亮起
- **修改设置**：调整亮度或休眠时间后，屏幕自动唤醒

> 在配网模式或蓝牙配对模式下，屏幕不会自动息屏。
