# OLED 屏幕

FlexKVM 配备一块单色 OLED 显示屏（128x64 分辨率），用于显示设备状态、网络信息和当前工作模式。

设备通电后 OLED 依次显示：

1. **开机 logo** — "楚拓电子"品牌标志，约 20 秒后进入状态界面
2. **设备状态界面** — 显示 HDMI、USB 连接状态及网络信息
3. **休眠** — 无操作后自动息屏（默认 60 秒），按下按键 A 或按键 B 唤醒

> 在配网模式下，屏幕不会自动息屏。

## OLED 设置

进入 **设置 → 系统**，找到 OLED 屏幕设置区块。

![OLED 设置](./images/oled/setting_oled.webp)

### 亮度

拖动滑块调节 OLED 屏幕亮度。

|   参数   | 说明      |
| :--------: | ----------- |
| 调节范围 | 1 ~ 10 档 |
| 生效方式 | 实时生效  |

亮度越高屏幕越清晰，但也越耗电。建议根据使用环境选择合适亮度。

### 休眠时间

OLED 屏幕在无操作后自动关闭的时间。

|   参数   | 说明                                 |
| :--------: | -------------------------------------- |
|  可选值  | 10s / 30s / 60s / 120s / 300s / 600s |
| 生效方式 | 选择后即时生效                       |

## OLED 界面

OLED 有两个界面：

- **主界面**
- **配网界面**

### 主界面

![OLED 主界面](../../quick_start/images/oled_wifi_connected.webp)

主界面一共四行，分为三个部分：

- **状态栏**：顶部一行，显示当前设备各个接口的连接状态
- **IP 地址** 中间两行，显示当前设备的各个接口的 IP 地址
- **系统版本**：底部一行，显示当前设备的系统版本号

#### 状态栏

一共 6 个图标，从左到右分别是：

| 图标 | 含义 |
|:----:|------|
| HDMI | HDMI 接口是否插入 |
| USB | USB 信号是否正常 |
| TF 卡 | TF 卡是否插入 |
| ATX | ATX 模块是否连接 |
| 有线网络 | 有线网络是否连接 |
| 无线网络 | WiFi 未连接 / WiFi 已连接 / 热点已开启（三种状态） |

OLED 状态栏上的网络图标反映接口连接状态：

| 图标状态 | 含义               |
| :--------: | -------------------- |
|  图标正常显示  | 对应接口已成功连接 |
|  图标上显示 X  | 对应接口未连接     |

#### IP 地址

OLED 显示的 IP 地址使用字母前缀标识接口类型：


|       显示格式       |  接口  | 说明             |
| :--------------------: | :-------: | ------------------ |
| **E**xxx.xxx.xxx.xxx | 以太网 | E = Ethernet     |
| **W**xxx.xxx.xxx.xxx |  WiFi  | W = Wireless     |
| **A**xxx.xxx.xxx.xxx | AP 热点 | A = Access Point |

接口正在获取 IP 地址时会显示 Loading 提示：


|       显示       | 含义              |              超时处理              |
| :----------------: | ------------------- | :----------------------------------: |
| **E Loading...** | 以太网正在获取 IP |  超过 10 秒未获取到请检查网线连接  |
| **W Loading...** | WiFi 正在获取 IP  | 超过 10 秒未获取到请检查 WiFi 连接 |

#### 系统版本

显示当前设备的系统版本号，如 `v0.1.2` 或者 `v0.1.3-Beta.1`。

## 配网界面

长按按键 A 进入配网模式时，OLED 显示热点名称、随机密码和 IP 地址 `192.168.10.1`。详见[配网模式](../network/provision.md)。
