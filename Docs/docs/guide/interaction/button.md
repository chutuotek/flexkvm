# 物理按键

FlexKVM 设备上有四个物理按键，用于配网、切换模式和系统维护。

## 按键速查

| 按键 | 操作 | 功能 | 适用场景 |
|:----:|:----|------|----------|
| **按键 A** | 长按 3~6 秒 | 进入热点配网模式 | 首次联网、网络配置错误后恢复 |
| **按键 A** | 长按超过 6 秒 | 返回主界面（不进入配网） | 误触后取消操作 |
| **按键 B** | 长按 3 秒 | 切换 WiFi 与 AP 热点模式 | 无需进入 Web 界面，快速开启热点 |
| **复位按键** | 短按 | 强制重启系统 | 系统无响应或异常 |
| **恢复出厂按键** | 长按 15 秒 | 恢复出厂设置（清除所有配置） | 设备转让、配置混乱无法修复 |

## 按键说明

### 按键 A — 配网模式

长按 3~6 秒进入热点配网模式，OLED 显示 AP 图标后松开，设备会生成临时 WiFi 热点，供手机或电脑连接后配置网络。

> 长按不足 3 秒不会触发；超过 6 秒则返回主界面。详见[配网模式](../network/provision.md)。

### 按键 B — WiFi / AP 切换

长按 3 秒可在 WiFi 模式和热点模式之间切换：

| 当前模式 | 切换结果 | 等待时间 |
|:--------:|:--------:|:--------:|
| WiFi 模式 | 关闭 WiFi，开启热点模式 | 约 10 秒 |
| 热点模式 | 关闭热点，恢复 WiFi | 3~4 秒 |

详见[热点模式](../network/ap.md)和[WiFi](../network/wifi.md)。

### 复位按键

短按立即重启系统，不会清除配置。适用于系统卡死或网络配置异常导致无法访问时的快速恢复。

### 恢复出厂按键

长按 15 秒清除所有配置并恢复出厂状态。操作时 🟢 状态灯和 🔴 警告灯会同时快闪。

> ⚠️ 恢复出厂会清除所有配置（网络、账户、证书等），操作前请确保已备份必要信息。无法远程操作，需物理接触设备。
