# 物理按键

FlexKVM 有四个物理按键，用于配网、切换模式和系统维护。

## 按键速查

| 按键 | 操作 | 功能 | 适用场景 |
|:---:|:---|------|----------|
| 按键 A | 短按 | 循环切换 OLED 子页面 | 查看 HDMI/系统/ETH/WiFi/AP 信息 |
| 按键 A | 长按 1~3 秒后释放 | 进入配网模式 | 首次联网、网络配置错误后恢复 |
| 按键 A | 长按超 3 秒后释放 | 返回主界面（取消配网） | 误触后取消操作 |
| 按键 B | 短按 | 返回主界面（从子页面） | 退出 HDMI/系统/ETH/WiFi/AP 信息等详情页 |
| 按键 B | 长按 1~3 秒后释放 | 切换直连模式 | 无路由器场景，网线直连电脑 |
| 按键 B | 长按 3~5 秒后释放 | 切换 WiFi ↔ AP 热点 | 无需 Web 界面，快速开启 AP 热点 |
| 按键 B | 长按 5 秒后释放 | 返回主界面（取消操作） | 误触后取消 |
| 复位按键 | 短按 | 强制重启 | 系统无响应或异常 |
| 恢复出厂按键 | 按住 1 秒出倒计时，15 秒归零后松开 | 恢复出厂 | 设备转让、配置混乱无法修复 |

## 按键说明

### 按键 A — 配网 + 信息查看

**短按**：循环切换 OLED 子页面 — 主页 → HDMI 信息 → 系统信息 → ETH 信息 → ETH IPv6 → WiFi 信息 → WiFi IPv6 → AP 信息 → 主页。用于快速查看视频参数、系统信息和网络详情。

**长按**：分两阶段 —— 按住 1 秒后 OLED 显示配网图标预览，此时松手进入配网模式；继续按住至 3 秒，OLED 切换为 HOME 图标预览，此时松手返回主页（取消配网）。详见[配网模式](../network/provision.md)。

### 按键 B — 三阶段切换 + 返回

**短按**：在任意信息子页面（HDMI 信息/系统信息/ETH 信息/ETH IPv6/WiFi 信息/WiFi IPv6/AP 信息等）中返回主界面。

**长按**：按键 B 长按，OLED 按时间依次显示三种模式预览，松手即触发对应操作：

| 长按时长 | 操作 | OLED 预览 | 等待 |
|:---:|:---|:---|:---:|
| 1~3 秒 | 切换直连模式 | 直连专用图标 / 以太网图标 | ~5 秒 |
| 3~5 秒 | 切换 WiFi ↔ AP 热点 | WiFi 或 AP 图标 | 3~10 秒 |
| 5 秒后 | 返回主界面（取消操作） | HOME 图标 | 即时 |

**第一阶段（1~3s）**：切换[直连模式](../network/eth-server.md)。当前是有线网络（非直连）→ 显示直连专用图标，松手开启直连；当前是直连模式 → 显示以太网图标，松手恢复有线网络。

**第二阶段（3~5s）**：切换 WiFi 和 [AP 热点](../network/ap.md)。当前是 AP 热点 → 显示 WiFi 图标，松手关闭 AP 热点恢复 WiFi；当前是 WiFi 或全关 → 显示 AP 图标，松手关闭 WiFi 开启 AP 热点。

**第三阶段（5s+）**：返回首页，不执行任何切换操作。适用于误触后取消。

> 达到每个阶段时 OLED 立即显示预览。只要不松手，依次进入下一阶段。

### 复位按键

短按立即重启系统，不丢配置。适用于系统卡死或网络配置异常导致无法访问时。

### 恢复出厂按键

按住 **1 秒** → OLED 进入 RESET MODE，倒计时从 **14** 开始；继续按住，倒计时逐秒归零（总计 15 秒）→ OLED 显示 RESET → **松开**才执行清除。**中途松开即取消**，不清除任何数据。清除过程中 🟢 状态灯和 🔴 警告灯同时快闪，清除完成后设备自动重启。

**会清除**：网络、账号、密码、证书等配置。**不会清除**：审计日志、固件版本。

> ⚠️ 需物理接触设备，无法远程操作。详见[恢复出厂设置](../maintenance/factory-reset.md)。
