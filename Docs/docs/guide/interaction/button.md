# 物理按键

FlexKVM 有四个物理按键，用于配网、切换模式和系统维护。

## 按键速查

| 按键 | 操作 | 功能 | 适用场景 |
|:---:|:---|------|----------|
| 按键 A | 长按 3~6 秒 | 进入热点配网模式 | 首次联网、网络配置错误后恢复 |
| 按键 A | 长按超 6 秒 | 返回主界面（不配网） | 误触后取消操作 |
| 按键 B | 长按 3~6 秒后释放 | 切换以太网直连模式 | 无路由器场景，网线直连电脑 |
| 按键 B | 长按 6~9 秒后释放 | 切换 WiFi ↔ 热点模式 | 无需 Web 界面，快速开热点 |
| 按键 B | 长按 9 秒后释放 | 返回主界面（取消操作） | 误触后取消 |
| 复位按键 | 短按 | 强制重启 | 系统无响应或异常 |
| 恢复出厂按键 | 长按 15 秒 | 恢复出厂设置 | 设备转让、配置混乱无法修复 |

## 按键说明

### 按键 A — 配网

长按 3~6 秒进入配网模式。OLED 显示 AP 图标后松手 → 设备生成临时 WiFi 热点。不到 3 秒不触发，超 6 秒返回。详见[配网模式](../network/provision.md)。

### 按键 B — 三阶段切换

长按按键 B，OLED 按时间依次显示三种模式预览，松手即触发对应操作：

| 长按时长 | 操作 | OLED 预览 | 等待 |
|:---:|:---|:---|:---:|
| 3~6 秒 | 切换以太网直连模式 | **ETH SERVER** 或 **ETH CLIENT** | ~5 秒 |
| 6~9 秒 | 切换 WiFi ↔ 热点模式 | WiFi 或 AP 大图标 | 3~10 秒 |
| 9 秒后 | 返回主界面（取消操作） | HOME 大图标 | 即时 |

**第一阶段（3~6s）**：切换以太网[直连模式](../network/eth-server.md)。当前是以太网客户端 → 显示 "ETH SERVER"，松手开启直连；当前是直连模式 → 显示 "ETH CLIENT"，松手恢复普通以太网。

**第二阶段（6~9s）**：切换 WiFi 和[热点模式](../network/ap.md)。当前是 WiFi → 显示 AP 图标，松手关 WiFi 开热点；当前是热点 → 显示 WiFi 图标，松手关热点恢复 WiFi。

**第三阶段（9s+）**：返回首页，不执行任何切换操作。适用于误触后取消。

> 达到每个阶段时 OLED 立即显示预览。只要不松手，依次进入下一阶段。

### 复位按键

短按立即重启系统，不丢配置。适用于系统卡死或网络配置异常导致无法访问时。

### 恢复出厂按键

长按 15 秒 → OLED 显示倒计时 → 倒计时归零后松开。清除过程中 🟢 状态灯和 🔴 警告灯同时快闪，清除完成后设备自动重启。

**会清除**：网络、账户、密码、证书等配置。**不会清除**：审计日志、固件版本。

> ⚠️ 需物理接触设备，无法远程操作。详见[恢复出厂设置](../maintenance/factory-reset.md)。
