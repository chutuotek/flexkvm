# 配网模式

配网模式（Provisioning Mode）是 FlexKVM 提供的一种临时 WiFi 热点模式，用于首次配置无线网络，或在网络配置错误导致无法通过 Web 界面访问设备时恢复连接。

> 配网模式与[热点模式](./ap.md)的区别：配网模式是**临时**的，配置完成后自动退出；热点模式是**持续运行**的，用于其他设备长期连接 FlexKVM 的 WiFi 热点。两者通过不同的按键触发。

## 适用场景

| 场景 | 说明 |
|------|------|
| 首次配网 | 设备未联网，通过配网模式配置 WiFi |
| 恢复连接 | 修改了 IP 配置或 MAC 地址后无法访问设备，进入配网模式重新配置 |
| 更换网络 | 更换路由器或网络环境后，原网络配置失效 |

## 与按键 B 的区别

| 功能 | 按键 A（3~6 秒） | 按键 B（3 秒） |
|------|:-----------------:|:--------------:|
| 触发模式 | 配网模式（临时） | AP 热点（持续） |
| 用途 | 首次配网 / 故障恢复 | 日常开启/关闭热点 |
| 退出方式 | 配网页面点击"保存" | 再次长按按键 B 切换 |

## 进入配网模式

1. 确保设备已通电，OLED 显示屏亮起
2. 长按**按键 A** 3~6 秒
3. OLED 显示屏显示 AP 图标 :material-access-point: 后松开按键

![配网模式切换](../../quick_start/images/oled_provision_switch.webp)

> 长按不足 3 秒不会触发；超过 6 秒则返回主界面。如果误操作，松开重试即可。

松开按键后，进入配网等待界面：

![配网等待界面](../../quick_start/images/oled_provision_start.webp)

等待约 12 秒（设备正在生成 WiFi 热点），OLED 显示热点名称、密码和 IP 地址：

![配网界面](../../quick_start/images/oled_provision.webp)

## 连接热点

使用手机或电脑搜索并连接 OLED 上显示的 WiFi 热点，输入显示的 8 位随机密码。

**手机操作：**

1. 打开手机 WiFi 设置，连接到 FlexKVM 热点
2. 系统自动弹出浏览器门户页，点击"信任"或"继续"
3. 如未自动弹出，手动打开浏览器访问 `192.168.10.1`
4. Android 用户也可在通知栏中点击"登录网络"打开门户页

**电脑操作：**

1. 连接 FlexKVM 热点
2. 打开浏览器访问 `192.168.10.1`

![手机连接热点](../../quick_start/images/phone_connect_provision.webp)

> 手机/电脑连接 FlexKVM 热点期间会暂时断开互联网连接，配网完成后自动恢复。

## 配置网络

进入配网页面后，可以看到与正常 Web 管理界面一致的网络设置，分为三个区块：

> 配网模式下所有配置修改后立即生效（AP 配置除外），与正常 Web 管理界面操作一致。各网络的详细配置项可参考对应的文档。

### 有线网络

配置 FlexKVM 的百兆有线网口，支持 DHCP / 静态 IP、自定义 MAC 地址等。

![以太网设置](./images/eth/setting_eth.webp)

详见 [以太网](./eth.md)。

### WiFi 网络

扫描周围的 WiFi 网络，连接或手动添加网络。

![WiFi 列表](../../quick_start/images/web_list_wifi.webp)

![连接 WiFi](../../quick_start/images/web_connect_wifi.webp)

连接成功后卡片会显示"已连接"标签：

![连接成功](../../quick_start/images/web_connected_wifi.webp)

> 如需刷新网络列表，点击 WiFi 卡片右上角的刷新按钮 :material-refresh:。

详见 [WiFi](./wifi.md)。

### AP 网络

配置设备热点（AP）的参数，如 SSID、密码、频段、信道等。

![AP 配置](./images/ap/setting_ap.webp)

> AP 配置与其他网络配置不同：修改后 **不会立即生效**，而是暂存配置，待点击「保存」退出配网模式后统一生效。

详见 [热点模式](./ap.md)。

## 保存并退出

所有网络配置完成后，点击页面右上角的 **"保存"** 按钮：

1. AP 配置统一生效
2. 设备自动退出配网模式并重启网络
3. OLED 显示屏显示设备 IP 地址，🔴 警告灯熄灭（详见 [LED 指示灯](../interaction/led.md)）

![保存退出](../../quick_start/images/web_save.webp)

## 注意事项

- 配网模式下可配置**所有网络**（有线、WiFi、AP），并非仅限 WiFi
- 如果配置错误导致无法访问，可重新按键进入配网模式修改
- 如果配网失败，设备会保持在配网模式，可重试或检查网络环境
- 长时间未操作，配网模式会自动超时退出，重新按键进入即可
