# 网络唤醒 (WoL)

远程唤醒同一局域网内已关机的设备——只需填好 MAC 地址，一键发送唤醒信号。

> FlexKVM 和目标设备必须在**同一个局域网**内，不支持跨网络唤醒。

## WoL 按键

菜单栏中的网口图标用于网络唤醒：

| 图标 | 含义 |
|------|------|
| ![](../icon/wol/ethernet-port.svg) | 网络唤醒（WoL），唤醒局域网内设备 |

点击菜单栏中的网口图标打开 WoL 管理菜单：

![WoL 菜单](./images/wol/wol.webp)

## 前置条件

被唤醒的设备必须满足以下条件：

- 主板和 BIOS 支持并开启了 Wake-on-LAN
- 通过网线连接（WiFi 不支持）
- 处于关机、休眠或睡眠状态（不能是完全断电）
- 与 FlexKVM 处于同一局域网

### 开启 BIOS WoL

开机按 `Del` / `F2` 进入 BIOS，在 **Power Management（电源管理）** 中找到 **Wake-on-LAN** 或类似选项（如 Power On By PCI-E / PME Event）并开启，保存退出。

> 不同主板 BIOS 界面差异较大，如果找不到对应选项，请联系主板厂商或查阅主板手册。

## 使用方法

### 添加设备

1. 点击 "+" 按钮
2. 填写设备名称（仅支持英文字母和数字，最长 32 个字符）
3. 填写 MAC 地址（格式如 `AA:BB:CC:DD:EE:FF`）
4. 点击确认

> 设备名称不能重复，最多添加 5 台。

![添加设备](./images/wol/wol_add.webp)

### 唤醒设备

设备列表中点击闪电图标即可发送唤醒信号。唤醒成功后会弹出提示。

> 如果唤醒失败，请检查：① 设备是否通过网线连接；② BIOS 中 WoL 是否开启；③ MAC 地址是否正确；④ 设备是否处于同一局域网。

### 删除设备

点击垃圾桶图标从列表中移除。

## 如何查看 MAC 地址

| 系统 | 命令 |
|------|------|
| Windows | 打开命令行，输入 `ipconfig /all`，找到"物理地址" |
| Linux | 打开终端，输入 `ip addr` 或 `ifconfig` |
| macOS | 打开终端，输入 `ifconfig` |

## 常见问题

**点了唤醒但设备没反应？**
→ 检查：① 设备是否连的网线（不是 WiFi）；② BIOS 中 WoL 是否开启；③ MAC 地址是否填对。

**可以跨网络唤醒吗？**
→ 不可以。FlexKVM 和目标设备必须在同一个局域网内。
