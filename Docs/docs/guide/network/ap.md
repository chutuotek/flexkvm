# 热点模式

FlexKVM 可以创建 WiFi 热点（AP），供其他设备直接连接访问管理界面。长按按键 B 约 3 秒即可开启或切换热点，无需进入 Web 界面操作。

- 默认 SSID： FlexKVM-AP 
- 默认密码： 12345678 

> 设备性能受限，热点和 WiFi 同时启用会影响两者性能，建议仅在需要时启用其中一种模式。

## 规格

| 项目 | 说明 |
|:----:|------|
| 无线协议 | 802.11 a/b/g/n/ac/ax（与 WiFi 共用无线模块） |
| 频段 | 2.4GHz / 5GHz |
| 天线接口 | SMA 内针（与 WiFi 共用天线） |
| 默认状态 | 关闭 |

> 提示：启用热点后，其他设备可以搜索并连接到该 WiFi 热点，通过热点分配的 IP 地址访问 FlexKVM 管理界面。

## OLED 显示

当热点模式启用时，OLED 状态栏会显示热点图标。通过按键 B 切换模式时，OLED 会短暂显示切换后的模式图标。

热点模式的 IP 地址会显示为 **Axxx.xxx.xxx.xxx**，其中 **A** 表示 AP 接口。

![AP oled](./images/ap/oled_ap_connected.webp)

## 按键切换

可通过按键 B 在热点模式与 [WiFi](./wifi.md) 模式之间快速切换：

| 当前模式 | 操作 | 切换结果 | OLED 图标 | 等待时间 |
|:--------:|:----:|:--------:|:--------:|:--------:|
| WiFi 模式 | 长按按键 B 约 3 秒，OLED 显示热点图标后松开 | 关闭 WiFi，开启热点模式 | ![热点图标](./images/ap/oled_ap_icon.webp){ width="80" } | 约 10 秒 |
| 热点模式 | 长按按键 B 约 3 秒，OLED 显示 WiFi 图标后松开 | 关闭热点，恢复 WiFi | ![WiFi 图标](./images/wifi/oled_wifi_icon.webp){ width="80" } | 3~4 秒 |

> 按键 B 切换的是热点模式与 WiFi 模式，与[配网模式](./provision.md)（按键 A）不同。配网模式用于首次联网或故障恢复。

## 软件配置

在 Web 管理界面中，进入"设置" → "网络"，可以看到 AP 网络设置区块，如下图所示：

![AP 设置](./images/ap/setting_ap.webp)

### 启用与禁用

点击卡片右侧的开关可以启用或禁用热点。

| 参数 | 说明 |
|:---:|------|
| 默认状态 | 关闭 |
| 默认 SSID | FlexKVM-AP |
| 默认密码 | 12345678 |

> 警告：如果同时开启热点和 WiFi，两者性能会相互影响。建议在热点使用完毕后及时关闭。

### AP 配置

点击卡片左侧的齿轮图标打开配置弹窗：

![AP 配置](./images/ap/setting_ap_setting.webp)

| 配置项 | 说明 | 默认值 | 可选值 |
|------|------|:---:|------|
| SSID | WiFi 热点名称 | FlexKVM-AP | 自定义字符串 |
| 密码 | WiFi 热点密码 | 12345678 | 8~63 位字符 |
| 加密方式 | 无线安全协议 | WPA_WPA2 | WPA / WPA2 / WPA3 / 开放 |
| 频段 | 工作频率 | 2.4GHz | 2.4GHz / 5GHz |
| WiFi 6 | 启用 802.11ax | 关闭 | 开启 / 关闭 |
| 信道 | 无线信道 | 自动 | 2.4G: 0~11, 5G: 36~165 |
| 最大客户端数 | 同时连接的设备上限 | 2 | 1 ~ 64 |

> 注意：AP 配置修改后立即生效。如果通过[配网模式](./provision.md)配置 AP，修改会暂存，待退出配网模式后统一生效。

### 连接状态

![AP 连接状态](./images/ap/setting_ap_open.webp)

启用热点后，卡片上会显示当前连接信息：

- **热点 SSID**：当前热点的名称
- **频段标签**：2.4G 或 5G
- **已连接客户端数**：当前连接的设备数量 / 最大客户端数

例如 `1/2` 表示当前有 1 台设备连接，最多允许 2 台设备同时连接。

## 配置验证

热点启用后，可通过以下方式验证：

| 验证项 | 方法 |
|--------|------|
| OLED 显示屏 | 查看是否有热点图标显示 |
| Web 界面 | AP 卡片显示已启用状态及连接数 |
| 客户端连接 | 使用手机或电脑搜索热点 SSID 并连接 |

## 故障排查

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| 热点无法启用 | WiFi 模式已开启 | 先关闭 WiFi 再启用热点，或使用按键 B 切换 |
| 客户端无法连接 | 密码错误或 SSID 未广播 | 确认密码输入正确，检查 SSID 是否包含特殊字符 |
| 连接后无法访问管理界面 | 客户端 IP 配置异常 | 确认客户端使用 DHCP（热点自动分配 IP） |
| 热点性能差 | 同时开启了 WiFi | 关闭 WiFi 后再使用热点 |
| 客户端连接数不足 | 最大客户端数设置过低 | 在 AP 配置中增大最大客户端数 |
