# 热点模式

FlexKVM 自建一个 WiFi 热点，手机或电脑直接连上来就能访问管理界面——不需要路由器、不依赖现场网络。长按按键 B 3~5 秒后释放即可开关。

- 默认 SSID：`FlexKVM-AP`
- 默认密码：`12345678`

> 热点和 WiFi 共用无线模块，同时开两者性能会互相影响。用完了记得关。

## 规格

| 项目 | 说明 |
|:----:|------|
| 无线协议 | 802.11 a/b/g/n/ac/ax |
| 频段 | 2.4GHz / 5GHz |
| 天线接口 | SMA 内针（与 WiFi 共用） |
| 默认状态 | 关闭 |

## OLED 显示

热点开启后，OLED 状态栏显示热点图标，IP 前缀为 **A**（如 `A192.168.4.1`），A = Access Point。

![AP oled](./images/ap/oled_ap_connected.webp)

## 按键切换

长按**按键 B** 3~5 秒后释放（第二阶段），在热点和 [WiFi](./wifi.md) 之间切换：

| 当前模式 | 操作 | 切换结果 | OLED 图标 | 等待时间 |
|:--------:|:----:|:--------:|:--------:|:--------:|
| WiFi 模式 | 长按按键 B 3~5 秒，OLED 显示热点图标后松开 | 关 WiFi，开热点 | ![热点图标](./images/ap/oled_ap_icon.webp){ width="80" } | 约 10 秒 |
| 热点模式 | 长按按键 B 3~5 秒，OLED 显示 WiFi 图标后松开 | 关热点，恢复 WiFi | ![WiFi 图标](./images/wifi/oled_wifi_icon.webp){ width="80" } | 3~4 秒 |

> 按键 B 长按分三阶段：1~3 秒切换[以太网直连模式](./eth-server.md)，3~5 秒切换热点/WiFi，5 秒后返回。详见[物理按键](../interaction/button.md)。

## 软件配置

进 Web 界面 → 设置 → **网络**。

![AP 设置](./images/ap/setting_ap.webp)

### 启用与禁用

点卡片右侧开关。启用后热点立刻生效，其他设备可以搜到并连接。

> 热点开着的时候，通过热点分配的 IP 就能访问管理界面。

### AP 配置

点卡片左侧齿轮图标：

![AP 配置](./images/ap/setting_ap_setting.webp)

| 配置项 | 说明 | 默认值 | 可选值 |
|------|------|:---:|------|
| SSID | 热点名称 | FlexKVM-AP | 自定义 |
| 密码 | 连接密码 | 12345678 | 8~63 位 |
| 加密方式 | 安全协议 | WPA_WPA2 | WPA / WPA2 / WPA3 / 开放 |
| 频段 | 工作频率 | 2.4GHz | 2.4GHz / 5GHz |
| WiFi 6 | 802.11ax | 关闭 | 开启 / 关闭 |
| 信道 | 无线信道 | 自动 | 2.4G: 0~11, 5G: 36~165 |
| 最大客户端数 | 同时连接上限 | 2 | 1 ~ 64 |

> 配置修改后立即生效。配网模式下修改 AP 配置会暂存，退出配网时统一生效。

### 连接状态

![AP 连接状态](./images/ap/setting_ap_open.webp)

启用后卡片显示：热点 SSID、频段标签、已连接客户端数/上限（如 `1/2` 表示 1 台已连，最多 2 台）。

### 配置验证

| 验证项 | 方法 |
|--------|------|
| OLED | 看有没有热点图标 |
| Web 界面 | AP 卡片显示已启用 + 连接数 |
| 客户端 | 手机或电脑搜热点 SSID 并连接 |

## 故障排查

| 现象 | 可能原因 | 先试这个 |
|------|----------|---------|
| 热点开不了 | WiFi 正开着 | 先关 WiFi 再开热点，或用按键 B 切换 |
| 客户端连不上 | 密码输错、SSID 有特殊字符 | 确认密码，检查 SSID |
| 连上后打不开管理页 | 客户端 IP 异常 | 确认客户端用 DHCP（热点会自动分配） |
| 性能差 | WiFi 和热点同时开着 | 关掉 WiFi |
| 客户端数不够 | 上限设太低 | 在配置里调大最大客户端数 |
