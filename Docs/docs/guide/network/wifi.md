# WiFi

FlexKVM 支持通过 WiFi 连接到无线网络，可以扫描周围的 WiFi 网络并连接。

进入"设置" → "网络"，可以看到 WiFi 网络设置区块，如下图所示：

![WiFi 设置](./images/wifi/web-wifi-setting.webp)

## 启用/禁用

点击卡片右侧的开关可以启用或禁用 WiFi。

| 参数 | 说明 |
|:---:|------|
| 默认状态 | 启用 |
| 接口名称 | wlan0 |

> 提示：启用 WiFi 后设备会尝试自动连接已保存的网络。

## 扫描网络

点击卡片右上角的刷新按钮可以手动触发 WiFi 扫描。

![WiFi 扫描](./images/wifi/web-wifi-scan.webp)

扫描完成后会以卡片列表的形式展示周围的 WiFi 网络，每个卡片显示以下信息：

| 信息 | 说明 |
|------|------|
| 网络名称 (SSID) | WiFi 网络的名称 |
| 信号强度 | 以图标显示信号强弱（4 格满格） |
| 加密类型 | WPA / WPA2 / WPA3 / WEP / 开放 |
| 频段 | 2.4G 或 5G |

信号强度分级标准：

| 信号范围 (dBm) | 等级 | 说明 |
|:---:|:---:|------|
| > -50 | 4 | 极强 |
| > -65 | 3 | 强 |
| > -80 | 2 | 中等 |
| > -100 | 1 | 弱 |
| <= -100 | 0 | 无信号 |

列表排序规则：已连接或连接中的网络排在最前，已保存的网络排在次前，其余按信号强度降序排列。

## 连接网络

### 开放网络

点击未加密的开放网络卡片即可直接连接，无需输入密码。

### 加密网络

点击加密网络卡片会弹出连接对话框，输入 WiFi 密码后确认。

![WiFi 连接](./images/wifi/web-wifi-connect.webp)

| 参数 | 说明 |
|------|------|
| 密码 | 8~63 位字符 |

> 提示：连接成功后网络配置会自动保存，下次启动时自动重连。

### 手动添加网络

点击列表上方的 `+` 按钮，可以手动输入网络信息：

![添加 WiFi](./images/wifi/web-wifi-add.webp)

| 字段 | 说明 |
|------|------|
| 网络名称 (SSID) | WiFi 网络的名称 |
| 加密类型 | 开放 / WPA / WPA2 / WPA3 |
| 密码 | 加密网络需要填写密码 |

## 管理已保存网络

已保存的网络提供以下操作：

| 按钮 | 说明 |
|------|------|
| 连接 | 手动连接到该网络 |
| 断开 | 断开当前连接 |
| 设置 | 打开网络详细配置 |
| 忘记 | 从已保存列表中删除该网络 |

### 网络详细配置

点击已保存网络的"设置"按钮，可以配置该网络的连接参数：

- **DHCP 模式（默认）**：IP 地址由路由器自动分配
- **静态 IP 模式**：为该 WiFi 网络设置固定的静态 IP、网关和 DNS（最多 3 个），格式要求与以太网静态 IP 配置相同
- **自定义 MAC**：为该 WiFi 连接设置自定义 MAC 地址

> 提示：每个已保存的网络可以有独立的配置，连接到不同 WiFi 时自动切换。
