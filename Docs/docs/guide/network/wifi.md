# WiFi

FlexKVM 支持 802.11 a/b/g/n/ac/ax（兼容 WiFi 2/3/4/5/6）双频无线网络，2.4GHz 穿墙覆盖广、5GHz 低延迟适合视频传输，与[百兆有线网口](./eth.md)互为备份。可以扫描周围的 WiFi 网络并连接。

> 建议：如果同时使用以太网和 WiFi，将两者配置在不同网段可避免路由冲突。例如以太网用 `192.168.1.x`，WiFi 用 `192.168.2.x`。

## 规格

| 项目 | 说明 |
|:----:|------|
| 无线协议 | 802.11 a/b/g/n/ac/ax（兼容 WiFi 2/3/4/5/6） |
| 频段 | 双频 2.4GHz / 5GHz |
| 天线接口 | SMA 内针 |
| 默认状态 | 启用 |
| MAC 地址 | 见包装盒贴纸 |

## OLED 显示

当设备连接到 WiFi 时，OLED 显示屏上的网络图标上的"X"会消失，并显示当前 IP 地址。

![OLED 网络图标](../../quick_start/images/oled_wifi_connected.webp)

WiFi 的 IP 地址会显示为 **Wxxx.xxx.xxx.xxx**，其中 **W** 表示 WiFi 接口，**xxx.xxx.xxx.xxx** 表示当前分配的 IPv4 地址。

> 在获取 IP 地址时会显示 **W Loading...**，如果超过 10s 没有获取到 IP 地址，请检查 WiFi 连接是否正常，或者网络配置是否正确。
>
> 如果没有连接 WiFi，OLED 显示屏上的网络图标上的"X"会显示。

## 按键切换

可通过按键 B 在 WiFi 与[热点模式](./ap.md)之间快速切换：

| 当前模式 | 操作 | 切换结果 | 等待时间 |
|:--------:|:----:|:--------:|:--------:|
| WiFi 模式 | 长按按键 B 约 3 秒，OLED 显示热点图标后松开 | 关闭 WiFi，开启热点模式 | 约 10 秒 |
| 热点模式 | 长按按键 B 约 3 秒，OLED 显示 WiFi 图标后松开 | 关闭热点，恢复 WiFi | 3~4 秒 |

> 按键切换的是 WiFi 与热点模式，与[配网模式](./provision.md)（按键 A）不同。配网模式用于首次联网或故障恢复。

## 软件配置

在 Web 管理界面中，进入"设置" → "网络"，可以看到无线网络设置区块，如下图所示：

![WiFi 设置](./images/wifi/setting_wifi.webp)

### 扫描网络

点击右上角的刷新按钮可以手动触发 WiFi 扫描。扫描时刷新按钮会旋转，完成后自动更新网络列表。设备也会自动每 40 秒扫描一次，保持列表更新。

### 启用与禁用

点击卡片右侧的开关可以启用或禁用 WiFi。切换开关后会弹出确认对话框，确认后生效。

> 提示：启用 WiFi 后设备会尝试自动连接已保存的网络。如果同时关闭 WiFi 和以太网，将无法通过网络访问设备，请确保至少保留一种网络连接方式。

### 网络卡片

WiFi 网络会以卡片列表形式展示。每张卡片显示以下信息：

- **网络名称 (SSID)**：WiFi 网络的名称
- **信号强度**：以 4 格图标显示信号强弱（4 格对应下文的等级 4，1 格对应等级 1）
- **频段标识**：2.4G、5G 或 2.4G/5G（双频混合网络）
- **加密类型**：WPA / WPA2 / WPA3 / WEP / 开放
- **状态标签**：已连接、连接中、已保存

点击卡片可展开操作按钮，可用操作因卡片类型而异：

**已连接**

![WiFi 已连接](./images/wifi/setting_wificard_connected.webp)

- **断开**：断开当前连接的网络
- **设置**：打开网络配置弹窗

**已保存（未连接）**

![WiFi 已保存](./images/wifi/setting_wificard_saved.webp)

- **连接**：连接到该网络
- **忘记**：从已保存的网络列表中移除该网络
- **设置**：打开网络配置弹窗

**未保存**

![WiFi 未保存](./images/wifi/setting_wificard_unsaved.webp)

- **连接**：连接到该网络

> 提示：每个已保存的网络可以有独立的配置，连接到不同 WiFi 时自动切换。

网络按以下规则排序：已连接或连接中的网络排在最前，已保存的网络排在次前，其余按信号强度降序排列。

### 连接网络

先展开目标网络卡片（见上节「网络卡片」），然后根据网络类型操作：

#### 开放网络

点击未加密的开放网络卡片展开卡片，然后点击连接按键，无需输入密码即可进行连接。连接成功后卡片会显示「已连接」标签及 IP 地址。

#### 加密网络

点击需要密码的网络卡片，卡片展开后点击"连接"按钮。

![WiFi 连接](../../quick_start/images/web_connect_wifi.webp)

在弹出的对话框中输入 WiFi 密码后确认。

![WiFi 连接中](../../quick_start/images/web_connecting_wifi.webp)

连接过程中会显示当前状态：

![WiFi 连接状态](./images/wifi/web_connecting_wifi2.webp)

连接成功后卡片会显示「已连接」标签及 IP 地址。

> 提示：连接成功后网络配置会自动保存，下次启动时自动重连。

#### 手动添加网络

点击列表上方的 `+` 按钮，可以手动输入网络信息：

![添加 WiFi](./images/wifi/setting_wifi_add.webp)

| 字段 | 说明 |
|------|------|
| 网络名称 (SSID) | WiFi 网络的名称 |
| 加密类型 | 开放 / WPA / WPA2 / WPA3 |
| 密码 | 加密网络需要填写密码 |

连接成功后卡片会显示「已连接」标签及 IP 地址。

> 连接成功后该网络会自动保存到「已保存」列表，可通过卡片的「设置」按钮进入网络配置弹窗（如修改 IP 模式、DNS 等）。

### 网络配置

点击已保存网络卡片上的"设置"按钮，打开网络配置弹窗，包含三个标签页：

#### 详情信息

![WiFi 详情信息](./images/wifi/setting_wifi_info.webp)

只读展示当前连接的网络信息：

| 信息项 | 说明 |
|------|------|
| IP 地址 | 当前分配的 IPv4 地址 |
| MAC 地址 | WiFi 接口的物理地址 |
| 子网掩码 | 当前使用的子网掩码 |
| 网关 | 当前使用的默认网关 |
| DNS1 ~ DNS3 | 当前使用的 DNS 服务器 |

#### IPv4 配置

支持两种 IP 获取模式：

![WiFi DHCP](./images/wifi/setting_wifi_static_off.webp)

**DHCP（默认）**：由路由器自动分配 IP 地址、网关和 DNS，无需手动配置。

![WiFi 静态 IP](./images/wifi/setting_wifi_static_on.webp)

**静态 IP**：手动设置固定的网络参数。

| 字段 | 说明 | 是否必填 |
|------|------|:---:|
| IP 地址 | 如 `192.168.1.100` | 是 |
| 子网掩码 | 如 `255.255.255.0` | 是 |
| 网关 | 如 `192.168.1.1` | 是 |
| DNS1 | 首选 DNS 服务器 | 否 |
| DNS2 | 备用 DNS 服务器 | 否 |
| DNS3 | 第二备用 DNS 服务器 | 否 |

> 注意：切换为静态 IP 模式后请确保参数与当前网络环境兼容，否则可能导致设备断网。

点击"保存"按钮保存配置，并自动生效。

#### MAC 地址

支持自定义 WiFi 接口的 MAC 地址。

![WiFi MAC 默认](./images/wifi/setting_wifi_mac_off.webp)

**默认状态**：使用设备出厂 MAC 地址。包装盒上的贴纸会标明该接口的 MAC 地址，也可在 Web 界面的「详情信息」标签页中查看。

![WiFi MAC 自定义](./images/wifi/setting_wifi_mac_on.webp)

**自定义 MAC**：格式为 `AA:BB:CC:DD:EE:FF`（6 组十六进制数，以冒号分隔）

> 警告：修改 MAC 地址可能导致网络连接中断。部分路由器可能拒绝识别新的 MAC 地址，请谨慎使用。MAC 地址修改后立即生效，无需重启设备。

### 配置验证

连接成功后，可以通过以下方式验证：

| 验证项 | 方法 |
|--------|------|
| OLED 显示屏 | 查看 IP 地址是否显示 |
| Web 界面 | WiFi 卡片状态显示 IP 地址 |
| 网络测试 | 尝试从其他设备 ping 该 IP 地址 |

## 故障排查

### 常见连接失败原因

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| 找不到网络 | WiFi 未启用、天线未安装 | 检查 WiFi 开关状态，确认天线已连接 |
| 密码错误提示 | 密码输入错误 | 重新输入密码，注意大小写和特殊字符 |
| 连接超时 | 信号太弱、路由器限制 | 靠近路由器，检查路由器是否开启 MAC 过滤 |
| 连接后无 IP | DHCP 未响应 | 尝试使用静态 IP，或检查路由器 DHCP 服务 |
| 频繁断连 | 信号不稳定、干扰严重 | 更换信道，使用 5GHz 频段（如支持） |

### 频段兼容性

| 频段 | 支持 | 说明 |
|:----:|:----:|------|
| 2.4GHz | ✅ | 兼容性好，覆盖范围广 |
| 5GHz | ✅ | 速度快，干扰少 |

### 信号强度建议

为获得稳定的连接体验，建议信号强度至少达到 **等级 2（中等）以上**：

- **等级 3-4**：连接稳定，适合视频传输
- **等级 2**：基本可用，偶尔可能卡顿
- **等级 1 及以下**：连接不稳定，不建议使用

如果信号较弱，可以：
1. 调整 FlexKVM 或路由器的位置
2. 使用 WiFi 信号放大器
3. 改用以太网有线连接
