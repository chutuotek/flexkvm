# 以太网

FlexKVM 的百兆有线网口提供稳定可靠的有线网络连接，与 [WiFi](./wifi.md) 互为备份，一条链路断开时另一条自动接管。支持 DHCP 和静态 IP 两种方式获取 IP 地址。

> 建议：如果同时使用以太网和 WiFi，将两者配置在不同网段可避免路由冲突。例如以太网用 `192.168.1.x`，WiFi 用 `192.168.2.x`。

## 规格

| 项目 | 说明 |
|:----:|------|
| 接口类型 | RJ-45 |
| 传输速率 | 10Mbps / 100Mbps，自动协商（该网口为百兆口，连接千兆路由器时协商为 100Mbps，属于正常现象） |
| 默认状态 | 启用 |
| MAC 地址 | 见包装盒贴纸 ETH: xx.xx.xx.xx.xx.xx |
| PoE 供电 | 不支持，需外接 PoE 供电模块 |

> 如有 PoE 需求，请参阅 [扩展性](../product/extensibility.md)。

## OLED 显示

当设备连接到以太网时，OLED 显示屏上的网络图标上的"X"会消失，并显示当前 IP 地址。

![OLED 网络图标](../../quick_start/images/oled_eth_connected.webp)

以太网的 IP 地址会显示为 **Exxx.xxx.xxx.xxx**，其中 **E** 表示以太网接口。

> 在获取 IP 地址时会显示 **E Loading...**，如果超过 10s 没有获取到 IP 地址，请检查网线是否连接正常，或者网络配置是否正确。
>
> 如果没有插入网线，OLED 显示屏上的网络图标上的"X"会显示。
>
> 更多 OLED 状态说明详见 [OLED 屏幕](../interaction/oled.md)。

## 软件配置

进入"设置" → "网络"，可以看到有线网络设置区块，如下图所示：

![以太网设置](./images/eth/setting_eth.webp)

### 启用与禁用

点击卡片右侧的开关可以启用或禁用以太网。禁用后以太网接口将被关闭。

> 警告：如果同时关闭以太网和 WiFi，将无法通过网络访问设备。请确保至少保留一种网络连接方式。

### 网络状态

以太网卡片会显示当前的连接状态：

| 状态 | 说明 |
|------|------|
| 已连接，IP: x.x.x.x | 网络正常连接，显示当前 IP 地址 |
| 网线未连接 | 以太网已启用但网线未接入 |
| 未启用 | 以太网已被禁用 |

### 网络配置

点击卡片左侧的齿轮图标，打开有线网络配置弹窗，包含三个标签页：

#### 详情信息

![以太网详情信息](./images/eth/setting_eth_info.webp)

只读展示当前网络信息（配置前摸底或配置后验证时均可查看）：

| 信息项 | 说明 |
|------|------|
| IP 地址 | 当前分配的 IPv4 地址 |
| MAC 地址 | 以太网接口的物理地址 |
| 子网掩码 | 当前使用的子网掩码 |
| 网关 | 当前使用的默认网关 |
| DNS1 ~ DNS3 | 当前使用的 DNS 服务器 |

#### IPv4 配置

支持两种 IP 获取模式：

![以太网 DHCP](./images/eth/setting_eth_static_off.webp)

**DHCP（默认）**：由路由器自动分配 IP 地址、网关和 DNS，无需手动配置。

![以太网 STATIC](./images/eth/setting_eth_static_on.webp)

**静态 IP**：手动设置固定的网络参数。

| 字段 | 说明 | 是否必填 |
|------|------|:---:|
| IP 地址 | 如 `192.168.1.100` | 是 |
| 子网掩码 | 如 `255.255.255.0` | 是 |
| 网关 | 如 `192.168.1.1` | 是 |
| DNS1 | 首选 DNS 服务器 | 否 |
| DNS2 | 备用 DNS 服务器 | 否 |
| DNS3 | 第二备用 DNS 服务器 | 否 |

> 注意：切换为静态 IP 模式后请确保参数与当前网络环境兼容，否则可能导致设备断网。

点击"保存"按钮保存配置，并自动生效。

#### MAC 地址

支持自定义网络接口的 MAC 地址。

![以太网 mac off](./images/eth/setting_eth_mac_off.webp)

**默认状态**：使用设备出厂 MAC 地址，包装盒上的贴纸会标明该接口的 MAC 地址。

![以太网 mac on](./images/eth/setting_eth_mac_setting.webp)

**自定义 MAC**：格式为 `AA:BB:CC:DD:EE:FF`（6 组十六进制数，以冒号分隔）

> 警告：修改 MAC 地址可能导致网络连接中断。部分路由器可能拒绝识别新的 MAC 地址，请谨慎使用。MAC 地址修改后立即生效，无需重启设备。
>
> 如因修改 MAC 地址导致无法连接，可通过[配网模式](./provision.md)（长按按键 A 3~6 秒）进入设备热点重新配置。

### 配置验证

静态 IP 或 MAC 地址配置完成后，可通过以下方式验证是否生效：

| 验证项 | 方法 |
|--------|------|
| OLED 显示屏 | 查看是否显示新配置的 IP 地址 |
| Web 界面 | 以太网卡片状态显示 IP 地址 |
| 网络测试 | 尝试从其他设备 ping 该 IP 地址 |

> 提示：网络配置修改后立即生效，无需重启设备。但如果配置错误导致无法访问，可通过[配网模式](./provision.md)（长按按键 A 3~6 秒）重新配置，或恢复出厂设置。

## 故障排查

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| 网口灯不亮 | 网线未插紧或网线故障 | 尝试重新插拔网线两端，或更换网线 |
| 网口灯亮但不闪烁 | 路由器端口异常或 DHCP 未开启 | 更换路由器端口，或检查路由器 DHCP 服务是否已开启 |
| OLED 显示 E Loading... 超过 20s | DHCP 无响应、IP 地址池耗尽 | 确认路由器 DHCP 正常、可用 IP 充足，或改用[静态 IP](#ipv4-配置) |
| 连接千兆路由器后速率只有 100Mbps | 产品规格为百兆口，非故障 | 该网口协商速率为 100Mbps，属正常现象 |
| 配置静态 IP 后无法连接 | IP 与当前网络环境不兼容 | 通过[配网模式](./provision.md)进入设备热点，重新配置 |
| 修改 MAC 地址后无法连接 | 路由器拒绝识别新 MAC | 通过[配网模式](./provision.md)进入设备热点，重新配置 |
