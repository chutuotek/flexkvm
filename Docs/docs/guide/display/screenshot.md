# 截图

把当前远程画面存为图片，适合留档关键画面。

## 怎么截

点顶栏截图图标 :material-camera: 即可。

> **验证**：截图成功 → 顶部弹出"截图成功"，文件自动保存到浏览器下载目录。没画面时截图会提示失败。

## 文件命名

`flexkvm-screenshot-YYYY-MM-DDTHH-MM-SS.{扩展名}`

如 `flexkvm-screenshot-2026-05-12T21-44-20.png`

## 格式与画质

在设置 → 系统 → **截图设置** 中调整。

![截图设置](./images/screenshot/setting_screenshot.webp)

### 格式

| 选项 | 说明 |
|------|------|
| PNG | 无损，画质最好，文件大 |
| JPG | 有损，文件小 |

### 画质

仅对 JPG 生效：

![截图 JPG 设置](./images/screenshot/setting_screenshot_jpg.webp)

| 选项 | 说明 |
|------|------|
| 低 | 文件最小 |
| 中 | 日常用 |
| 高 | 细节多 |
| 最佳 | 最高画质 |

> PNG 始终最高画质，不受此设置影响。

---

**截图没反应？** → 检查浏览器是否拦截了下载。

**画面模糊？** → 截图分辨率和远程画面一致。要更高清先在[远程画面](screen.md)里调高分辨率。
