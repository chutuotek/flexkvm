# 音频

控制 FlexKVM 的麦克风和扬声器，在被控主机和本地之间传输声音。

音频基于 USB 虚拟声卡（UAC）实现。开启后被控主机上会出现名为 **FlexKVM Audio** 的音频设备。

> 开启或关闭音频时会短暂断开并重新连接 USB，被控主机上的鼠标、键盘和磁盘挂载会短暂失效后恢复。这是正常现象。

## 音频按键

菜单栏中的音频按键图标反映当前状态：

| 图标 | 含义 |
|------|------|
| ![](../icon/audio/audio-lines.svg) | 麦克风和扬声器均已开启 |
| ![](../icon/audio/mic.svg) | 麦克风已开启 |
| ![](../icon/audio/volume2.svg) | 扬声器已开启 |
| ![](../icon/audio/audio-lines-off.svg) | 音频已关闭或未连接 |

## 音频菜单

点击音频按键弹出菜单：

### 状态

| 状态 | 说明 |
|------|------|
| 已连接 | 音频正常 |
| 未连接 | 音频设备未连接，刷新页面或重新连接远程画面可恢复 |
| 已禁用 | 音频功能已关闭 |

### 音频开关

总开关。打开后被控主机上会出现 FlexKVM Audio 设备，关闭后声卡移除、麦克风和扬声器都停止工作。

> 开关音频时 USB 会短暂断开重连，鼠标、键盘和磁盘挂载会短暂失效后恢复。

### 麦克风

开启后，你电脑的麦克风声音会传给被控主机。

> 首次使用需要允许浏览器的麦克风权限。如果浏览器弹出权限请求，请点击"允许"。

### 扬声器

开启后，你能听到被控主机的声音。

## 被控主机设置

音频开关打开后，进入被控主机的系统声音设置：

| 用途 | 选择设备 |
|------|----------|
| 播放声音（听到被控主机的声音） | **FlexKVM Audio** 设为默认播放设备 |
| 录制声音（对被控主机说话） | **FlexKVM Audio** 设为默认录音设备 |

- **Windows**：右键系统托盘扬声器图标 → 声音设置 → 选择输出/输入设备
- **macOS**：系统设置 → 声音 → 输出/输入
- **Linux**：系统设置 → 声音 → 输出/输入设备

## 常见问题

**麦克风没声音？**
→ ① 检查浏览器是否获得了麦克风权限；② 确认音频总开关和麦克风开关都已打开；③ 检查电脑的麦克风是否正常工作；④ 确认被控主机的录音设备已选择 FlexKVM Audio。

**扬声器没声音？**
→ ① 确认音频总开关和扬声器开关都已打开；② 确认被控主机的播放设备已选择 FlexKVM Audio；③ 检查被控主机是否有音频输出。

**音频有杂音或延迟？**
→ 这是网络传输的正常现象。尝试改善网络环境。
