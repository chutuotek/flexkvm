# 音频

控制 FlexKVM 的麦克风和扬声器，在被控主机和本地之间传输声音。

## 音频按键

菜单栏中的音频按键图标反映当前状态：

| 图标 | 含义 |
|------|------|
| ![](../icon/audio/audio-lines.svg) | 麦克风和扬声器均已开启 |
| ![](../icon/audio/mic.svg) | 麦克风已开启 |
| ![](../icon/audio/volume2.svg) | 扬声器已开启 |
| ![](../icon/audio/audio-lines-off.svg) | 音频已关闭或未连接 |

## 音频菜单

点击音频按键弹出菜单：

### 状态

| 状态 | 说明 |
|------|------|
| 已连接 | 音频正常 |
| 未连接 | 音频设备未连接 |
| 已禁用 | 音频功能已关闭 |

### 音频开关

总开关,关闭后被控主机上的FlexKVM声卡会被移除，麦克风和扬声器都停止工作。

### 麦克风

开启后，你电脑的麦克风声音会传给被控主机。被控主机就能"听到"你说话。

> 首次使用需要允许浏览器的麦克风权限。如果浏览器弹出权限请求，请点击"允许"。

### 扬声器

开启后，你能听到被控主机的声音。

## 常见问题

**麦克风没声音？**
→ ① 检查浏览器是否获得了麦克风权限；② 确认音频总开关和麦克风开关都已打开；③ 检查电脑的麦克风是否正常工作。

**扬声器没声音？**
→ 确认音频总开关和扬声器开关都已打开，且被控主机有音频输出。

**音频有杂音或延迟？**
→ 这是网络传输的正常现象。尝试改善网络环境。
