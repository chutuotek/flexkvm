# 拓展

## poe供电拓展

> FLexKVM 支持百兆网口及使用5V进行供电(type-c)，原生不支持poe供电

用户可以购买poe供电模块(将poe和网络进行隔离)进行拓展，实现poe供电。

## 背板拓展

FlexKVM 的背板设计为可拓展的，背板和FlexKVM主体之间是通过螺丝进行固定，支持多种背板类型，包括但不限于：

- 磁吸背板
- 35mm导轨卡扣


> 用户也可以根据自己的需求，DIY设计自己的背板，以满足特定的使用场景。

其他用户的DIY背板设计案例：

- 暂无

### 磁吸背板

> 磁吸背板为基础套餐免费赠送的

磁吸背板的主体部分为3D打印件，四颗N52磁铁，安装了磁吸背板的FlexKVM可以磁吸在各种金属表面，如铁皮、金属机箱等，实现快速固定，方便携带。

### 35mm导轨卡扣

35mm导轨卡扣可以卡在35mm导轨上(C45)
