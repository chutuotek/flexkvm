# 物理与电气特性

## 电源参数

| 参数 | 值 | 说明 |
|------|:---:|------|
| 电源输入 | 5V/1A | 通过 USB Type-C 接口供电 |
| 典型功耗 | 1.5W ~ 2.4W | 正常工作模式 |

> 使用普通的手机充电器（5V/1A 或以上）即可供电。包装内不含电源适配器，需自备。建议使用独立电源适配器以获得最佳稳定性。

## 尺寸与重量

| 参数 | 值 |
|:----:|:---:|
| 尺寸 | 65 × 46 × 22 mm |
| 重量 | 约 100g |

## 环境参数

| 参数 | 范围 |
|:----:|:---:|
| 工作温度 | 0°C ~ 70°C |
| 存储温度 | -20°C ~ 80°C |
| 工作湿度 | 10% ~ 90%（不凝结） |
| 存储湿度 | 5% ~ 95%（不凝结） |
