# 硬盘挂载

FlexKVM 支持 TF 卡（MicroSD 卡）的挂载与文件管理，可以将 TF 卡中的镜像文件通过 USB 导出为虚拟光驱（CD-ROM）或大容量存储设备。

进入菜单栏，点击镜像图标打开硬盘挂载菜单：

![镜像菜单](./images/disk/web-image-menu.webp)

## TF 卡状态

当 TF 卡正确插入后，菜单中会显示 TF 卡总容量。分区列表显示所有识别到的分区及其文件系统类型和大小。

![TF 卡信息](./images/disk/web-tf-info.webp)

### 分区操作

选择分区后可以进行以下操作：

| 操作 | 说明 |
|------|------|
| 挂载 | 将选中的分区挂载到系统，挂载后可浏览和管理文件 |
| 共享 | 将选中的分区或整盘通过 USB 导出到被控主机 |

> 提示：整盘（disk）选项只能共享，不能挂载。分区需要先挂载才能浏览文件。

## 分区挂载

选择分区后点击"挂载"按钮，分区挂载成功后：

- 显示当前挂载的分区名和存储使用情况（已用/总量）
- 进度条显示存储使用百分比
- 文件列表显示分区内的所有文件

![分区已挂载](./images/disk/web-tf-mounted.webp)

### 文件管理

分区挂载后可以对文件进行以下操作：

| 操作 | 说明 |
|------|------|
| 上传 | 上传文件到 TF 卡分区 |
| 下载 | 将选中的文件下载到本地 |
| 删除 | 删除选中的文件 |
| 刷新 | 刷新文件列表 |
| 卸载 | 卸载分区 |

> 注意：删除操作不可恢复，请谨慎操作。

## 镜像共享

FlexKVM 支持将 TF 卡中的镜像文件通过 USB 导出到被控主机，被控主机会识别为一个外部存储设备。

### 整盘/分区共享

选择分区或整盘后点击"共享"按钮，可将整个存储设备导出为 USB Mass Storage 设备。

![共享设置](./images/disk/web-tf-export.webp)

**共享只读**：启用后，被控主机只能读取导出的存储设备，无法写入。默认为关闭状态。

### 单文件 CD-ROM 共享

分区挂载后，在文件列表中勾选一个 `.img` 或 `.iso` 镜像文件，然后点击"共享文件"按钮，可将该文件导出为虚拟 CD-ROM 光驱。

> 注意：单文件共享仅支持 `.img` 和 `.iso` 格式的镜像文件。

导出过程中可以点击"取消共享"按钮停止导出。

> 提示：CD-ROM 模式常用于安装操作系统，被控主机会将导出的镜像文件识别为光驱，可以直接从光驱启动。
