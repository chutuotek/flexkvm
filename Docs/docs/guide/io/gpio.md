# GPIO 引脚控制

通过 GPIO 引脚连接和控制外部设备，适合开关、传感器、继电器等硬件外设。

> 此功能面向工业控制、自定义硬件集成等专业场景。普通用户通常不需要使用。

---

## 前置条件

| 物品 | 说明 |
|------|------|
| FlexKVM 设备 | 已按[快速开始](../../quick_start/index.md)完成接线和网络配置 |
| 2.54 mm 杜邦线（带母口） | 连接 GPIO 引脚 |
| 外部设备 | 开关、传感器、继电器等，需支持 **3.3V** 逻辑电平 |

> :warning: GPIO 引脚电平为 **3.3V**，请勿连接 5V 或其它非 3.3V 设备，否则可能损坏设备。

---

## 引脚说明

FlexKVM 提供两个独立 GPIO 引脚，引脚旁边印有对应字母标识：

![IO GPIO](images/product_io.webp)

| 丝印 | 引脚 | 说明 |
|:----:|:----|------|
| G | GND | 地线，与外部设备共地 |
| A | GPIOA | 通用输入输出，可独立配置模式 |
| B | GPIOB | 通用输入输出，可独立配置模式 |

> GPIOA 和 GPIOB 完全独立，可分别设置为输入或输出模式。

---

## 接线示例

以下两个示例展示最常见的输入和输出场景。

### 读取开关信号（输入模式）

将 GPIOA 配置为输入，检测外部开关的通断：

```
GPIOA ──┬── 按钮一端
        │
GND ────┴── 按钮另一端
```

- 按钮按下 → GPIOA 读到低电平
- 按钮松开 → GPIOA 读到高电平（内部默认上拉）

### 控制 LED 指示灯（输出模式）

将 GPIOB 配置为输出，控制外部 LED 的亮灭：

```
GPIOB ────→ 限流电阻 ────→ LED 正极（长脚）
GND ────────────────────→ LED 负极（短脚）
```

> LED 需串联一个 **220Ω ~ 1kΩ** 的限流电阻，否则可能烧毁 LED 或 GPIO 引脚。

## 软件配置

在 FlexKVM Web 界面中，点击菜单栏的芯片图标，进入 IO 菜单后选择 **GPIO 引脚控制**。

| 图标 | 含义 |
|:----:|------|
| ![](../icon/io/cpu.svg) | IO 功能，包含 GPIO 和 UART 串口 |

![GPIO 界面](images/io.webp)

> 所有引脚默认处于**禁用状态**（输入模式、不监听电平变化），需要手动启用。

### 启用引脚

![GPIO 启用](images/io_gpio.webp)

每个引脚卡片上有一个开关，开启后引脚进入**输入模式**并开始监听电平变化。

### 输入模式

输入模式下，引脚的电平由外部设备决定，Web 界面实时反映当前状态：

- 🟢 **绿色** = 高电平（3.3V）
- ⚫ **灰色** = 低电平（0V）

> 输入模式下**不能**手动设置电平。外部设备改变电平后，界面会自动更新。

### 输出模式

点击模式切换按钮，切换为输出模式后，可通过"高"/"低"按钮手动控制引脚电平：

- 点击 **高** → 引脚输出 3.3V
- 点击 **低** → 引脚输出 0V

> 输出模式下，如需重新读取外部信号，请切换回输入模式。

## 常见问题

**GPIO 引脚输出没有电压？**
→ 确认引脚已启用且模式为"输出"。启用但未切换为输出模式时，引脚处于输入状态，不会主动输出电平。

**输入模式读到错误的电平？**
→ 检查外部接线是否正确，确认引脚与外部设备**共地**（GND 已连接）。

**接线后界面状态不变？**
→ 确保引脚已开启。禁用状态下的引脚不会监听电平变化，界面不会更新。
