# GPIO 引脚控制

通过 GPIO 引脚连接和控制外部设备，适合开关、传感器、继电器等硬件外设。

> 此功能面向工业控制、自定义硬件集成等专业场景。普通用户通常不需要使用。

## 打开 GPIO 面板

点击菜单栏中的芯片图标，打开 IO 菜单后选择 GPIO 引脚控制。

| 图标 | 含义 |
|------|------|
| ![](../icon/io/cpu.svg) | IO 功能，GPIO 和 UART 串口 |

![IO GPIO](images/io/io_gpio.webp)

FlexKVM 提供 GPIOA 和 GPIOB 两个引脚，可独立配置。

## 启用与模式

每个引脚卡片上有一个开关，开启后可设置模式：

| 模式 | 用途         | 说明                   |
| ------ | -------------- | ---------------------------- |
| 输入 | 检测外部信号 | 显示当前是高电平还是低电平 |
| 输出 | 向外发送信号 | 手动切换高/低电平        |

## 输入模式

- 🟢 绿色灯 = 高电平
- ⚫ 灰色灯 = 低电平

电平由外部设备决定，不能手动切换。

## 输出模式

点击"高"或"低"按钮手动切换输出电平。

## 常见问题

**GPIO 输出电压不对？**
→ 确认引脚已启用且模式为"输出"。

**输入模式读到错误的电平？**
→ 检查外部接线是否正确，确认引脚与外部设备共地。
