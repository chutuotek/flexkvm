# frp 内网穿透

frp 是**端口映射**工具：设备上的 frpc 客户端主动连上你自己那台有公网 IP 的服务器（frps），把 FlexKVM 上的某个端口映射成服务器上的一个公网端口。之后从任何能访问这台服务器的地方，就能打开设备上的 Web 界面或 SSH——设备本身不需要公网 IP，也不用在路由器上做端口转发。

> 入口：设置 → 应用 → frp 内网穿透

![frp 内网穿透](./images/frp/setting_frp_panel.webp)

## 前置条件

FlexKVM 这一侧只跑客户端 frpc，**服务端 frps 要你自己准备**：一台有公网 IP 的服务器，装好 frp 并运行 frps。服务器怎么装、怎么配见 [frp 官方文档](https://gofrp.org)，本文不展开。

要在服务器上记下三项，它们必须与 frps 侧一致：

| 要准备的 | 说明 |
|----------|------|
| 服务端地址 | 服务器的域名或公网 IP |
| 服务端端口 | frps 的 `bindPort`（默认 `7000`） |
| 鉴权 token | frps 配了 token 就必须填一致；没配可以留空 |

服务器防火墙（云服务器还要在安全组）需要放行 frps 的 `bindPort`，以及每条隧道用到的**公网端口**。

> frp 是端口映射，不是组网：设备不会获得虚拟 IP，服务端也只把端口单方向转发给设备。要与电脑双向互通（互 ping、访问整段内网），用 [Tailscale](tailscale.md)。

## 安装

设备上可能还没有这个应用——卡片上会显示黄色提示**应用未安装**，此时服务控件（开关、服务端设置、隧道列表）整块收起，只剩提示和**应用管理**入口。

1. 点卡片上的**应用管理**
2. 点**检查更新**
3. 点**下载**（可以随时取消），下载完成后自动校验安装包
4. 校验通过后按钮变为**立即安装**，点它完成安装

> **验证**：安装完成后「应用未安装」提示消失，开关行副标题显示版本号（形如 `版本 0.71.0`），服务控件全部出现。

下载源选择、安装失败原因、固件版本要求见[应用管理](../maintenance/upgrade-app.md)。

## 启用服务

使能的前置是**服务端地址已填**（鉴权 token 可选）：地址为空时开关是灰的，行上提示"先填写服务端地址才能启用 frp"。填好地址后打开开关，后端生成 `frpc.toml` 并拉起 frpc 进程。

> **验证**：开关打开后，「隧道列表」行右侧显示**运行中**。

运行态由后端轮询后推送（隧道起停、服务端掉线重连都会更新），不需要手动刷新；点卡片右上角的刷新图标（**刷新状态**）可以立刻查一次 frpc 的 admin API。

> 落盘或起停失败时开关会自动退回原位，不会留下"界面显示已开、实际没生效"的错位。

## 设置服务端

点**服务端设置**打开表单，三项都要与 frps 一致：

| 字段 | 说明 |
|------|------|
| 服务端地址 | frps 的域名或 IP，如 `frps.example.com` |
| 服务端端口 | frps 的 `bindPort`，默认 `7000` |
| 鉴权 token | 与 frps 一致；**留空表示不修改**（token 不回显） |

![frp 服务端设置](./images/frp/setting_frp_server.webp)

卡片的**服务端设置**行右侧显示当前 `地址:端口`，没填过时显示**未设置**。

**运行中禁改**：frpc 在跑时这一行是灰的，因为改连接参数必然重连、会掐断全部隧道。要先关掉开关再改，保存即落盘，下次启用按新参数连接。运行中该行副标题显示 `公网：<端口>`，停止后回到"frps 地址与鉴权 token（token 可选）；改完下次启用生效"。

> **验证**：保存后该行显示 `frps.example.com:7000`；重新打开开关，「隧道列表」行显示**运行中**且隧道陆续恢复。

## 新增、修改、删除隧道

点**隧道列表**打开列表，右下角是**新增隧道**按钮（列表为空时提示"还没有隧道，点右下角新增"）。

![frp 隧道列表](./images/frp/setting_frp_proxies.webp)

一条隧道只有 5 个字段：

| 字段 | 说明 |
|------|------|
| 名称 | 这条隧道的唯一标识，**同名保存就是改写它**；只能包含字母、数字、`-` 和 `_` |
| 类型 | 只支持 `TCP` / `UDP` |
| 本地地址 | 被暴露的本机地址，默认 `127.0.0.1` |
| 本地端口 | 本机上真正提供服务的端口 |
| 公网端口 | frps 上的落点端口（地址由 frps 决定，不在这里填） |

![frp 新增隧道](./images/frp/setting_frp_proxy_new.webp)

以把设备 Web 界面映射出去为例：本地地址 `127.0.0.1`、本地端口 `443`、公网端口挑一个服务器上空闲的端口（如 `8443`），完成后访问 `https://<frps 地址>:8443` 即可。

> 端口必须是 1–65535，名称最多 63 个字符；隧道最多 16 条，满了保存会提示"隧道数量已达上限（16 条）"。
> 表单只提供这 5 项，不暴露 frpc 的加密、限速、自定义域名等高级配置。

点**确认**保存，**热生效，不断开已有连接**（这一点与改服务端参数不同）。

### 修改

列表里点铅笔图标 → 弹出**编辑隧道**，字段和新增一样，改完点**确认**。**改名字等于新增一条**：同名才改写，换成别的名字后旧隧道仍然在列表里，需要自己删掉。

### 删除

列表里点垃圾桶图标 → **立即下发，没有二次确认**。

> **验证**：保存后列表里出现这条隧道——名称右侧是类型标签，下一行显示 `127.0.0.1:443 → frps.example.com:8443`，状态正常时不额外标状态。

## 隧道列表与运行状态

- **隧道列表**行右侧是整体状态：**运行中** / **未运行** / **控制面不可达**；副标题是"共 N 条隧道"
- 列表里每条隧道显示名称、类型、`本地地址 → 公网地址`；状态正常时不标状态，`wait`（等待中）/ `error`（出错）会显示在名称右侧，出错时鼠标悬停在状态文字上看原因
- 只有应用已安装、已启用、进程在跑且控制面可达时，**新增隧道**与每行的编辑/删除按钮才可用；否则是灰的
- 列表内容来自 frpc 上报的**运行态**：服务未运行时列表是空的，**配置不会因此丢失**，重新启用后隧道照旧

> **验证**：关掉开关后打开隧道列表，列表为空并提示"还没有隧道，点右下角新增"；重新打开开关并点**刷新状态**，原来的隧道全部回来——这说明列表显示的是运行态，不是设备上存着的配置。

## 应用管理

卡片上的**应用管理**入口管这个应用的下载、安装与卸载：

| 操作 | 说明 |
|------|------|
| 下载源 | 选择安装包从 Gitee 还是 GitHub 下载 |
| 检查更新 | 拉取最新版本信息，完成后显示上次检查时间 |
| 下载 / 立即安装 | 下载安装包并校验，校验通过后安装；下载中可以取消 |
| 卸载应用 | 停止 frpc 并删除应用文件（有二次确认） |

- 升级是「停 → 换目录 → 起」，`frpc.toml` 与隧道配置都放在安装目录之外，**升级不会丢配置**
- 卸载会把开关置回关闭，也**不会删掉隧道配置**，重新安装后隧道表照旧

> 版本状态、失败原因分档等完整说明见[应用管理](../maintenance/upgrade-app.md)。

## 故障排查

| 现象 | 可能原因 | 先试这个 |
|------|----------|---------|
| 卡片显示「应用未安装」 | 设备上还没装这个应用 | 点**应用管理** → 检查更新 → 下载 → 立即安装 |
| 开关灰色点不动 | 应用未安装，或服务端地址还没填 | 看开关行下的提示，先填服务端地址 |
| 「服务端设置」行点不动 | frpc 正在运行（运行中禁改） | 先关掉开关，改完再打开 |
| 「隧道列表」里一条都没有 | 服务未运行（列表显示的是运行态），或隧道还没配 | 先打开开关；确实没配就点**新增隧道** |
| 隧道状态一直 `wait` | frps 侧的公网端口没放行或被占用 | 在服务器防火墙与安全组放行该公网端口，或换一个端口 |
| 隧道状态 `error` | frps 拒绝了这条隧道 | 鼠标悬停在状态文字上看原因，换一个公网端口重试 |
| 显示「控制面不可达」 | frpc 进程还活着，但本机 admin API（默认 `7400`）查不到 | 点**刷新状态**；仍不行就关掉开关重新打开 |
| 公网连不上设备 | 服务器没放行 `bindPort` 或公网端口 | 检查服务器防火墙与云安全组，并确认列表里那条隧道没有报错 |
| 保存隧道被拒 | 名称含非法字符、端口超范围，或已到 16 条上限 | 按界面上的红色错误提示改 |
| 开关打开后自动弹回 | 落盘或起停失败 | 看弹出的错误提示，按提示补装应用或填服务端地址 |
| 换过 token 后连不上 frps | token 与 frps 不一致 | 停用后重新填写**鉴权 token**，再启用 |
