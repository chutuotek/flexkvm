# 物理与电气特性

## 核心规格

| 参数 | 值 |
|:----:|:---:|
| 视频输入 | HDMI 1.4，最高 1920×1200@60fps |
| 以太网 | 10/100M 自适应，支持直连模式（DHCP 服务器） |
| WiFi | WiFi 6，双频 2.4GHz / 5GHz |
| USB 数据接口 | USB 2.0 OTG |
| TF 卡 | MicroSD 卡 |
| OLED 屏幕 | 128×64，单色 |
| 扩展接口 | 5pin 排针，UART + GPIO，3.3V 电平 |
| 散热方式 | 铝合金被动散热，无风扇 |

## 电源参数

| 参数 | 值 | 说明 |
|------|:---:|------|
| 电源输入 | 5V/1A | 通过 USB Type-C 接口供电 |
| 典型功耗 | 1.5W ~ 2.4W | 正常工作模式 |

> 使用普通的手机充电器（5V/1A 或以上）即可供电。包装内不含电源适配器，需自备。

## 尺寸与重量

| 参数 | 值 |
|:----:|:---:|
| 尺寸 | 65 × 46 × 22 mm（不含天线） |
| 重量 | 约 100g |

## 环境参数

| 参数 | 范围 |
|:----:|:---:|
| 工作温度 | 0°C ~ 70°C |
| 存储温度 | -20°C ~ 80°C |
| 工作湿度 | 10% ~ 90%（不凝结） |
| 存储湿度 | 5% ~ 95%（不凝结） |
