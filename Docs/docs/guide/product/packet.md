# 包装清单

打开包装后，请对照下表核对物品是否齐全。如有缺失，请联系您的购买渠道或技术支持。

## 基础包装

![FlexKVM 包装清单](../../images/product/package.webp)

| 编号 | 物品 | 数量 | 说明 |
|:----:|------|:----:|------|
| [1] | FlexKVM 主机 | 1 台 | 核心设备 |
| [2] | HDMI 连接线 | 1 条 | 连接被控设备的 HDMI 输出 |
| [3] | USB Type-C 数据线 | 3 条 | 供电、数据传输与 ATX 控制。三条规格完全相同，可互换使用，长度约 1 米，Type-A to Type-C |
| [4] | ATX 控制器 | 1 个 | 远程控制电脑电源开关 |
| [5] | ATX 杜邦线 | 10 根 | ATX 控制器接线，详见 [ATX 控制](../peripherals/atx.md) |
| [6] | 磁吸背板 | 1 个 | 将设备固定在机柜上（已预装在主机背面，开箱时确认即可） |
| [7] | 说明书 | 1 份 | 产品使用说明 |

> **电源适配器**：设备可通过 USB Type-C 供电线（包装编号 [3]）配合独立的 **5V/1A 电源适配器** 供电，包装内不含电源适配器，需**自备**。建议使用独立电源适配器以获得最佳稳定性。

## 额外配件

选购了额外配件时，请对照下表核对物品是否齐全。

| 配件 | 说明 |
|------|------|
| 磁吸背板 | 基础套餐随机赠送，已预装在主机背面 |
| 35mm 导轨卡扣 | 需自行购买或搭配套餐选购，用于 35mm 导轨（C45）固定 |
| PoE 供电模块 | 需自行购买，将 PoE 供电与网络隔离后为设备供电 |

> 配件用途与安装方式 → [拓展配件](extensibility.md)。
