## 指示灯

FlexKVM 上有三个指示灯，分别反映供电、连接和网络状态。详细状态含义见 [LED 指示灯](../interaction/led.md)。

| 编号 | 名称 | 颜色 | 基本说明 |
|:----:|:----:|:----:|----------|
| [1] | 🔴 警告灯 | 红色 | 反映网络和系统状态 |
| [2] | 🟢 状态灯 | 绿色 | 反映设备连接状态 |
| [9] | 🔴 电源灯 | 红色 | 亮 = 已供电，灭 = 未供电 |

## 按键操作

FlexKVM 上有四个物理按键，详细操作见[物理按键](../interaction/button.md)。

| 编号 | 名称 | 基本功能 |
|:----:|:----:|----------|
| [3] | 按键 A | 长按 1~3 秒进入热点配网模式 |
| [4] | 按键 B | 长按 3~5 秒切换 WiFi 与 AP 模式 |
| [11] | 恢复出厂按键 | 长按 15 秒恢复出厂设置 |
| [12] | 复位按键 | 短按强制重启系统 |

## HDMI 输入

- **规格**：标准 HDMI Type-A 接口，兼容 HDMI 1.4。
- **功能**：接收受控主机的 HDMI 视频信号，最高支持 1920x1200@60fps 输入。

## ATX 接口

- **规格**：USB Type-C 接口。
- **功能**：连接 ATX 控制器，远程控制目标设备的电源开关、强制重启与正常开关机。

## USB 接口

- **规格**：USB Type-C 接口，USB 2.0 数据通信/OTG。
- **功能**：与目标主机建立键鼠控制和数据传输通道。

## USB 供电开关

- **规格**：拨动开关。
- **功能**：控制 USB Data 接口的电源输入。拨到 **ON** 时，允许通过 USB Data 接口为整机供电；拨到 **OFF** 时，关闭该接口的电源输入。

## TF 卡槽

- **规格**：Micro SD（TF）卡槽。
- **功能**：用于虚拟 U 盘挂载 ISO 镜像及本地存储扩展。

## 拓展接口

- **规格**：5pin 2.54mm 排针。
- **功能**：提供 UART 串口通信与 GPIO 控制，引脚旁印有对应字母标识。

> **注意**：接口电平为 3.3V，请勿连接 5V 电平信号，否则可能损坏设备。

| 外壳标注 | 详细名称 | 功能介绍   |
| ---------- | ---------- | ------------ |
| T        | UART TXD   | 串口数据发送端 |
| R        | UART RXD   | 串口数据接收端 |
| G        | GND      | 地  |
| A        | GPIOA    | 通用输入输出 |
| B        | GPIOB    | 通用输入输出 |

## 显示屏

- **规格**：单色 OLED 显示屏，分辨率 128x64。
- **功能**：显示设备网络状态、IP 地址、AP 配网信息及当前工作模式。详见 [OLED 屏幕](../interaction/oled.md)。

## 电源接口

- **规格**：USB Type-C 接口。
- **功能**：5V/1A 及以上输入，为设备供电。

## 百兆网口

- **规格**：RJ-45 接口，10/100M 自适应以太网。
- **功能**：有线网络接入。

## WiFi 天线

- **规格**：SMA 内针接口，双频 2.4GHz / 5GHz。
- **功能**：连接外置 WiFi 天线，实现无线网络接入。
