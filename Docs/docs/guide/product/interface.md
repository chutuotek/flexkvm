## 指示灯

### 电源灯

🔴 红色指示灯。常亮表示设备已接通电源。

### 警告灯

🔴 红色指示灯，反映网络和系统状态：

| 状态 | 含义说明                                                                  |
| ------ | --------------------------------------------------------------------------- |
| 常灭 | 系统运行正常，无异常告警                                                  |
| 慢闪 | 网络已断开（WiFi 与以太网均不可用），或设备处于 AP 配网模式               |
| 快闪 | 正在进行 OTA 固件升级，请勿断电                                           |
| 常亮 | 系统发生严重错误（程序异常退出、内核 panic 等），请检查设备或联系技术支持 |

> 慢闪频率约为 1 次/秒，快闪频率约为 4 次/秒。

### 状态灯

🟢 绿色指示灯，反映设备连接状态：

| 状态 | 含义说明                                          |
| ------ | --------------------------------------------------- |
| 常亮 | 设备正常运行，HDMI 视频信号已锁定                 |
| 慢闪 | HDMI 输入信号丢失，请检查 HDMI 线缆及前端设备连接 |
| 快闪 | USB 数据通道未连接，请检查 USB 数据线             |
| 常灭 | 系统没有正常启动                                  |

> 慢闪频率约为 1 次/秒，快闪频率约为 4 次/秒。

**组合状态**：设备执行出厂恢复时，🟢 状态灯与 🔴 警告灯同时快闪。

## 按键操作

**按键 A**

| 操作 | 功能 |
| ------ | ------ |
| 长按 3 ~ 6 秒 | 显示 AP 热点图标，松开后进入热点配网模式 |
| 长按 6 秒以上 | 返回主界面 |

**按键 B**

| 操作 | 功能 |
| ------ | ------ |
| 长按 3 秒 | 在 WiFi 模式与 AP 模式之间切换 |

**恢复出厂按键**

| 操作 | 功能 |
| ------ | ------ |
| 长按 15 秒 | 设备恢复出厂设置 |

**复位按键**

| 操作 | 功能 |
| ------ | ------ |
| 短按 | 强制重启系统 |

## HDMI 输入

- **规格**：标准 HDMI Type-A 接口，兼容 HDMI 1.4。
- **功能**：接收受控主机的 HDMI 视频信号，最高支持 1920x1200@60fps 输入。

## ATX 接口

- **规格**：USB Type-C 接口。
- **功能**：连接 ATX 控制器，远程控制目标设备的电源开关、强制重启与正常开关机。

## USB 接口

- **规格**：USB Type-C 接口，USB 2.0 数据通信/OTG。
- **功能**：与目标主机建立键鼠控制和数据传输通道。

## USB 供电开关

- **规格**：拨动开关。
- **功能**：控制 USB Data 接口的电源输入。拨到 **ON** 时，允许通过 USB Data 接口为整机供电；拨到 **OFF** 时，关闭该接口的电源输入。

## TF 卡槽

- **规格**：Micro SD（TF）卡槽。
- **功能**：支持最高 512GB 存储卡，用于虚拟 U 盘挂载 ISO 镜像及本地存储扩展。

## 拓展接口

- **规格**：5pin 2.54mm 排针。
- **功能**：提供 UART 串口通信与 GPIO 控制，引脚旁印有对应字母标识。

> **注意**：接口电平为 3.3V，请勿连接 5V 电平信号，否则可能损坏设备。

**UART 接口**

| 外壳标注 | 详细名称 | 功能介绍   |
| ---------- | ---------- | ------------ |
| T        | TXD      | 数据发送端 |
| R        | RXD      | 数据接收端 |
| G        | GND      | 信号地线   |

接线时请将 FlexKVM 的 TXD 连接至目标设备的 RXD，RXD 连接至目标设备的 TXD，GND 互连。

**GPIO 接口**

| 外壳标注 | 详细名称 | 功能介绍     |
| ---------- | ---------- | -------------- |
| A        | GPIOA    | 通用输入输出 |
| B        | GPIOB    | 通用输入输出 |

支持输入/输出模式切换。

## 显示屏

- **规格**：单色 OLED 显示屏，分辨率 128x64。
- **功能**：显示设备网络状态、IP 地址、AP 配网信息及当前工作模式。

## 电源接口

- **规格**：USB Type-C 接口。
- **功能**：5V/1A 及以上输入，为设备供电。

## 百兆网口

- **规格**：RJ-45 接口，10/100M 自适应以太网。
- **功能**：有线网络接入。

## WiFi 天线

- **规格**：SMA 内针接口，双频 2.4GHz / 5GHz。
- **功能**：连接外置 WiFi 天线，实现无线网络接入。
