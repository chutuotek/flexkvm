# 拓展

## PoE 供电拓展

> FlexKVM 支持百兆网口及使用 5V 进行供电（Type-C），原生不支持 PoE 供电。

用户可以购买 PoE 供电模块（将 PoE 和网络进行隔离）进行拓展，实现 PoE 供电。

## 背板拓展

FlexKVM 的背板设计为可拓展的，背板和 FlexKVM 主体之间是通过螺丝进行固定，支持多种背板类型，包括但不限于：

- 磁吸背板
- 35mm 导轨卡扣

> 用户也可以根据自己的需求，DIY 设计自己的背板，以满足特定的使用场景。

螺孔尺寸为 m3.5mm,建议使用 M3.5x4mm的螺丝进行固定，不然会损害到 FlexKVM 的 PCB 板。

### 磁吸背板

> 磁吸背板为基础套餐免费赠送的。

![磁吸背板](./images/magnet.webp)

磁吸背板的主体部分为 3D 打印件，四颗 N52 磁铁，安装了磁吸背板的 FlexKVM 可以磁吸在各种金属表面，如铁皮、金属机箱等，实现快速固定，方便携带。

### 35mm 导轨卡扣

> 该配件需要用户自行购买或者搭配套餐进行购买。

![35mm导轨卡扣](./images/35mm.webp)

35mm 导轨卡扣可以卡在 35mm 导轨上（C45）。
