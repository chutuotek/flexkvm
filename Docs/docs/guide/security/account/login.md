# 登录

FlexKVM 用 HTTPS 保护登录。首次访问创建管理员账户，之后用账户密码登录。

## 首次登录（创建账户）

### 访问设备

浏览器输入 `https://设备IP`（OLED 上显示的 IP，如 `https://192.168.1.100`）。自签名证书会导致浏览器提示"不安全"——正常现象，按下面操作跳过：

| 浏览器 | 操作 |
|--------|------|
| Chrome | 点"高级" → "继续访问（不安全）" |
| Edge | 点"高级" → "继续前往此站点（不安全）" |
| Firefox | 点"高级" → "接受风险并继续" |
| Safari | 点"显示详细信息" → "访问此网站" |

### 创建管理员账户

首次访问显示账户创建界面：

![创建账户](../../../images/flexkvm_register.webp)

| 项目 | 要求 |
|------|------|
| 用户名 | 4-32 位，字母/数字/下划线/点/连字符 |
| 密码 | 8-32 位，可打印字符（不含空格） |

填完点"创建账户" → 自动登录进主界面。

> ⚠️ 账户信息存在设备本地，忘记密码无法找回——只能[恢复出厂设置](../../maintenance/factory-reset.md)重新创建。

## 登录已有账户

已创建过账户时显示登录界面：

![登录界面](../../../images/flexkvm_login.webp)

输入用户名和密码 → 点登录。

### 开了 2FA？

需要额外输入 6 位动态验证码。打开手机验证器 → 找到 FlexKVM 条目 → 输入验证码。验证码每 30 秒更新一次，过期就等新的。

设备时间偏差较大时（如设备掉电后 RTC 错乱），登录后自动弹出校准提示，按提示校准设备时间后验证码即可通过。

### 登录失败

| 问题 | 怎么办 |
|------|--------|
| 用户名或密码错 | 检查大小写、多余空格 |
| 2FA 验证码错 | 确认时间同步，等新验证码 |
| 账户被锁定 | 连续多次失败后临时锁定，等几分钟重试 |

## 多端登录与抢占

FlexKVM 同一时刻只允许一个用户在线。已有用户在线时，新设备登录会提示：

| 场景 | 提示与行为 |
|------|-----------|
| 已有用户在线，尝试登录 | 弹窗"当前已有 **{{用户名}}** 用户登录，是否进行登录？"——点**确认**抢占登录（在线用户被踢下线）；点**取消**返回登录页；30 秒无操作自动取消 |
| 被他人抢占（被踢） | 弹窗"你已被踢出，请重新登录"（含踢人者用户名），需重新登录 |
| 同一账户在其他标签页刷新 | 当前标签页暂停重连，回到该标签页后自动恢复 |

## 退出登录

点右上角用户名 → "退出登录"。服务端会吊销该账户的全部登录凭证（其他已登录设备也立即失效），旧凭证无法复用。退出后远程画面不断，但再操作需要重新登录。
