# ATX 电源控制

接好 ATX 控制器后，你就能远程控制被控主机的电源——开机、关机、强制断电、重启，就像亲手按机箱上的按钮。

---

## 开始之前

| 物品 | 说明 |
|------|------|
| FlexKVM | 已完成[快速开始](../../quick_start/index.md)接线和配网 |
| ATX 控制器 | 包装内，带排线 |
| ATX 杜邦线 | 包装内，10 根 |
| USB Type-C 数据线 | 包装内，连 FlexKVM 用 |
| 十字螺丝刀 | 拆机箱用 |

## 硬件接线

### 引脚定义

ATX 控制器排线上每根线都有标签，对照接到主板：

| ATX 控制器 | 主板插针 | 说明 |
|:-----------|:---------|:-----|
| PWR SW ×2 | POWER SW ×2 | 电源开关，不分正负 |
| RST SW ×2 | RESET SW ×2 | 复位开关，不分正负 |
| PWR LED+ | POWER LED+ | 电源指示灯正极 |
| PWR LED- | POWER LED- | 电源指示灯负极 |
| HDD LED+ | HDD LED+ | 磁盘指示灯正极 |
| HDD LED- | HDD LED- | 磁盘指示灯负极 |

> 电源和复位开关不分正负，互换也行。指示灯要分正负，接反了不亮。

### 找到主板插针

打开机箱，找到前置面板插针区——就是机箱电源键和重启键背后那排针脚。通常位于主板右下角，标识为 `JFP1`、`F_PANEL` 或 `PANEL`。

> 不确定？翻主板说明书"前置面板接口"章节，或搜主板型号 + `front panel pinout`。

![10-1 面板插针](./images/atx/atx_panel.webp)

### 接线原理

ATX 控制器排线每根线有两个接口——**公口**（插针）接机箱面板线，**母口**（带孔）接主板插针或杜邦线公端。控制器串在机箱面板和主板之间，既能透传物理按键信号，也能由 FlexKVM 远程触发。

### 接线步骤

> ⚠️ 接线前确保 ATX 控制器和主板都已断电。

**第一步：连机箱面板线到 ATX 控制器**

1. 从主板上拔下机箱面板连接线（母口从主板公针上拔下）
2. 对照[引脚定义表](#引脚定义)，将机箱面板线的母口插到 ATX 控制器排线对应标签的**公口**上

**第二步：连 ATX 控制器到主板**（二选一）

**方法一：直接连接（推荐）**——ATX 排线母口能直插主板时用。对准插入，有防呆设计，方向不对插不进去。

**方法二：用杜邦线**——母口形状不匹配时用。杜邦线母端插主板插针，公端插 ATX 排线母口。不分正负，插牢就行。

> 两种方法效果相同。接好后 ATX 控制器已串入电路。

### 连到 FlexKVM

用 USB Type-C 数据线把 ATX 控制器连到 FlexKVM 的 **ATX 接口**。

![atx](./images/atx/atx_connected.webp)

> **验证**：ATX 控制器电源灯亮起，OLED 上 ATX 图标从"未连接"变为"已连接"。

### 拓展安装（可选）

可选配件把 ATX 控制器固定在机箱内部：全高 USB 挡板 + USB 转接线。挡板装 PCI 位 → 转接线一端连挡板内侧 → 另一端连 ATX 控制器 → FlexKVM 从外部连挡板。

## 软件配置

顶栏点**外设**图标。

![外设菜单](./images/atx/atx.webp)

| 图标 | 含义 |
|:----:|------|
| ![](../icon/interface/unplug.svg) | 未连接或未启用 |
| ![](../icon/interface/power.svg) | ATX 已连接，主机已开机 |
| ![](../icon/interface/power-off.svg) | ATX 已连接，主机关机 |

### 启用

1. 顶栏点外设图标
2. 面板右上角开开关
3. 正常连接会显示设备名 `atx`

### 状态指示灯

面板顶部两个灯，信号直连主板：

| 指示灯 | 含义 |
|:------|------|
| 🟢 电源灯 | 主机正在运行 |
| 🟡 硬盘灯闪烁 | 硬盘读写中 |

### 电源控制

| 你要做什么 | 操作 |
|-----------|------|
| 开机 | 点电源键 → **短按** |
| 正常关机 | 点电源键 → **短按**（操作系统响应） |
| 强制关机 | 点电源键 → **长按**约 4 秒 |
| 重启 | 点复位键 |

> ⚠️ 强制关机和复位可能导致数据丢失。系统有响应时优先短按正常关机。

长按时长可调：点电源键旁展开箭头 → "长按关机"滑块（1s~10s）。

![展开后的设置界面](./images/atx/atx_setting.webp)

## 常见问题

**点开机没反应？** → 检查杜邦线是否接牢、主板插针位置对不对。外设面板设备名是否显示 `atx`。

**关机后马上开机了？** → BIOS 里开了"断电后自动开机"（Restore on AC Power Loss）。进 BIOS 关掉。

**ATX 不识别？** → 重插 Type-C 排线，确认 OLED 上 ATX 图标出现。不行就换个 USB 口。
