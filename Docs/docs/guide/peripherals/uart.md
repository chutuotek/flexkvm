# UART 串口终端

通过串口与被控设备（路由器、嵌入式开发板、交换机）进行命令行交互。

> 面向嵌入式调试、工业控制等专业场景。普通用户通常不需要。

## 开始之前

| 你需要 | 说明 |
|--------|------|
| FlexKVM | 已完成[快速开始](../../quick_start/index.md)接线和配网 |
| 2.54mm 杜邦线（母口） | 至少 3 根 |
| 被控设备 | 支持串口通信，参数（波特率等）需提前确认 |

## 引脚说明

FlexKVM 的 UART 接口为 3 pin 排针，引脚旁有字母标识：

![IO UART](images/product_io.webp)

| 丝印 | 引脚 | 说明 |
|:---:|:---|------|
| T | TXD | 数据发送 → 接被控设备 **RX** |
| R | RXD | 数据接收 → 接被控设备 **TX** |
| G | GND | 地线，与被控设备共地 |

> UART 交叉连接：FlexKVM 的 TXD 接待控设备 RXD，RXD 接待控设备 TXD，GND 互连。只接这三根就够了。

## 接线

```
FlexKVM                 被控设备
  TXD ───────────────→ RXD
  RXD ←─────────────── TXD
  GND ──────────────── GND
```

## 软件配置

顶栏点芯片图标 → IO 菜单 → **UART 串口终端**。

![UART 界面](images/io_uart.webp)

### 通信参数

启用 UART 后设置参数。**参数必须和被控设备完全一致**，否则乱码或不通：

| 参数 | 默认值 | 常见值 |
|------|:---:|------|
| 波特率 | 115200 | 9600、19200、38400、57600、115200 |
| 数据位 | 8 | 5/6/7/8 |
| 停止位 | 1 | 1/2 |
| 校验位 | 无 | 无/奇校验/偶校验 |

> 默认 **115200 8N1** 是串口设备最常用的配置。

### 启动与断开

设好参数 → 点启动 → 打开终端窗口，可直接与设备交互。

![UART 终端窗口](images/io_uart_term.webp)

终端布局：左上显示当前串口配置（如 `115200 8N1`），波特率旁指示灯（🟢 已连接 / 🔴 断开），右上有导出日志/清屏/断开按钮。

### 终端打开方式

| 方式 | 说明 |
|------|------|
| 悬浮窗 | 嵌在主界面的浮层，随页面操作一起看；点"在新窗口打开"可转独立标签页 |
| 新页面 | 独立标签页（`/terminal`）整页显示终端，适合副屏/长时间驻留监控 |

"启动方式"记住上次的选择，下次按同样方式打开。浏览器拦截新窗口时，手动访问 `/terminal` 即可。

> 串口同一时间只能被一个窗口使用。串口被其他窗口占用时，原窗口点"断开"即可释放；占用状态下提示"串口被其他窗口占用，等待释放…"。

> 连接期间不能改参数。需要改就先断开。

### 断线提示

断开时终端提示具体原因，不再只是"连接中断"：

| 提示 | 含义 | 处理 |
|------|------|------|
| 串口被其他窗口占用，等待释放… | 串口被另一个标签页占用 | 在占用窗口点断开，或关闭它 |
| 串口未启用，请先在主界面开启 | UART 没启动 | 回主界面 IO 菜单启动 |
| 主会话已断开，等待重新连接… | 主连接闪断 | 自动重连，稍候即可 |
| 会话已被其他登录替换 | 同一账号在别处登录 | 重新登录 |
| 串口已断开 / 串口打开失败 | 设备端异常或参数被占用 | 检查接线与参数后重新启动 |

> 网络瞬断自动重连；连续重连失败才停止并提示，避免无意义刷屏。

## 常见问题

**终端乱码？** → 参数和被控设备不一致，最常见是波特率不匹配。核对设备参数重配。

**连不上？** → 确认被控设备串口已启用、接线正确（TXD→RXD、RXD←TXD、GND 互连）。

**输入命令没反应？** → 确认被控设备处于可接收命令状态。部分设备只在特定阶段响应串口。
