# GPIO 引脚控制

FlexKVM 提供两个独立 GPIO 引脚，可连接开关、传感器、继电器等外部硬件——输入检测或输出控制。

> ⚠️ 引脚电平为 **3.3V**，别接 5V 或更高电压设备，否则会损坏设备。

> 面向工业控制、自定义硬件集成等专业场景。普通用户通常不需要。

## 开始之前

| 你需要 | 说明 |
|--------|------|
| FlexKVM | 已完成[快速开始](../../quick_start/index.md)接线和配网 |
| 2.54mm 杜邦线（母口） | 连接 GPIO 引脚 |
| 外部设备 | 开关、传感器、继电器等，需支持 **3.3V** 逻辑电平 |

## 引脚说明

两个独立 GPIO，引脚旁有字母标识：

![IO GPIO](images/product_io.webp)

| 丝印 | 引脚 | 说明 |
|:---:|:---|------|
| G | GND | 地线，与外部设备共地 |
| A | GPIOA | 通用输入输出，可独立配置 |
| B | GPIOB | 通用输入输出，可独立配置 |

## 接线示例

### 读取开关信号（输入模式）

```
GPIOA ──┬── 按钮一端
        │
GND ────┴── 按钮另一端
```

按钮按下 → GPIOA 低电平；松开 → 高电平（内部默认上拉）。

### 控制 LED（输出模式）

```
GPIOB ────→ 限流电阻 ────→ LED 正极（长脚）
GND ────────────────────→ LED 负极（短脚）
```

> LED 需串一个 **220Ω ~ 1kΩ** 限流电阻，否则可能烧 LED 或 GPIO。

## 软件配置

顶栏点芯片图标 → IO 菜单 → **GPIO 引脚控制**。

![GPIO 界面](images/io.webp)

所有引脚默认**禁用**（输入模式、不监听）。需要手动启用。

### 启用引脚

![GPIO 启用](images/io_gpio.webp)

每个引脚卡片上有开关。开启后进入输入模式并开始监听电平。

### 输入模式

引脚电平由外部设备决定，界面实时反映：

- 🟢 绿色 = 高电平（3.3V）
- ⚫ 灰色 = 低电平（0V）

> 输入模式下**不能**手动设电平。外部变化界面自动更新。

### 输出模式

点模式切换按钮 → 通过"高"/"低"按钮手动控制：

- 高 → 引脚输出 3.3V
- 低 → 引脚输出 0V

> 需要读外部信号时切换回输入模式。

---

## 常见问题

**输出没电压？** → 确认引脚已启用且模式为"输出"。启用但没切模式时仍在输入状态。

**读到错误电平？** → 检查接线，确认和设备**共地**（GND 已连）。

**接线后界面不变？** → 确保引脚已开启。禁用状态不监听电平变化。
