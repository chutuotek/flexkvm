# 热点配网

热点配网（Provisioning）用于快速配置 FlexKVM 的网络连接。设备在首次启动或无可用网络时会自动进入配网模式，用户通过手机或电脑连接设备热点完成网络设置。

![配网页面](./images/ap_province/web-provision-page.webp)

## 进入配网模式

设备在以下情况会自动进入配网模式：

- 首次启动且没有配置任何 WiFi 网络
- 已保存的 WiFi 网络全部连接失败
- 手动触发配网模式

进入配网模式后，设备的 OLED 屏幕会显示配网信息。

## 连接配网热点

配网模式会创建一个临时 WiFi 热点：

| 参数 | 说明 |
|:---:|------|
| SSID | flexkvm-conf |
| 频段 | 2.4GHz |
| 密码 | 随机生成的 8 位数字 |
| 未连接超时 | 3 分钟 |
| 已连接超时 | 5 分钟（有设备连接后自动延长） |

> 提示：配网密码为随机生成，请查看设备 OLED 屏幕获取密码。

## 配置网络

连接 `flexkvm-conf` 热点后，浏览器会自动跳转到配网页面。配网页面包含以下设置模块：

| 模块 | 说明 |
|------|------|
| 有线网络 | 配置以太网的 DHCP/静态 IP |
| AP 网络 | 配置热点模式的 SSID、密码、加密、频段等 |
| WiFi 网络 | 扫描并连接周围的 WiFi 网络 |

配置完成后点击"保存"按钮，设备会：

1. 保存所有网络配置
2. 关闭配网热点
3. 应用用户配置的网络设置
4. 自动连接到已配置的网络

![配网保存](./images/ap_province/web-provision-save.webp)

> 提示：保存成功后设备会自动退出配网模式并恢复正常运行。如果配置的网络无法连接，设备会再次进入配网模式。
