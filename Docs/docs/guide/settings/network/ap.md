# 热点模式

FlexKVM 可以创建 WiFi 热点（AP），供其他设备连接。热点模式常用于没有路由器的情况下直接访问设备管理界面。

进入"设置" → "网络"，可以看到 AP 网络设置区块，如下图所示：

![AP 设置](./images/ap/web-ap-setting.webp)

## 启用/禁用

点击卡片右侧的开关可以启用或禁用热点。

| 参数 | 说明 |
|:---:|------|
| 默认状态 | 关闭 |
| 接口名称 | ap0 |
| 默认 SSID | FlexKVM-AP |
| 默认密码 | 12345678 |

> 提示：启用热点后，其他设备可以搜索并连接到该 WiFi 热点，通过热点分配的 IP 地址访问 FlexKVM 管理界面。

## AP 配置

点击卡片左侧的齿轮图标打开配置弹窗：

![AP 配置](./images/ap/web-ap-modal.webp)

| 配置项 | 说明 | 默认值 | 可选值 |
|------|------|:---:|------|
| SSID | WiFi 热点名称 | FlexKVM-AP | 自定义字符串 |
| 密码 | WiFi 热点密码 | 12345678 | 8~63 位字符 |
| 加密方式 | 无线安全协议 | WPA_WPA2 | WPA / WPA2 / WPA3 / 开放 |
| 频段 | 工作频率 | 2.4GHz | 2.4GHz / 5GHz |
| WiFi 6 | 启用 802.11ax | 关闭 | 开启 / 关闭 |
| 信道 | 无线信道 | 自动 | 2.4G: 0~11, 5G: 36~165 |
| 最大客户端数 | 同时连接的设备上限 | 2 | 1 ~ 64 |

> 提示：如果设备硬件不支持 WiFi 6 或 5GHz，相关选项设置后将以实际硬件能力为准。

## 连接状态

启用热点后，卡片上会显示：

- 热点 SSID 名称
- 当前频段标签（2.4G / 5G）
- 已连接客户端数和最大客户端数

例如 `1/2` 表示当前有 1 台设备连接，最多允许 2 台设备同时连接。
