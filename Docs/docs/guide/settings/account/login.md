# 登录

FlexKVM 使用 HTTPS 协议保护登录安全，首次访问时需要创建管理员账户，后续访问使用账户密码登录。

## 首次登录（创建账户）

首次访问 FlexKVM 时，系统会要求创建管理员账户。

### 访问设备

在浏览器地址栏输入 `https://设备IP`（即 OLED 上显示的 IP 地址，例如 `https://192.168.1.100`）。

由于 FlexKVM 使用自签名 SSL 证书，浏览器会提示"不安全"或"证书无效"，这是正常现象。请按以下步骤继续访问：

| 浏览器 | 操作步骤 |
|--------|----------|
| Chrome | 点击"高级" → "继续访问（不安全）" |
| Edge | 点击"高级" → "继续前往此站点（不安全）" |
| Firefox | 点击"高级" → "接受风险并继续" |
| Safari | 点击"显示详细信息" → "访问此网站" |

### 创建管理员账户

首次访问会显示账户创建界面：

![创建账户](../../../images/flexkvm_create_account.webp)

| 项目 | 要求 | 示例 |
|------|------|------|
| 用户名 | 4-32 位，支持字母、数字、下划线、点、连字符 | `admin` |
| 密码 | 8-32 位，可打印字符（不含空格） | `MyP@ssw0rd` |

填写完成后点击"创建账户"，系统自动登录并进入主界面。

> 注意：账户信息存储在设备本地，忘记密码后无法找回，需要恢复出厂设置重新创建。

## 登录已有账户

如果已经创建过账户，访问设备时会显示登录界面：

![登录界面](../../../images/flexkvm_login.webp)

输入用户名和密码后点击"登录"即可进入主界面。

### 两步验证（2FA）

如果账户开启了双因素认证（2FA），登录时需要额外输入 6 位动态验证码：

1. 打开手机上的验证器应用（如 Google Authenticator、Microsoft Authenticator）
2. 找到 FlexKVM 对应的条目
3. 输入显示的 6 位验证码

> 提示：验证码每 30 秒更新一次，请在倒计时结束前完成输入。如果验证码过期，请等待新的验证码。

### 登录失败

如果登录失败，请检查：

| 问题 | 解决方法 |
|------|----------|
| 用户名或密码错误 | 检查大小写是否正确，是否有多余空格 |
| 2FA 验证码错误 | 确认设备时间同步正确，等待新验证码 |
| 账户被锁定 | 连续多次登录失败后账户会临时锁定，请等待几分钟后重试 |

## 退出登录

点击主界面右上角的用户名，选择"退出登录"即可退出当前账户。

> 提示：退出登录不会断开远程画面连接，但再次操作需要重新登录。
