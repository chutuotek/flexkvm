# 录像设置

设置录像的默认参数。录像功能的使用方法见 [录像](../../toolbar/record.md)。

进入 **设置 → 系统**，找到录像设置区块。

## 静音录制

开启后录制的视频不包含音频。

## 视频格式

| 格式 | 适用场景 |
|------|----------|
| WebM (VP9+Opus) | 默认格式，画质好 |
| WebM (VP8+Opus) | 兼容旧设备 |
| MP4 (H.264) | 兼容性最好，大多数播放器可播放 |

## 视频画质

| 选项 | 码率 | 适用场景 |
|------|------|----------|
| 低 | 1 Mbps | 文件尽量小 |
| 中 | 2 Mbps | 日常录制 |
| 高 | 4 Mbps | 画面细节多 |
| 极高 | 8 Mbps | 需要最佳画质 |
