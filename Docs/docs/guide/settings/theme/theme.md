# 语言与主题

进入"设置" → "外观"，可切换语言和主题。

## 语言

![语言设置](./images/setting_language.webp)

FlexKVM 支持多种语言，可通过下拉框切换：

- 简体中文
- 英文

## 主题

![主题设置](./images/setting_theme.webp)

FlexKVM 支持三种主题：

| 主题 | 说明 |
|------|------|
| 深色主题 | 深色背景搭配浅色文字，降低视觉疲劳，适合暗光环境 |
| 浅色主题 | 浅色背景搭配深色文字，清晰明亮，适合亮光环境 |
| 自动（默认） | 根据系统设置自动切换深色和浅色主题 |

## 强调色

强调色应用于按钮、链接、选中项等元素，默认为蓝色。点击颜色块即可切换。

可选颜色：

- 蓝色
- 青色
- 亮绿色
- 橙黄色
- 橙色
- 红色
- 品红色
- 紫色
- 灰色
