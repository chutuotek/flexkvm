# 重启与重置

进入"设置" → "维护"：

![维护界面](./images/maintenance_ui.webp)

重启与重置在第三个组中，包含两个卡片：

- 重启设备
- 恢复出厂设置

## 重启设备

点击"重启设备"卡片，弹出确认对话框：

![重启设备](./images/reboot.webp)

确认后设备重启，约 20~30 秒后恢复。

## 恢复出厂设置

点击"恢复出厂设置"卡片，弹出确认验证框：

![恢复出厂设置](./images/refactor.webp)

输入密码（如已开启 2FA，需输入验证码），点击"确定"，设备恢复出厂设置。

> 恢复出厂设置会删除设备上的所有数据，包括用户名、密码、2FA 密钥、设备配置等，请谨慎操作。

### 设备端

恢复出厂设置过程中，OLED 显示恢复出厂图标，红色和绿色指示灯同时快速闪烁。
