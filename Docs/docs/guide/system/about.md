# 关于设备

查看设备信息、固件版本和社区资源。

进设置 → 关于。

![关于](./images/about/setting_about.webp)

## 设备信息

| 信息项 | 说明 |
|:-----|------|
| 型号 | 如 `FlexKVM` |
| 系统版本 | 当前固件版本，如 `v0.1.2`。升级 → [固件升级](../maintenance/upgrade-online.md) |
| 序列号 (SN) | 唯一标识，联系技术支持时需提供 |

> 序列号可在包装盒或设置 → 关于页面查看。也可在 OLED 主界面短按按键 A 切换到系统信息子页面查看。

## 社区与联系

| 资源 | 说明 | 链接 |
|:----|------|:----:|
| GitHub | 开源仓库 | [github.com/chutuotek/flexkvm](https://github.com/chutuotek/flexkvm) |

| 本地文档 | 设备内置文档（无需联网） | `/docs/` |

> 遇到问题先看[常见问题](../../support/index.md)或在线文档，没解决再联系技术支持并提供序列号。
