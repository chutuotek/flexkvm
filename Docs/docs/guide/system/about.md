# 关于设备

查看设备信息、固件版本和社区资源。

> 入口：设置 → 关于

![关于](./images/about/setting_about.webp)

## 设备信息

| 信息项 | 说明 |
|:-----|------|
| 产品名称 | 固定为 `FlexKVM` |
| 主机名 | 由设备序列号生成，形如 `flexkvm-6jzdd`；也是 [mDNS 服务发现](../network/mdns.md)里访问用的名字 |
| 系统版本 | 当前固件版本，如 `v0.2.0`。升级 → [在线升级](../maintenance/upgrade-online.md) |
| 设备序列号 | 唯一标识，联系技术支持时需提供 |

> 序列号可在包装盒或设置 → 关于页面查看。也可在 OLED 主界面**短按两次按键 A** 切到系统信息子页面（第一次短按先进 HDMI 信息）。
