# 设备屏幕控制

FlexKVM 设备本身带有一块 OLED 屏幕，用于显示设备状态信息。进入"设置" → "高级功能"，可以看到 OLED 设置区块，如下图所示：

![OLED 设置](./images/time_oled_edid_ui.webp)

## 亮度

亮度使用滑块进行调节，拖动滑块即可实时调整屏幕亮度。

| 参数 | 说明 |
|:---:|------|
| 调节范围 | 1 ~ 10 档 |
| 默认值 | 5 |
| 生效方式 | 实时生效 |

> 提示：亮度档位越高屏幕越亮，同时也越耗电。建议根据使用环境选择合适亮度。

## 休眠时间

休眠时间指 OLED 屏幕在无操作后自动关闭的时间。到达设定的时间后，屏幕会自动息屏以节省功耗和延长屏幕寿命。

| 参数 | 说明 |
|:---:|------|
| 可选值 | 10s / 30s / 60s / 120s / 300s / 600s |
| 默认值 | 60s |
| 生效方式 | 实时生效 |

> 提示：休眠时间设置为 60s 表示屏幕在 60 秒无操作后自动关闭。

## 唤醒屏幕

屏幕息屏后，可以通过以下方式唤醒：

- **按设备按键**：按下 FlexKVM 设备上的物理按键，屏幕会立即亮起
- **休眠时间变更**：修改休眠时间设置后，屏幕会自动唤醒

> 注意：在配网模式或蓝牙配对模式下，屏幕不会自动息屏，以确保操作过程不受影响。
