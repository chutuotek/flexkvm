# 状态监控

实时查看设备运行状态——温度、CPU、内存、网络速率与运行时长，支持按日期回看历史曲线并导出 CSV。排查设备卡顿、网络瓶颈、异常重启时用。

进设置 → **状态**。

!!! note "截图占位"

    待补充：设置 → 状态页面截图（`images/status/setting_status.webp`）。

## 监控指标

| 指标 | 说明 |
|------|------|
| 温度 | SoC 温度（℃） |
| CPU | CPU 占用率（%） |
| 内存 | 内存占用（%） |
| 网络速率 | 下行 / 上行速率（B/s~MB/s 自动换算） |
| 应用运行时间 | FlexKVM 主程序运行时长 |
| 系统运行时间 | 设备开机时长 |

## 当前与历史

页面顶部切换 **当前** / **历史**：

- **当前**：显示最新数值与最近 10 分钟曲线，每 5 秒自动刷新。
- **历史**：选择日期，回看当天每项指标的完整曲线（历史数据按分钟记录）。

!!! tip

    设备重启后"应用运行时间"归零，但历史监控数据保留——结合时间点可排查"什么时候重启的、当时温度/CPU 是否异常"。

## 导出数据

历史视图 → 点**导出数据**：

| 选项 | 说明 |
|------|------|
| 下载这一天 | 导出所选日期的监控数据（`sys_monitor_<日期>.csv`） |
| 下载全部 | 打包全部历史数据下载（`sys_monitor_all.tar.gz` 压缩包，里面是每天的 CSV 文件） |

单日 CSV 是文本表格，可直接用 Excel / WPS 打开，字段包括：时间戳（timestamp）、温度（temp_c）、内存总量/可用（mem_total_mb / mem_avail_mb）、CPU 占用率（cpu_pct）。网络速率只在页面曲线中展示，不写入 CSV。
