# 时间设置

设好时区，系统时间通过 NTP 自动同步。设备时钟与当前时间偏差较大时，连接后自动提示校准。

进设置 → 系统 → 时间设置。

![时间设置](./images/time/setting_time.webp)

## 设置时区

下拉选时区，支持 UTC-12 ~ UTC+14 所有整点时区。默认 UTC+8（北京时间）。选择后即时生效。

下方显示当前设备时间，每秒刷新：

```
2026/07/01 14:30:00 (UTC+8)
```

## 校准设备时间

设备 RTC 掉电或长时间离线时，时间可能错乱（如落后数年），导致 2FA 验证码校验失败。设备时钟与当前时间偏差超过 60 秒时，连接后弹出校准提示，显示设备当前时间：

- 点"确认"：设备时间校准为当前时间，校准完成自动刷新登录凭证，无需重新登录
- 点"取消"：本次连接不再提示

## NTP 时间源

系统默认使用内置 NTP 服务器自动同步时间。时间设置页可添加自定义时间源：

- 输入主机名或 IP，如 `ntp.aliyun.com`
- 最多添加 5 个，重复输入自动提示
- 添加时可标记"首选"，同步优先使用首选源
- 添加或移除后立即生效
