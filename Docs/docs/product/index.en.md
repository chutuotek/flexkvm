# Product

FlexKVM is a high-performance IP-KVM solution designed for remote server management.

## Features

- Remote KVM control (Keyboard, Video, Mouse)
- Virtual media support
- File transfer
- OTA updates
- WiFi provisioning
- LED status indicators
- ATX power control

## Specifications

| Feature | Description |
|---------|-------------|
| Hardware | RV1106 platform |
| Video | Hardware-accelerated encoding |
| Network | Ethernet, WiFi |
| Power | ATX power control |
