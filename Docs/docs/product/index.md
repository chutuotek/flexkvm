# FlexKVM

**FlexKVM 是一款即插即用的带外管理设备。** 将它接入目标主机的 HDMI、USB 和电源控制接口，你就能通过浏览器或 Tailscale 网络，随时随地查看屏幕、控制键鼠、开关电源、挂载 ISO —— 即使目标系统宕机、无显卡驱动、甚至未安装操作系统。

> 无需在被控主机上安装任何软件，无需公网 IP，只要网络可达，机房就在你手边。

## 核心功能

### 远程桌面控制
通过网络实时查看和控制目标设备的 HDMI 输出，最高支持 **1920x1200@60Hz**。

> **关键差异**：纯硬件捕获，不依赖目标机的操作系统、显卡驱动或远程服务。BIOS、安全模式、蓝屏画面都能看见。

### 远程开关机
通过 ATX 控制接口实现电源远程管理，支持正常开关机、强制重启、强制断电。

### 虚拟 U 盘
将 TF 卡上的 ISO 镜像远程挂载为目标主机的 USB 存储设备，实现无现场人员的系统安装、恢复或 PE 维护。

### 异地组网（Tailscale）
内置 Tailscale 客户端，无需公网 IP、无需配置端口转发，两台设备登录同一账号即可组建加密虚拟网络。

### 双网络冗余
支持 **WiFi 6（2.4GHz/5GHz）** 与 **百兆有线网口**，无线与有线自动切换，保障连接可靠性。

### 串口与 GPIO 扩展
提供 UART 串口通信与 GPIO 控制，满足嵌入式调试、工业自动化、看门狗等扩展需求。

### 灵活安装
兼容磁吸背板与机柜夹两种固定方式，适应桌面、机柜、工业现场等多种环境。

### 低功耗静音
典型功耗仅 **1.5W ~ 2.4W**，铝合金外壳被动散热，无风扇设计，7x24 小时安静运行。

## 谁在使用 FlexKVM

### 企业 IT / 数据中心
服务器宕机后无法远程登录，FlexKVM 让你在办公室就能查看蓝屏信息、进入 BIOS 排查、甚至远程重装系统，省去工程师跑机房的麻烦。

### Homelab 与数码爱好者
NAS、软路由、All-in-One 主机放在角落不接显示器，一出启动故障就要搬电视。FlexKVM 让你随时远程查看画面、调整启动项、重装 PVE/ESXi/TrueNAS。

### 边缘计算与 IoT 运维
基站、无人机房、偏远站点的边缘网关故障，派人上门成本极高。FlexKVM 接入本地网络后即可通过 Tailscale 从总部远程维护，将停机时间从小时级压缩到分钟级。

### 嵌入式与工业自动化
工控机、PLC 上位机封闭在机柜内，现场往往没有显示器和公网。FlexKVM 直接捕获 HDMI 输出，配合 UART 串口实现"看屏+串口"双通道调试，大幅提升产线故障定位效率。

## 它适合你吗

| 检查项 | 说明 |
|--------|------|
| 目标设备有 HDMI 输出 | FlexKVM 通过 HDMI 捕获视频信号，需要目标设备具备 HDMI 接口 |
| 目标设备支持 USB 键鼠 | 远程控制通过 USB 模拟键盘鼠标实现 |
| 目标设备支持 ATX 电源控制（可选） | 如需远程开关机，需连接 ATX 控制器至主板 |
| FlexKVM 与操作端网络可达 | 支持同局域网、Tailscale 虚拟网或有线直连 |
| 操作端有现代浏览器 | 推荐使用 Chrome、Edge、Firefox 等浏览器访问 Web 界面 |

> 如果以上条件都满足，你就可以在 5 分钟内完成部署并开始远程管理。

FlexKVM 尺寸仅 **65 x 46 x 22 mm**，铝合金外壳，主要接口分布在一侧：

- **HDMI IN**：接收被控主机的视频信号（最高 1920x1200@60Hz）
- **USB DATA**：USB 2.0 OTG，连接被控主机实现键鼠控制与数据传输
- **USB PWR**：5V/1A 供电输入，也可通过 USB DATA 供电（受拨动开关控制）
- **ATX 控制**：USB Type-C 接口，连接 ATX 控制器实现远程电源管理
- **TF 卡槽**：Micro SD 卡，用于虚拟 U 盘镜像与本地存储扩展
- **扩展接口**：5pin 2.54mm 排针，提供 UART（TXD/RXD/GND）与 GPIO（GPIOA/GPIOB），电平 3.3V
- **网口**：RJ-45 百兆以太网
- **天线**：SMA 内针双频 WiFi 天线接口
- **显示屏**：128x64 单色 OLED，显示网络状态与 IP 地址

## 常见问题

### FlexKVM 和 IPMI/iDRAC/iLO 有什么区别？
IPMI 等企业带外方案需要主板原生支持，且通常价格昂贵、配置复杂。FlexKVM 是**外接式**带外管理方案，任何具备 HDMI 和 USB 接口的设备都能使用，无需主板支持，即插即用，成本更低。

### 它和向日葵、TeamViewer 等远程软件有什么区别？
远程软件依赖目标机的操作系统正常运行。如果系统蓝屏、未启动、或者没有显卡驱动，远程软件无法工作。FlexKVM 在**硬件层面**捕获视频信号，不依赖目标系统的任何软件状态。

### 是否需要公网 IP？
不需要。FlexKVM 内置 Tailscale，只要设备能访问互联网（无论是否有公网 IP、是否在 NAT 后），就能与另一台加入同一 Tailscale 网络的设备建立安全连接。

### 目标主机需要安装软件或驱动吗？
不需要。FlexKVM 对目标主机来说就是一个标准的 USB 键盘鼠标和 USB 存储设备，即插即用，兼容所有主流操作系统。

### 可以同时控制多台设备吗？
一台 FlexKVM 对应管理一台目标主机。如需管理多台设备，可为每台主机配备一台 FlexKVM，通过同一 Tailscale 网络分别访问。
