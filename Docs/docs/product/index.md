# FlexKVM

FlexKVM 是一款带外管理设备，让管理员通过网络远程控制无头服务器（headless server）的 BIOS、开关机、系统重装等操作，如同坐在机房现场。

## 应用场景

### 系统管理员

服务器宕机后无法通过 SSH 或 RDP 远程登录，需要现场接显示器才能查看蓝屏信息或进入 BIOS 排查。FlexKVM 提供真正的带外管理能力，即使操作系统崩溃，也能远程查看屏幕输出、进入 BIOS 设置、甚至通过虚拟 U 盘重新安装系统，无需工程师赶赴现场。

### Homelab 玩家与数码爱好者

家中的 NAS、软路由、All-in-One 主机通常放在角落且不连接显示器，一旦出现启动故障或需要调整 BIOS，只能搬显示器或电视来排查。FlexKVM 让你随时通过网络查看这些无头设备的画面，远程重装 PVE、ESXi 或 TrueNAS，像坐在机房一样管理家里的所有设备。

### 嵌入式开发工程师

调试工控机、树莓派、边缘网关等没有独立显示器的设备时，遇到内核 panic 或启动异常往往只能通过串口盲猜。FlexKVM 直接捕获设备的 HDMI 输出，让你实时看到启动画面和桌面环境，配合 UART 串口实现"看屏+串口"双通道调试，大幅提升定位效率。

### 工业自动化工程师

工厂产线中的工控机、PLC 上位机通常封闭在机柜内，没有外接显示器，且现场往往没有公网。设备出现系统卡死、软件崩溃时，工程师必须亲自跑到车间处理。FlexKVM 接入本地网络后即可远程查看工控屏幕、重启系统或通过虚拟 U 盘恢复系统，将产线停机时间从小时级压缩到分钟级。

### 边缘计算与 IoT 运维人员

部署在偏远站点、基站、无人机房内的边缘网关和 AI 推理盒子，平时无人值守，一旦故障派遣人员上门的成本极高。FlexKVM 内置 Tailscale 异地组网能力，无需公网 IP 即可建立安全连接，让运维人员在总部就能远程查看设备画面、排查故障、重装系统。

### IT 技术支持与服务商

为客户部署服务器后，后期遇到启动故障、RAID 配置调整或系统重装等问题，传统方式需要工程师携带显示器和键鼠上门，响应慢、成本高。预装 FlexKVM 后，技术支持团队可以远程接入客户设备的 BIOS 层面进行诊断和操作，显著提升服务响应速度与客户满意度。

### 远程办公用户

家里或公司摆放着一台高性能工作站、渲染主机或 AI 训练服务器，平时不连接显示器。出差或居家办公时需要临时访问，普通远程软件无法在系统未启动或显卡未驱动时工作。FlexKVM 在硬件层面捕获视频信号，即使系统处于 BIOS 或安全模式，也能远程操控这台主机。

## 产品特点

- **远程桌面控制**：通过网络实时查看和控制目标设备的 HDMI 输出，最高支持 1920x1200@60Hz。
- **远程开关机**：通过 ATX 控制接口实现电源远程开关，支持强制重启与正常开关机。
- **虚拟 U 盘**：通过 TF 卡远程挂载 ISO 镜像，实现无现场人员的系统安装与恢复。
- **异地组网**：内置 Tailscale，无需公网 IP 即可组建安全虚拟网络，随时随地访问设备。
- **双网络冗余**：支持 WiFi 6 与百兆有线网口，自动保障网络连接可靠性。
- **串口与 GPIO 扩展**：提供 UART 串口通信与 GPIO 控制，满足嵌入式调试与自动化需求。
- **灵活安装**：兼容磁吸背板与机柜夹两种固定方式，适应桌面、机柜、工业现场等多种环境。
- **低功耗运行**：典型功耗仅 1.5W ~ 2.4W，铝合金外壳被动散热，无风扇静音设计。

### 电源指示灯

红点常亮表示设备已接通电源。

### 警告指示灯（红色）

| 指示灯状态 | 含义说明 |
|-----------|---------|
| 常灭 | 系统运行正常，无异常告警 |
| 慢闪 | 网络已断开（WiFi 与以太网均不可用），或设备处于 AP 配网模式 |
| 快闪 | 正在进行 OTA 固件升级，请勿断电 |
| 常亮 | 系统发生严重错误（程序异常退出、内核 panic 等），请检查设备或联系技术支持 |

> 慢闪频率约为 1 次/秒，快闪频率约为 5 次/秒。

### 状态指示灯（绿色）

| 指示灯状态 | 含义说明 |
|-----------|---------|
| 常亮 | 设备正常运行，HDMI 视频信号已锁定 |
| 慢闪 | HDMI 输入信号丢失，请检查 HDMI 线缆及前端设备连接 |
| 快闪 | USB 数据通道未连接，请检查 USB 数据线 |
| 常灭 | 待机状态，视频信号未锁定 |

> 慢闪频率约为 1 次/秒，快闪频率约为 5 次/秒。

**组合状态**：设备执行出厂恢复时，绿灯与红灯将同时快闪。

### 按键 A

- **长按 3 ~ 6 秒**：显示 AP 热点图标，松开后进入热点配网模式。
- **长按 6 秒以上**：返回主界面。

### 按键 B

- **长按 3 秒**：在 WiFi 模式与 AP 模式之间切换。

### 恢复出厂按键

长按 15 秒，设备恢复出厂设置。

### 复位按键

短按强制重启系统。

### HDMI 输入

- **规格**：标准 HDMI Type-A 接口，兼容 HDMI 1.4。
- **功能**：接收受控主机的 HDMI 视频信号，最高支持 1920x1200@60fps 输入。

### ATX 控制

- **规格**：USB Type-C 接口。
- **功能**：连接 ATX 控制器，远程控制目标设备的电源开关、强制重启与正常开关机。

### USB Data

- **规格**：USB Type-C 接口，USB 2.0 数据通信/OTG。
- **功能**：与目标主机建立键鼠控制和数据传输通道。

### USB 供电开关

- **规格**：拨动开关。
- **功能**：控制 USB Data 接口的电源输入。拨到 **ON** 时，允许通过 USB Data 接口为整机供电；拨到 **OFF** 时，关闭该接口的电源输入。

### TF 卡槽

- **规格**：Micro SD（TF）卡槽。
- **功能**：支持最高 512GB 存储卡，用于虚拟 U 盘挂载 ISO 镜像及本地存储扩展。


### 拓展接口

- **规格**：5pin 2.54mm 排针。
- **功能**：提供 UART 串口通信与 GPIO 控制，引脚旁印有对应字母标识。

> **注意**：接口电平为 3.3V，请勿连接 5V 电平信号，否则可能损坏设备。

#### UART 接口

| 外壳标注 | 详细名称 | 功能介绍 |
|---------|---------|---------|
| T       | TXD     | 数据发送端 |
| R       | RXD     | 数据接收端 |
| G       | GND     | 信号地线 |

接线时请将 FlexKVM 的 TXD 连接至目标设备的 RXD，RXD 连接至目标设备的 TXD，GND 互连。

#### GPIO 接口

| 外壳标注 | 详细名称 | 功能介绍 |
|---------|---------|---------|
| A       | GPIOA   | 通用输入输出 |
| B       | GPIOB   | 通用输入输出 |

支持输入/输出模式切换。

### 显示屏

- **规格**：单色 OLED 显示屏，分辨率 128x64。
- **功能**：显示设备网络状态、IP 地址、AP 配网信息及当前工作模式。

### 电源供电接口

- **规格**：USB Type-C 接口。
- **功能**：5V/1A 及以上输入，为设备供电。

### 百兆网口

- **规格**：RJ-45 接口，10/100M 自适应以太网。
- **功能**：有线网络接入。

### WiFi 天线

- **规格**：SMA 内针接口，双频 2.4GHz / 5GHz。
- **功能**：连接外置 WiFi 天线，实现无线网络接入。
