# FlexKVM

## 👋 欢迎使用 FlexKVM

FlexKVM 是一款高效、灵活的 IP-KVM 解决方案，通过 HDMI+USB 实现完整的远程设备控制。支持 WiFi、以太网、Tailscale 多种连接方式，随时随地管理您的服务器。
