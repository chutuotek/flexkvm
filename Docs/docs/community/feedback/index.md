# 建议与反馈

感谢您帮助我们改进 FlexKVM！您的反馈对我们非常重要，可以帮助我们改进产品，提升用户体验。

## Bug反馈

Bug反馈是一个重要的环节，一个好的 Bug 反馈可以帮助我们快速定位问题，并及时修复。

当您通过邮箱反馈 Bug 时，请提供以下信息：

- **FlexKVM系统版本**: 可以通过web页面查看
- **操作系统版本**: 您的电脑操作系统版本
- **浏览器版本**: 您访问FlexKVM的浏览器版本
- **出现时间**: 问题大概是在什么时候发生的，整个方便开发者定位问题
- **出现频率**: 问题出现的频率：单次/偶尔/不能稳定复现/稳定复现
- **问题的详细描述**: 问题的详细描述，比如说在什么场景下触发的问题，问题出现的现象等
- **附件**: 问题的截图，程序的系统日志，网页日志等

例子：

```
FlexKVM版本：v0.1.2
操作系统版本：Windows 10 21H1
浏览器版本：Chrome 148.0.7778.178（正式版本） （64 位）
出现时间：2026年5月22日 10:20
出现频率：稳定复现
问题描述：虚拟键盘会出现按下无反应情况,重新刷新后恢复正常
附件：截图，程序的系统日志，网页日志
```

**系统日志提取**

文章: [系统日志](../../guide/maintenance/log.md)

当您反馈问题时，你可以根据上面的文章来提取系统日志，以便我们更好地了解问题。

> **提示**：提取系统日志时，请注意要提取问题发生时的日志，以便我们更好地定位问题。

提取的文件包括：

- 后端日志
- web日志

## 建议

无需提供太多信息，您可以发挥您的想象力，畅所欲言，不限于下面内容：

- 您希望FlexKVM支持哪些功能，比如说: 支持nfs远程挂载，支持更多分辨率等
- 您可以分享您在FlexKVM使用过程中遇到的问题及改进方法，比如说: 键盘的样式，悬浮键盘会遮挡部分内容，可以xxxx进行改进和优化
- 您可以分享您在其它平台使用类似产品时的体验，比如说: 您在其它平台使用类似产品时，觉得哪些功能很好用，哪些功能不好用
- 您还可以分享一下您理想中的ipkvm设备应该是怎么样的。

``您的建议可能会在后续的版本中实现，敬请期待！``
