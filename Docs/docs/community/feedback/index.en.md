# Feedback & Suggestions

Thank you for helping us improve FlexKVM! Your feedback helps us improve the product and user experience.

## Bug Reports

A good bug report helps us quickly locate and fix issues.

When reporting bugs via email, please provide the following information:

- **FlexKVM system version**: Log into FlexKVM Web interface, click the Settings icon → "About" to view
- **OS version**: Your computer's operating system version
- **Browser version**: The browser version you use to access FlexKVM
- **Time of occurrence**: When did the issue occur? This helps developers narrow it down
- **Frequency**: Once / Occasional / Intermittent / Always reproducible
- **Detailed description**: What scenario triggers the issue and what exactly happens
- **Attachments**: Screenshots, system logs, web logs, etc.

Example:

```
FlexKVM version: v0.1.2
OS version: Windows 10 21H1
Browser version: Chrome 148.0.7778.178 (Official Build) (64-bit)
Time of occurrence: 2026-05-22 10:20
Frequency: Always reproducible
Issue description: Virtual keyboard becomes unresponsive; refreshing the page restores normal behavior
Attachments: Screenshots, system logs, web logs
```

**Extracting System Logs**

See [System Logs](../../guide/maintenance/log.en.md)

When reporting issues, include system logs from the time the issue occurred so we can better diagnose the problem.

Files to include:

- Backend logs
- Web logs

## Suggestions

No need for extensive detail — feel free to share any ideas. This includes but is not limited to:

- Features you'd like FlexKVM to support, e.g., NFS remote mount, more resolutions
- User experience improvements, e.g., virtual keyboard styling, adding drag functionality to the floating keyboard that blocks content
- Experiences with similar products on other platforms — what features worked well, what didn't
- Your vision of an ideal IP-KVM device

`Your suggestions may be implemented in future releases — stay tuned!`

- Email
