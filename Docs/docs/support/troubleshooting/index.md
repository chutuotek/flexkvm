# 故障排查

> 遇到问题时先别急，按步骤排查往往能快速定位。如果以下方法都无法解决，请带上诊断信息[提交反馈](../faq/index.md#功能建议)，开发团队会协助处理。

遇到问题请先在顶部**搜索栏**输入症状关键词（如"连不上"、"画面卡"、"升级失败"等）快速定位相关内容。

---

## 无法访问设备

### 浏览器打不开 Web 页面

| 排查步骤 | 操作 |
|---------|------|
| 1. 确认 IP 地址 | 查看 OLED 上显示的 IP，确认在浏览器中输入的是 `https://IP` 格式 |
| 2. 检查网络连通 | 在控制端 `ping <设备IP>`，看是否通 |
| 3. 检查同一网络 | 确认控制端和设备在同一个局域网（连接同一个路由器） |
| 4. 尝试无痕模式 | 用浏览器的无痕/隐私模式打开，排除缓存或 HSTS 干扰 |
| 5. 检查设备状态 | OLED 是否正常显示？🔴 电源灯是否常亮？ |

> 如果以上都无效，可能是网络配置出了问题。长按**按键 A** 3~6 秒进入[配网模式](../../guide/network/provision.md)重新配置。

### 连接 WiFi 后无法获取 IP 地址

| 可能原因 | 解决方法 |
|---------|---------|
| DHCP 未响应 | 尝试使用[静态 IP](../../guide/network/wifi.md#ipv4-配置) |
| 信号太弱 | 靠近路由器或使用 5GHz 频段 |
| 路由器 MAC 过滤 | 确认路由器未开启 MAC 地址过滤 |
| 密码错误 | 重新输入密码，注意大小写和特殊字符 |

### Tailscale 远程连接不上

| 可能原因 | 解决方法 |
|---------|---------|
| 访问端未安装 Tailscale | 在需要访问的设备上也安装 Tailscale 并登录同一账号 |
| 设备未登录 Tailscale | 在设置→应用中心检查 Tailscale 登录状态 |
| Tailscale 服务未启用 | 确认 Tailscale 开关已打开 |

## 远程画面异常

### 画面黑屏或显示"未连接"

| 排查步骤 | 操作 |
|---------|------|
| 1. 检查 HDMI 线 | 确认 HDMI 线已插紧，被控主机端和 FlexKVM 端都检查 |
| 2. 检查被控主机 | 确认被控主机已开机，未处于休眠状态 |
| 3. 检查 🟢 状态灯 | 状态灯**常亮**表示 HDMI 正常连接，**慢闪**表示未连接 |
| 4. 尝试重新连接 | 在画面菜单中点击"重新连接" |
| 5. 尝试更换 EDID | 切换到固定分辨率 EDID，排除 EDID 协商问题 |

### 画面卡顿或延迟大

| 可能原因 | 解决方法 |
|---------|---------|
| 网络带宽不足 | 在画面菜单中**降低画质** |
| 使用 2.4GHz WiFi | 切换到 5GHz 频段或有线网络 |
| 视频流卡死 | 点击"重新连接" |
| GOP 值过大 | 在画面菜单中将 GOP 设为 1（默认值） |

### 画面花屏或显示异常

| 可能原因 | 解决方法 |
|---------|---------|
| EDID 不匹配 | 切换 EDID 配置试试 |
| 视频流异常 | 点击画面菜单中的"重新连接" |
| HDMI 线接触不良 | 重新插拔 HDMI 线两端 |

## 键鼠操作异常

### 键盘按键无效或错乱

| 可能原因 | 解决方法 |
|---------|---------|
| 被控系统类型未选对 | 在键盘设置中确认**被控系统**选择了 Windows/Linux/MacOS |
| 输入焦点不在远程画面 | 点击远程画面区域获取焦点 |
| 全屏模式下 ESC 被拦截 | 退出全屏再操作，或使用映射的 ESC 键（默认 Right Ctrl） |

### 鼠标操作异常

| 可能原因 | 解决方法 |
|---------|---------|
| 鼠标模式不对 | 在鼠标设置中切换**绝对/相对模式**试试 |
| 画面黑边区域无法操作 | 画面比例与窗口不一致时，黑边区域无法操作，可尝试全屏 |
| 鼠标灵敏度不适 | 在鼠标设置中调整灵敏度 |

### 远程输入延迟高

与画面卡顿原因相同。尝试降低画质、使用有线网络或 5GHz WiFi。

## 音频问题

### 麦克风没声音

1. 检查浏览器是否获得了麦克风权限（地址栏左侧的锁图标可查看）
2. 确认音频总开关和麦克风开关都已打开
3. 检查电脑的麦克风是否正常工作
4. 确认被控主机的录音设备已选择 **FlexKVM Audio**

### 扬声器没声音

1. 确认音频总开关和扬声器开关都已打开
2. 确认被控主机的播放设备已选择 **FlexKVM Audio**
3. 检查被控主机是否有音频输出

### 音频有杂音或延迟

这是网络传输的正常现象。尝试改善网络环境。

## ATX 电源控制问题

### 点击开机没反应

1. 检查杜邦线是否接牢、主板插针位置是否正确
2. 展开外设菜单看设备名是否显示 `atx`
3. 确认 ATX 控制器上的电源指示灯亮起

### 关机后马上又开机了

部分主板的 BIOS 中开启了"断电后自动开机"（Restore on AC Power Loss）。进入 BIOS 关闭此选项即可。

### ATX 控制器不识别

重新插拔 ATX 控制器的 USB Type-C 数据线，确认 OLED 上显示 ATX 图标。如果仍不识别，尝试将数据线换一个 USB 口。

## 存储问题

### TF 卡插上没反应

检查文件系统是否支持。FAT32 和 exFAT 兼容性最好。确认 TF 卡已插到位（听到咔嗒声）。

### 共享的光驱被控主机不识别

确认文件是 `.img` 或 `.iso` 格式。其他格式无法作为光驱共享。

### 上传到一半断了

刷新页面后重新上传。断点续传暂不支持。

### 系统安装到一半失败了

检查安装过程中是否开关过鼠标、键盘或音频功能，这些操作会导致虚拟光驱短暂断开。

## 升级问题

### 在线升级失败

| 可能原因 | 解决方法 |
|---------|---------|
| 网络不稳定 | 切换下载源（GitHub/Gitee），或改用离线升级 |
| 电源不稳定 | 升级过程中断电可能导致设备变砖，请使用独立电源适配器 |
| 固件校验失败 | 重新下载安装包后重试 |

### 离线升级失败

确认上传的固件文件完整且未损坏。如果升级过程中断电导致设备无法启动，请参考[线刷镜像](../../guide/maintenance/flash.md)恢复。

## 设备状态异常

### 🟢 状态灯异常

| 状态 | 含义 | 解决方法 |
|------|------|---------|
| 常灭 | 系统未正常启动 | 检查电源连接，尝试重启设备 |
| 慢闪 (1次/秒) | HDMI 未连接或主机休眠 | 检查 HDMI 线，唤醒被控主机 |
| 快闪 (4次/秒) | USB 未连接或主机关机 | 检查 USB 线，确认被控主机已开机 |
| 常亮 | 正常 | ✅ 无需处理 |

> 优先级：快闪 > 慢闪 > 常亮。USB 和 HDMI 都未连接时显示快闪。

### 🔴 警告灯异常

| 状态 | 含义 | 解决方法 |
|------|------|---------|
| 慢闪 (1次/秒) | 网络未连接或热点配网模式 | 配置网络后自动熄灭 |
| 快闪 (4次/秒) | 紧急事件（升级中、恢复出厂等） | 等待操作完成 |
| 常亮 | 系统严重错误 | 重启设备，若仍常亮请联系技术支持 |

---

## 重启能解决大部分问题

如果遇到不确定的异常，先试试重启 FlexKVM 设备：

- **软件重启**：Web 界面 → 设置 → 维护 → 重启设备
- **硬件复位**：短按设备上的**复位按键**

重启不会清除任何配置。如果重启后问题仍然存在，再按上述分类排查。
