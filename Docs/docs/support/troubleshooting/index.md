# 故障排查

> 按步骤排查通常能快速定位问题。如果以下方法都无法解决，请带上诊断信息[提交反馈](../../community/feedback/index.md)，开发团队会协助处理。

遇到问题请先在顶部**搜索栏**输入症状关键词（如"连不上"、"画面卡"、"升级失败"等）快速定位相关内容。

---

## 无法访问设备

### 浏览器打不开 Web 页面

| 排查步骤 | 操作 |
|---------|------|
| 1. 确认 IP 地址 | 查看 OLED 上显示的 IP，确认在浏览器中输入的是 `https://IP` 格式 |
| 2. 检查网络连通 | 在控制端 `ping <设备IP>`，看是否通 |
| 3. 检查同一网络 | 确认控制端和设备在同一个局域网（连接同一个路由器） |
| 4. 尝试无痕模式 | 用浏览器的无痕/隐私模式打开，排除缓存或 HSTS 干扰 |
| 5. 检查设备状态 | OLED 是否正常显示？🔴 电源灯是否常亮？ |

> 如果以上都无效，可能是网络配置出了问题。长按**按键 A** 1~3 秒进入[配网模式](../../guide/network/provision.md)重新配置。

### 连接 WiFi 后无法获取 IP 地址

| 可能原因 | 解决方法 |
|---------|---------|
| DHCP 未响应 | 尝试使用[静态 IP](../../guide/network/wifi.md#ipv4-配置) |
| 信号太弱 | 靠近路由器或使用 5GHz 频段 |
| 路由器 MAC 过滤 | 确认路由器未开启 MAC 地址过滤 |
| 密码错误 | 重新输入密码，注意大小写和特殊字符 |

### 有线网络拿不到 IP

| 排查步骤 | 操作 |
|---------|------|
| 1. 看网口灯 | 不亮 → 检查网线两端、换根网线 |
| 2. 看是否闪烁 | 亮但不闪 → 换路由器端口 |
| 3. 等 Loading | OLED 显示 `E Loading...` 超过 20 秒 → 确认路由器 DHCP 已开启、地址池未耗尽 |
| 4. 仍无 IP | 改用[配网模式](../../guide/network/provision.md)，或为设备配[静态 IP](../../guide/network/eth.md#网络配置) |

### 直连模式拿不到 IP

| 现象 | 可能原因 | 解决方法 |
|------|----------|---------|
| 电脑拿不到 IP | 网线没插好、电脑网口未设为 DHCP | 检查网线与电脑网络设置 |
| 拿到的不是 192.168.x.x | 电脑还连着其他网络 | 关掉电脑 WiFi，只保留有线 |
| 能 ping 通但页面打不开 | 浏览器缓存或代理 | 清缓存、关代理，用无痕窗口 |
| 改了网段号后连不上 | 电脑还拿着旧 IP | 电脑端禁用再启用以太网，或 `ipconfig /release && /renew` |
| 网段号保存不了 | 与 AP 热点网段冲突 | 换一个网段号（两者不能同为 `192.168.x.1`） |

> 完整配置与排查 → [直连模式](../../guide/network/eth-server.md)

### AP 热点搜不到或连不上

| 现象 | 可能原因 | 解决方法 |
|------|----------|---------|
| 搜不到热点 | WiFi 正开着（两者共用无线模块） | 先关 WiFi 再开热点，或用按键 B 切换 |
| 客户端连不上 | 密码错、SSID 含特殊字符 | 核对密码，简化 SSID |
| 连上后打不开管理页 | 客户端 IP 异常 | 确认客户端使用 DHCP（热点自动分配） |
| 速度慢 | WiFi 和热点同时开着 | 关掉 WiFi |
| 客户端数不够 | 最大连接数设得过低 | 在 AP 配置里调大 |

> 配置项与实测等待时间 → [AP 热点](../../guide/network/ap.md)

### mDNS 主机名打不开

| 排查步骤 | 操作 |
|---------|------|
| 1. 同一局域网 | 控制端与 FlexKVM 必须连同一路由器（或直连热点） |
| 2. Windows 支持 | 安装 Apple Bonjour 才能解析 `.local`（macOS/iOS/Linux/Android 原生支持） |
| 3. 代理干扰 | 关闭 VPN/代理，或把 `*.local` 设为直连 |
| 4. 跨网段 | `.local` 无法跨网段解析，改用 IP 或 Tailscale |

> 主机名查看与开关 → [mDNS 服务发现](../../guide/network/mdns.md)

### Tailscale 远程连接不上

| 可能原因 | 解决方法 |
|---------|---------|
| 控制端未安装 Tailscale | 在控制端上也安装 Tailscale 并登录同一账号 |
| 设备未登录 Tailscale | 在设置 → 应用检查 Tailscale 登录状态 |
| Tailscale 服务未启用 | 确认 Tailscale 开关已打开 |
| 开关灰色不可用 | Tailscale 未正确预装，联系技术支持 |
| 提示设备已注册 | 设备已在其他 Tailnet，先在管理后台移除旧设备 |

> 登录方式与连接信息 → [Tailscale](../../guide/vpn/tailscale.md)

## 远程画面异常

### 画面黑屏或显示"未连接"

| 排查步骤 | 操作 |
|---------|------|
| 1. 检查 HDMI 线 | 确认 HDMI 线已插紧，被控设备端和 FlexKVM 端都检查 |
| 2. 检查被控设备 | 确认被控设备已开机，未处于休眠状态 |
| 3. 检查 🟢 状态灯 | 状态灯**常亮**表示 HDMI 正常连接，**慢闪**表示未连接 |
| 4. 尝试重新连接 | 在画面菜单中点击"重新连接" |
| 5. 尝试更换 EDID | 切换到固定分辨率 EDID，排除 EDID 协商问题 |

> 看到"信号协商中…"是正常过渡（HDMI 刚插入或切换分辨率），稍候自动恢复；分辨率或刷新率不被支持时画面提示，需在主机上调低。完整说明 → [远程画面](../../guide/remote/screen.md)

### 画面卡顿或延迟大

| 可能原因 | 解决方法 |
|---------|---------|
| 网络带宽不足 | 在画面菜单中**降低画质** |
| 使用 2.4GHz WiFi | 切换到 5GHz 频段或有线网络 |
| 视频流卡死 | 点击"重新连接" |
| GOP 值过大 | 在画面菜单中将 GOP 设为 1（默认值） |

> 画质档位与带宽预估 → [远程画面](../../guide/remote/screen.md#画质)

### 画面花屏或显示异常

| 可能原因 | 解决方法 |
|---------|---------|
| EDID 不匹配 | 切换 EDID 配置试试 |
| 视频流异常 | 点击画面菜单中的"重新连接" |
| HDMI 线接触不良 | 重新插拔 HDMI 线两端 |

> 自定义 EDID 与 EDID 修改 → [远程画面](../../guide/remote/screen.md#edid-配置)

### 截图或录像异常

| 现象 | 可能原因 | 解决方法 |
|------|----------|---------|
| 截图失败 | 远程画面未连接 | 先确认画面正常出流，再点截图 |
| 录的视频没声音 | 开了静音录制 / 主机无音频输出 | 关掉静音录制，检查主机音频 |
| 录像文件播不了 | 编码兼容性 | 换 MKV（H.264）格式 |
| 录制卡顿、CPU 高 | 用了软件编码器 | 选标注（硬件）的编码器，或降低视频质量 |

> 完整参数与说明 → [截图](../../guide/remote/screenshot.md) · [录像](../../guide/remote/recording.md)

## 键鼠操作异常

### 键盘按键无效或错乱

| 可能原因 | 解决方法 |
|---------|---------|
| 被控系统类型未选对 | 在键盘设置中确认**被控系统**选择了 Windows/Linux/macOS |
| 输入焦点不在远程画面 | 点击远程画面区域获取焦点 |
| 全屏模式下 ESC 被拦截 | 退出全屏再操作，或使用映射的 ESC 键（默认右 Ctrl） |
| 粘贴文本没反应（内容含中文） | 粘贴只支持英文字符（字母、数字、符号），详见[键盘](../../guide/remote/keyboard.md#粘贴文本) |

> 快捷键、虚拟键盘、Esc 映射 → [键盘](../../guide/remote/keyboard.md)

### 鼠标操作异常

| 可能原因 | 解决方法 |
|---------|---------|
| 鼠标模式不对 | 在鼠标设置中切换**绝对/相对模式**试试 |
| 画面黑边区域无法操作 | 画面比例与窗口不一致时，黑边区域无法操作，可尝试全屏 |
| 鼠标灵敏度不适 | 在鼠标设置中调整灵敏度 |
| 相对模式下鼠标出不来 | 按 `Esc` 退出控制 |

> 模式差异、节流与灵敏度 → [鼠标](../../guide/remote/mouse.md)

### 远程输入延迟高

与画面卡顿原因相同。尝试降低画质、使用有线网络或 5GHz WiFi。

## 音频问题

### 麦克风没声音

1. 检查浏览器是否获得了麦克风权限（地址栏左侧的锁图标可查看）
2. 确认音频总开关和麦克风开关都已打开
3. 检查电脑的麦克风是否正常工作
4. 确认被控设备的录音设备已选择 **FlexKVM Audio**

### 扬声器没声音

1. 确认音频总开关和扬声器开关都已打开
2. 确认被控设备的播放设备已选择 **FlexKVM Audio**
3. 检查被控设备是否有音频输出

### 音频有杂音或延迟

这是网络传输的正常现象。尝试改善网络环境。

> 双向音频的开关与设备选择 → [音频](../../guide/remote/audio.md)

## ATX 电源控制问题

### 点击开机没反应

1. 打开**外设**菜单，确认面板里的开关已**启用**（未启用时设备名不显示 `atx`）
2. 检查杜邦线是否接牢、主板插针位置是否正确
3. 确认 ATX 控制器上的电源指示灯亮起

### 关机后马上又开机了

部分主板的 BIOS 中开启了"断电后自动开机"（Restore on AC Power Loss）。进入 BIOS 关闭此选项即可。

### ATX 控制器不识别

重新插拔 ATX 控制器的 USB Type-C 数据线，确认 OLED 上显示 ATX 图标。如果仍不识别，换一根带数据的 USB 线。

> 完整接线（控制器↔机箱面板↔主板）与启用步骤 → [ATX 电源控制](../../guide/peripherals/atx.md)

## 存储问题

### TF 卡插上没反应

检查文件系统是否支持。支持 FAT32 / exFAT / ext4，exFAT 兼容性最好；NTFS 卡请先转成 exFAT。确认 TF 卡已插到位（听到咔嗒声）。

### 共享的光驱被控设备不识别

确认文件是 `.img` 或 `.iso` 格式。其他格式无法作为光驱共享。

### 上传到一半断了

刷新页面后重新上传。断点续传暂不支持。

### 系统安装到一半失败了

检查安装过程中是否开关过鼠标、键盘或音频功能，这些操作会导致虚拟光驱短暂断开。

> 分区共享与单文件共享的操作顺序不同，装系统前先确认已按[存储管理](../../guide/peripherals/disk.md)的步骤挂载/共享。

### 上传无法取消或提示失败

取消和失败是两种结果，提示文案不同：取消是主动中止，失败会按原因提示。上传失败可刷新后重传（不支持断点续传）。

## 升级问题

### 在线升级失败

| 可能原因 | 解决方法 |
|---------|---------|
| 网络不稳定 | 切换下载源（默认 GitCode，也可选 Gitee/GitHub），或改用离线升级 |
| 电源不稳定 | 升级过程中断电可能导致设备变砖，请使用独立电源适配器 |
| 固件校验失败 | 重新下载安装包后重试 |

### 离线升级失败

确认上传的固件文件完整且未损坏。如果升级过程中断电导致设备无法启动，[线刷镜像](../../guide/maintenance/flash.md)页仍在编写中，请直接[提交反馈](../../community/feedback/index.md)并提供序列号。

> 升级前需输入密码确认（开了 2FA 还要验证码）。完整流程 → [在线升级](../../guide/maintenance/upgrade-online.md) · [离线升级](../../guide/maintenance/upgrade-offline.md)

### 应用更新失败

| 现象 | 可能原因 | 解决方法 |
|------|----------|---------|
| 检查更新失败 | 网络不通或下载源不可用 | 切换下载源后重试 |
| 下载失败 | 网络不稳 | 切换下载源后重新下载 |
| 校验失败 | 下载包损坏 | 重新下载 |
| 应用不兼容 | 固件版本过低 | 先在 设置 → 升级 里升级固件 |

> 应用更新只支持 Gitee / GitHub 两个源，不需要重启设备，失败自动回滚 → [应用更新](../../guide/maintenance/upgrade-app.md)

## 账号与登录问题

### 登录不上或密码错误

| 现象 | 可能原因 | 解决方法 |
|------|----------|---------|
| 用户名或密码错 | 大小写、多余空格 | 重新输入；确认没有首尾空格 |
| 2FA 验证码总是错 | 设备时间偏差过大 | 按提示校准设备时间；或改用 8 位备用码 |
| 提示"当前已有用户登录" | 已有会话在线 | 点确认抢占（原用户被踢下线）；30 秒不操作自动取消 |
| 提示"你已被踢出" | 被其他会话抢占 | 重新登录 |
| 忘记密码 | 无法找回 | 只能[恢复出厂设置](../../guide/maintenance/factory-reset.md)后重建账号 |

> 登录流程、2FA 与多端抢占 → [登录管理](../../guide/security/account/login.md)

## SSH 连接问题

| 现象 | 可能原因 | 解决方法 |
|------|----------|---------|
| `Connection refused` | SSH 服务未启用 | 到 设置 → 安全 → SSH 打开开关 |
| `Connection timed out` | IP 不对或网络不可达 | 核对 OLED 显示的 IP，先 ping 通 |
| `Permission denied` | 用户名或密码错 | 用与 Web 界面相同的账号密码，注意大小写 |
| 登录后立刻断开 | 已有其他 SSH 会话 | 关掉另一个会话或等待超时 |
| 输错密码被踢 | 失败超过 3 次 | 重新连接即可，计数会重置 |

> 可用命令、`reset` 的二次验证与终端快捷键 → [SSH 远程访问](../../guide/security/ssh.md)

## 串口与 GPIO 问题

| 现象 | 可能原因 | 解决方法 |
|------|----------|---------|
| 串口终端乱码 | 通信参数与被控设备不一致 | 核对波特率/数据位/校验位/停止位 |
| 串口连不上 | TXD/RXD 未交叉、未共地 | 设备 TXD 接被控 RXD、RXD 接 TXD、GND 互连 |
| 串口显示"被其他窗口占用" | 同一串口只能一个窗口使用 | 在占用它的窗口点断开释放 |
| GPIO 输出没电压 | 引脚未启用或仍在输入模式 | 先启用引脚，再切到输出模式 |
| GPIO 读到错误电平 | 未与被控设备共地 | 连接 GND 共地 |
| GPIO 接线后界面没变化 | 引脚处于禁用状态 | 打开该引脚开关后才会监听 |

> 接线与参数说明 → [UART 串口终端](../../guide/peripherals/uart.md) · [GPIO 引脚控制](../../guide/peripherals/gpio.md)

## HTTPS 证书问题

| 现象 | 可能原因 | 解决方法 |
|------|----------|---------|
| 保存提示不匹配 | 私钥和证书不是一对 | 确认私钥对应这个证书 |
| 保存后仍警告 | 还在用自签名证书 | 在证书模式下拉里手动切到 `custom` |
| 导入 CA 后仍告警 | 证书没装进受信任存储 | 导入系统/浏览器的"受信任的根证书颁发机构"并重启浏览器 |
| 用户子 CA 仍告警 | 客户端没信任部署者根 CA | 先在客户端信任部署者根 CA |
| 提示格式错误 | 不是 PEM 格式 | 用 OpenSSL 转成 PEM（`.pfx`、`.jks` 不能直接粘贴） |
| 上传旧证书失败 | 签名算法过弱或已过期 | 换用 SHA-256 及以上、且在有效期内的证书 |

> 三种证书模式与各平台导入方法 → [HTTPS 证书](../../guide/security/https.md)

## AI Agent 问题

### Agent 调用失败

| 现象 | 可能原因 | 解决方法 |
|------|----------|---------|
| 返回 401 | API Key 缺失、错误或已作废 | 到 设置 → Agent 重新生成并更新客户端配置 |
| 返回 403 | Agent 未启用，**或用了 `http://` 明文访问** | 确认 Agent 开关已打开；MCP 端点强制 HTTPS，改用 `https://` |
| 返回 429 | 认证失败次数过多被限速 | 等待约 1 分钟后重试，并检查 Key 是否正确 |
| Skill 装好但 AI 说没这个能力 | 目录位置不对或未重启客户端 | 确认技能目录含 `SKILL.md`，重启客户端；OpenClaw 用 `openclaw skills list` |
| MCP 配置后工具不出现 | 客户端未连上 | Claude Code 用 `claude mcp list` 查状态；DSH 检查 patch 文件与 `FlexKVM_TOKEN` 环境变量 |
| 连接报 TLS / 证书错误 | 自签名证书 | 在客户端机器导入并信任设备 CA 证书 |
| AI 操作没反应 | 单批次超时或超出限额 | 一批最多 32 个事件、总时长 60 秒；文本单次最多 512 字符 |

> 两种接入方式、API Key 管理与能力边界 → [AI Agent 控制](../../guide/remote/agent.md)

## 设备状态异常

### 🟢 状态灯异常

| 状态 | 含义 | 解决方法 |
|------|------|---------|
| 常灭 | 系统未正常启动 | 检查电源连接，尝试重启设备 |
| 慢闪（1 次/秒） | HDMI 未连接或被控设备休眠 | 检查 HDMI 线，唤醒被控设备 |
| 快闪（4 次/秒） | USB 未连接或被控设备关机 | 检查 USB 线，确认被控设备已开机 |
| 常亮 | 正常 | ✅ 无需处理 |

> 优先级：快闪 > 慢闪 > 常亮。USB 和 HDMI 都未连接时显示快闪。

### 🔴 警告灯异常

| 状态 | 含义 | 解决方法 |
|------|------|---------|
| 慢闪（1 次/秒） | 网络未连接或配网模式 | 配置网络后自动熄灭 |
| 快闪（4 次/秒） | 紧急事件（升级中、恢复出厂等） | 等待操作完成 |
| 常亮 | 系统严重错误 | 重启设备，若仍常亮请联系技术支持 |

## 重启能解决大部分问题

如果遇到不确定的异常，先试试重启 FlexKVM 设备：

- **软件重启**：Web 界面 → 设置 → 维护 → 重启设备
- **硬件复位**：短按设备上的**复位按键**

重启不会清除任何配置，日志也会保留。

> 但要**反馈 Bug 时**，请先导出日志再重启：Web 日志只存在浏览器内存里，刷新或关页面就没了。见[建议反馈](../../community/feedback/index.md)。

如果重启后问题仍然存在，再按上述分类排查。
