# 常见问题

## 产品对比

### FlexKVM 和 IPMI/iDRAC/iLO 有什么区别？

IPMI 等企业带外方案需要主板原生支持，价格昂贵、配置复杂。FlexKVM 是**外接式**方案，任何具备 HDMI 和 USB 接口的设备都能用，无需主板支持，即插即用，成本更低。

### 它和向日葵、TeamViewer 等远程软件有什么区别？

远程软件依赖操作系统运行。系统蓝屏、未启动、或无显卡驱动时远程软件无法工作。FlexKVM 在**硬件层面**捕获视频信号，不依赖目标系统的任何软件状态。

## 网络与连接

### 是否需要公网 IP？

不需要。FlexKVM 内置 Tailscale，设备能访问互联网即可建立安全连接。也支持通过 WiFi 6 热点直连，完全不需要互联网。

### WiFi 和有线网络可以同时使用吗？会冲突吗？

可以同时使用，两者互为备份。一条链路断开时另一条自动接管——拔了网线画面不黑、键鼠不断。建议将两者配置在不同网段，例如以太网用 `192.168.1.x`，WiFi 用 `192.168.2.x`。

### 如何查看 FlexKVM 的 IP 地址？

在设备的 OLED 屏幕上看。以太网 IP 显示为 `Exxx.xxx.xxx.xxx`，WiFi IP 显示为 `Wxxx.xxx.xxx.xxx`。详见 [OLED 屏幕](../../guide/interaction/oled.md)。

### 什么是配网模式？什么时候需要使用？

配网模式是 FlexKVM 启动的一个临时 WiFi 热点，用于首次配置网络或在网络配置错误导致无法访问时恢复连接。长按**按键 A** 3~6 秒即可进入。详见 [配网模式](../../guide/network/provision.md)。

### 连接 FlexKVM 热点时手机会断网吗？

会。手机连接 FlexKVM 热点期间会暂时断开互联网连接，配网完成后保存退出即可自动恢复。

## 远程画面与操作

### 支持哪些浏览器？

推荐使用 Chrome、Edge、Firefox 等现代浏览器访问 Web 界面。其他浏览器可能存在兼容性问题（如画面显示异常）。

### 远程画面卡顿或延迟怎么办？

尝试降低画质（画面菜单中调整），或点击"重新连接"。如果网络环境较差，建议使用 5GHz WiFi 或有线网络。详见 [远程画面](../../guide/display/screen.md)。

### 能在 BIOS/UEFI 界面操作吗？

可以。FlexKVM 在硬件层捕获 HDMI 信号，BIOS、蓝屏、安全模式都能看见并操作。需要在键盘设置中选择正确的**被控系统**类型，否则 BIOS 热键可能无效。

### 同时开启音频或虚拟光驱会导致 USB 断开？

开启或关闭音频、切换 USB 设备标识时，USB 会短暂断开并重新连接，被控主机上的鼠标、键盘和磁盘挂载会短暂失效后恢复。这是正常现象，系统安装过程中请勿操作音频开关。

## 电源与硬件

### 目标主机需要安装软件或驱动吗？

不需要。FlexKVM 对目标主机来说就是一个标准的 USB 键盘、鼠标和 U 盘，即插即用，兼容所有主流操作系统。

### FlexKVM 支持哪些操作系统？

FlexKVM 对被控设备**完全透明**——它模拟标准 USB 键盘鼠标和存储设备，兼容 Windows、Linux、macOS 等所有主流操作系统，无需安装任何软件或驱动。

### 包装内含电源适配器吗？

**不含**。包装内提供 USB Type-C 数据线，需要使用自备的 5V/1A（或以上）USB 电源适配器。建议使用独立电源适配器以获得最佳稳定性。

### 可以用被控设备的 USB 供电吗？有什么影响？

可以。将 USB 供电开关拨到 **I** 即可从被控设备取电。但被控设备关机后 FlexKVM 也会断电，无法远程开机。**需要远程开机功能时，必须使用独立电源适配器供电。**

### FlexKVM 支持 PoE 供电吗？

原生不支持。需要购买外接 PoE 供电模块（将 PoE 和网络进行隔离）实现。详见 [拓展配件](../../guide/product/extensibility.md)。

### ATX 控制器是必须的吗？没有能不能用？

不是必须的。没有 ATX 控制器时，FlexKVM 仍可正常查看远程画面和控制键鼠，只是无法远程开关机和重启被控设备。如果需要远程电源控制，参考 [ATX 电源控制](../../guide/peripherals/atx.md) 进行接线配置。

### 可以同时控制多台设备吗？

一台 FlexKVM 管理一台目标主机。管理多台设备时，每台主机配备一台 FlexKVM，通过同一 Tailscale 网络分别访问。

## 存储

### TF 卡支持哪些文件系统？

支持 FAT32、exFAT、ext4、NTFS。推荐使用 exFAT（无 4GB 单文件限制）。详见 [存储管理](../../guide/storage/disk.md)。

### 如何远程重装操作系统？

通过 FlexKVM 的虚拟光驱功能，将系统 ISO 镜像挂载为 USB 光驱，被控主机从光驱启动即可安装。详细步骤参考 [远程重装系统](../../guide/scenarios/reinstall-os.md)。

## 账号与安全

### 忘记了登录密码怎么办？

账户信息存储在设备本地，忘记密码后无法找回，需要通过恢复出厂设置重新创建。详见 [恢复出厂设置](../../guide/maintenance/factory-reset.md)。

### 如何开启两步验证（2FA）？

在 Web 界面的设置 → 账号 → 2FA 验证中，点击"生成 2FA"，用手机验证器应用（如 Google Authenticator）扫码绑定即可。详见 [账号安全](../../guide/security/account/account.md)。

### 什么是备用码？有什么用？

开启 2FA 时会生成 10 个 8 位备用码。每个备用码仅可使用一次，用于手机丢失或验证器无法使用时的紧急登录。建议保存在密码管理器或打印纸质备份。

### 为什么浏览器提示"不安全"？

FlexKVM 使用自签名 SSL 证书，浏览器无法验证其合法性，属于正常现象。通信仍然是加密的。点击"高级"→"继续访问"即可。如需去除警告，可上传 CA 签名的自定义证书，详见 [HTTPS 证书](../../guide/security/https.md)。

### 无法打开 `https://设备IP` 怎么办？

按以下顺序排查：

1. 确认控制端和 FlexKVM 连接的是**同一个路由器**
2. 确认输入的 IP 地址与 OLED 显示的完全一致（注意 `https://` 前缀）
3. 在控制端 `ping` 该 IP 地址，确认网络可达
4. 如使用热点配网，确认手机/电脑仍连接在 FlexKVM 热点上，未自动切换回其他 WiFi
5. 尝试使用浏览器的无痕/隐私模式打开
