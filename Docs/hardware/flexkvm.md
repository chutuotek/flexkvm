# FlexKVM

``介绍的时候需要注意，对于主芯片介绍这些需要进行包装，不要直接写芯片名字，对功能进行包装``

cpu: rv1106g3 - 256MB内存（编码器， SiP 封装，低功耗）

## 硬件功能介绍

- 双频wifi6（最大速度支持300Mbit/s）
- 5.4蓝牙功能（蓝牙配网，未来支持）
- 百兆以太网
- usb2.0 gadget（可用于设备的供电）
- atx接口，使用usb接口形态的串口通讯
- tf卡接口
- 0.77寸单色oled屏幕，单色分辨率128x64
- hdmi输入接口（最大支持1920x1200@60fps）
- led x 2(红灯和绿灯)
- 复位按键
- 恢复默认出厂按键
- 用户操作按键 x 2 （按键A和按键B）
- usb供电接口（5V/1A）
- gpio x 2 （3.3V）(未启用，未来支持)
- uart ttl接口（3.3V） （未启用，未来支持）
- 供电+调试接口，调试功能默认关闭，拆开外壳后，可以通过拨动开关添加usb串口调试

### 按键A

- 0 ~ 3秒：屏幕无变化（防误触防抖
- 3秒 到达：屏幕上的蓝牙图标消失，替换为一个硕大的 [AP图标]。此时进入“准备热点配网”状态，按键释放后进入“热点配网”状态
- 6秒 到达：如果你一直按着不松手，到了9秒，屏幕显示一个[home]图标，按键释放后返回“主界面”状态

### 按键B

长按3s，将wifi和ap模式进行切换，如果当前是wifi模式则显示ap图标，如果当前是ap模式则显示wifi图标，松手后切换成对应模式

## 配件

- atx控制器：接入电脑主板上的atx接口，用于控制电脑的开关机，复位以及获取电脑的电源和硬盘状态
- 磁吸底板：可以装配到FlexKVM的底部，用3颗M3.5x4的螺丝进行固定，磁吸使用的是4颗n53的磁铁，可以磁吸到电脑的底板，用于固定FlexKVM
- 机柜夹具：可以装配到FlexKVM的底部，用于固定FlexKVM到机柜上，使用3颗M3.5x4的螺丝进行固定

### 可拓展

- poe分离器，可以使用poe分离器将电和网线分离，转成5V和网线

## 软件

### 用户

当前仅支持一名用户

### 网页

网页访问仅支持https协议进行通讯，使用的是自签证的证书，所以浏览器会提示不安全，但是可以正常使用，用户可以上传自己的证书，添加证书切换功能

网页共有3个页面

- 登录界面
- 主界面
- ap配网界面

进入其他页面前，需要先登录，登录成功后会返回JWT Token，用于后续的通讯

#### 登录界面

登录前会访问设备状态：

- 如果设备的用户没有初始化，登录界面就会切换成管理员创建页面，需要创建管理员用户，创建成功后，会自动跳转到主界面
- 如果设备的用户已经初始化，登录界面就会切换成登录页面，输入用户名和密码，如果用户开启了2FA功能则需要输入2FA码，登录成功后，会自动跳转到主界面

用户名: 只能是字母,数字，'_','-','.',4-32位
密码：8-32位,可打印字符，无空格，禁止字符
2FA码: 6位数字，刮刮卡8位数字，刮刮卡为一次性的，用完就失效
