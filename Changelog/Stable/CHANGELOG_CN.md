# CHANGELOG

- 语言: zh-CN
- 作者: ZEROK

## v0.1.4 (2026-07-28)

### 新增

- OLED 主界面短按按键 A 循环查看 ETH、WiFi、AP、HDMI、系统信息共 6 个子页面，短按按键 B 随时返回
- OLED 新增 DHCP 和静态 IP 反色区分显示
- OLED 系统信息子页面可查看产品名称、主机名和序列号
- OLED HDMI 子页面可查看分辨率、帧率、画质和链路状态
- Web 端静态 IP 配置表单自动填入当前配置

### 优化

- 按键 A/B 长按响应更快，1 秒即可触发
- 修改 AP 热点配置后自动生效，无需手动重启
- OLED 息屏后自动复位子页面，唤醒即回主界面
- OLED 页面图标和网络状态提示更清晰统一

### 修复

- 修复 AP 热点配置修改后未立即生效的问题
- 修复部分场景下 WiFi 连接失败后配置残留的问题

## v0.1.3 (2026-07-25)

### 新增功能

- 新增以太网直连模式（DHCP Server），支持电脑直连设备上网
  - 前端新增直连模式配置界面
  - OLED 主页支持直连状态图标显示
  - 物理 B 键支持三阶段长按切换网络模式

### 问题修复

- 修复 HDMI 视频采集在多种场景下的稳定性问题
  - 冷启动时视频信号检测更可靠，不再需要重新插拔 HDMI 线
  - 分辨率切换（如 BIOS 到桌面）时画面不再卡住或花屏
  - GPU 重置期间信号恢复更快，减少黑屏等待时间
  - 热插拔检测响应更及时，插拔显示器后画面更快恢复
- 修复 HDMI 驱动内存安全问题，提升长时间运行稳定性
- 修复 HDMI 驱动安全漏洞（CVE-2024-35830）
- 修复 HDMI 分辨率变化时可能导致视频异常的问题
- 修复 LED 告警灯与系统灯共享相位导致闪烁卡死的问题
- 修复 ATX HDD LED 状态无法上报到前端的问题
- 修复 OTA 升级时 changelog 频道选择和 URL 格式问题

### 改进

- 重构 dnsmasq 为 PID 管理，网络服务控制更可靠
- 更新文档
