# CHANGELOG

## v0.2.0 (2026-10-15)

### 新增

- AI Agent 远程控制：设置 → Agent 生成 API Key 后，AI 客户端可通过 Skill（flexkvm-skill）与 MCP 两种方式控制键鼠、截屏，支持 OpenClaw / Claude Code / Codex / DSH 等；与网页用户并发操作键鼠时自动串行处理
- Agent 操作日志：设置 → Agent 可查看并下载 AI 客户端的远程操作记录，凭据校验失败也会记入审计
- WireGuard VPN：设置 → 应用 → WireGuard 生成密钥、配置接口与对端、导出配置，实时查看连接状态
- ZeroTier 与 frp 内网穿透：设置 → 应用 新增对应配置面板
- 视频编码器可切换 H.264 / H.265（H.265 同画质约省 30% 码率，需浏览器支持）
- 系统状态监控：设置 → 状态 实时查看温度、CPU、内存、网络速率与运行时长，支持按日期查看历史曲线并导出 CSV
- 录像新增 MKV 容器（与 WebM 并存），画质新增自动档位，编码器按浏览器能力自动标注（硬件）/（软件）
- TF 卡支持 NTFS 分区挂载，可直接读写 NTFS 卡；设置 → 存储 可对 FAT32 / exFAT / ext4 分区做体检与修复
- EDID 修改：可覆盖显示器制造商、显示器名称、序列号字符串与产品代码，支持一键清除，无需上传完整 EDID；自定义 EDID 支持删除
- 画面菜单新增“拔出显示器 / 插入显示器”，可模拟显示器断开让主机重新识别
- 全屏双模式：工具栏全屏（`F11`）与画面全屏（`Ctrl+F11`）
- 信号超范围时独立提示，并给出可操作建议
- 串口终端支持在独立标签页打开（`/terminal`），断开时提示具体原因，瞬时断开自动重连
- HTTPS 证书体系升级：自签名模式自动生成 CA+叶子证书，支持下载 CA 证书导入浏览器信任，支持导入部署者签发的用户子 CA
- 文件上传与下载均支持取消，失败时按原因分类提示
- 鼠标移动节流：默认开启（125Hz），频率 10~500Hz 可调
- USB 键鼠内置 Logitech 预设身份（K120 键盘 / M100 鼠标），常见系统免驱兼容性更好
- 键鼠通道掉线时在菜单栏提示，可查看状态并自动恢复
- 画质、编码器、GOP、EDID 等画面设置收紧为仅管理员可改，非管理员对应控件置灰
- mDNS 服务发现：局域网内用 `flexkvm-xxxx.local` 主机名访问 Web 与 SSH（设置 → 网络 → mDNS 可开关）
- 应用更新：设置 → 应用 在线检查、下载并安装应用更新（如 Tailscale），下载源为 GitHub / Gitee，默认 Gitee；支持卸载，失败自动回滚，并校验固件门槛
- PWA 离线支持：断网时仍可打开已缓存的界面
- WiFi 支持 OWE 加密
- 以太网/WiFi 详情面板显示 MTU
- 登录会话自动续期，长时间不再频繁要求重新登录
- 固件版本变化后页面自动刷新
- 重启设备时 OLED 显示重启页面
- SSH 新增 mDNS 管理命令（`mdns status|enable|disable`）

### 优化

- HDMI 插拔与信号变化检测更及时，新增“信号协商中”状态，连接状态显示更准
- 远程画面连接与重连更快，按浏览器能力协商最佳编码参数，弱网提示更及时；主通道长时间静默时自动探测重连
- USB 键鼠断连后自动恢复更可靠
- Tailscale 状态显示 DNS 名称，面板刷新更及时，连接信息收进详情弹窗
- 审计日志更精准：剔除 HDMI/WebRTC 等高频记录，补齐 WiFi/AP 启停审计
- 鼠标灵敏度、滚动速率等偏好持久化保存，刷新页面不丢失
- 以太网直连网段与 AP 热点网段相同时拒绝启用，避免网络不可达
- 网络唤醒（WoL）目标地址自适应所在子网广播，唤醒成功率更高
- 固件在线升级保留 GitHub / Gitee / GitCode 三个下载源，默认源改为 GitCode
- 界面细节：内存占用改按百分比显示、设置下拉按内容自适应宽度、网络异常自动恢复更稳、首屏加载更快
- 设置页重组：新增「状态」「Agent」「采集」「安全」四个页签，截图/录像归入「采集」，HTTPS/SSH 归入「安全」，mDNS 移入网络页
- 设置页地址可直接分享或收藏，刷新、前进后退不丢当前页签；访问不存在的路径显示中文 404 页
- 切换设置页时远程画面与键鼠连接不中断

### 移除

- 设备不再内置离线文档（原 `/docs/`），文档统一在在线文档站查阅；关于页、登录页与配网页的文档入口相应指向在线站
- 关于页不再显示型号，改显产品名称与主机名

### 修复

- 修复首次插入 HDMI 黑屏、分辨率切换后黑屏、断流恢复后黑屏等画面问题
- 修复刷新页面后旧视频连接残留导致新连接无画面
- 修复视频链路卡死时界面仍显示“已连接”、无法反映真实状态的问题
- 修复自定义 EDID 数据损坏时设备反复重启、无法启动的问题
- 修复开机自启阶段 USB 键鼠与存储可能整体挂死的问题
- 修复强制登录（抢占）后设备可能停止响应的问题
- 修复多次登录触发限速后账户被误锁的问题
- 修复 WiFi 扫描可能永久卡在“扫描中”的问题
- 修复部分 WiFi 网络无法连接的问题
- 修复静态 IP 掩码不合法时配置写坏、重启后回退 DHCP 的问题
- 修复网络设置失败时仍提示“已保存”的问题
- 修复 TF 卡挂载状态与实际不一致、界面卡在“已挂载”的问题
- 修复 TF 传输状态悬挂、下载状态显示异常，以及删除文件误报失败、列表不刷新
- 修复上传文件时取消失效、失败重复报错的问题
- 修复串口设备读取错误时连接静默失效的问题
- 修复断开连接后麦克风采集未停止、指示灯常亮的问题
- 修复网页录制启动失败后无法再次录制的问题
- 修复 iOS 全屏异常与长按放大镜干扰
- 修复英文界面下快捷键编辑器部分标签仍显示中文的问题
- 修复网络唤醒设备上限被写死为 5 台、增删失败时无任何提示的问题
- 修复 USB 键鼠在部分主机上识别异常、光标乱跳的问题
- 修复恢复出厂设置清理失败时仍按成功处理并重启的问题
- 多项安全加固：改密后旧会话立即失效、TLS 1.2 限用 AEAD 套件、证书私钥权限收紧、下载路径校验、CSRF 存储隔离等

## v0.1.5 (2026-08-08)

### 新增

- OLED 主界面新增 ETH/WiFi IPv6 信息子页面，共 7 个子页面循环查看
- OLED 信息子页面顺序调整：HDMI、系统信息前置（第 2/3 页），网络详情后置
- 触控屏手势支持：单指点击/双击、长按右键、双指滑动滚轮、长按拖拽
- Tailscale 支持 Authkey 接入与 headscale 自建服务器登录
- 多端登录抢占提示与被踢提示
- 以太网/WiFi 详情面板新增 IPv6 地址显示
- 登出后其他已登录设备立即失效
- TF 菜单图标随文件上传/下载实时切换状态
- 最多可配置 5 个ntp 时间源
- 配网模式或者登录成功，控制端时间和FlexKVM时间相差60s，会询问是否同步时间

### 优化

- 提升 Firefox 等浏览器下远程画面的兼容性与画质
- 断网或设备重启后自动重连恢复
- 配网模式访问改用 HTTP，免自签名证书警告
- 配网热点密码改为 8 位数字，输入更方便

### 修复

- 2FA 生成后 10 分钟内需完成绑定，超时需重新生成
- 修复多项稳定性和安全问题
- ETH在web端一直显示已连接

## v0.1.4 (2026-07-28)

### 新增

- OLED 主界面短按按键 A 循环查看 ETH、WiFi、AP、HDMI、系统信息共 6 个子页面，短按按键 B 随时返回
- OLED 新增 DHCP 和静态 IP 反色区分显示
- OLED 系统信息子页面可查看产品名称、主机名和序列号
- OLED HDMI 子页面可查看分辨率、帧率、画质和链路状态
- Web 端静态 IP 配置表单自动填入当前配置

### 优化

- 按键 A/B 长按响应更快，1 秒即可触发
- 修改 AP 热点配置后自动生效，无需手动重启
- OLED 息屏后自动复位子页面，唤醒即回主界面
- OLED 页面图标和网络状态提示更清晰统一

### 修复

- 修复 AP 热点配置修改后未立即生效的问题
- 修复部分场景下 WiFi 连接失败后配置残留的问题

## v0.1.3 (2026-07-25)

### 新增功能

- 新增以太网直连模式（DHCP Server），支持电脑直连设备上网
  - 前端新增直连模式配置界面
  - OLED 主页支持直连状态图标显示
  - 物理 B 键支持三阶段长按切换网络模式

### 问题修复

- 修复 HDMI 视频采集在多种场景下的稳定性问题
  - 冷启动时视频信号检测更可靠，不再需要重新插拔 HDMI 线
  - 分辨率切换（如 BIOS 到桌面）时画面不再卡住或花屏
  - GPU 重置期间信号恢复更快，减少黑屏等待时间
  - 热插拔检测响应更及时，插拔显示器后画面更快恢复
- 修复 HDMI 驱动内存安全问题，提升长时间运行稳定性
- 修复 HDMI 驱动安全漏洞（CVE-2024-35830）
- 修复 HDMI 分辨率变化时可能导致视频异常的问题
- 修复 LED 告警灯与系统灯共享相位导致闪烁卡死的问题
- 修复 ATX HDD LED 状态无法上报到前端的问题
- 修复 OTA 升级时 changelog 频道选择和 URL 格式问题

### 改进

- 重构 dnsmasq 为 PID 管理，网络服务控制更可靠
- 更新文档
