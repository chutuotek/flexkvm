# CHANGELOG

- 语言: zh-CN
- 作者: chutuotek

## v0.1.6-Beta (2026-09-09)

### 新增

- AI Agent 远程控制：设置 → Agent 生成 API Key 后，AI 客户端可通过 Skill（flexkvm-skill）与 MCP 两种方式控制键鼠、截屏，支持 OpenClaw / Claude Code / Codex / DSH 等，事件批次可中途取消
- 系统状态监控：设置 → 状态 实时查看温度、CPU、内存、网络速率与运行时长，支持按日期查看历史曲线并导出 CSV
- 录制改用 WebCodecs：新增 MKV 容器（与 WebM 并存），视频编码器按浏览器能力自动检测并标注（硬件）/（软件）
- EDID 修改：可覆盖显示器制造商、显示器名称、序列号字符串与产品代码，无需上传完整 EDID
- 画面菜单新增"拔出显示器 / 插入显示器"，可模拟显示器断开让主机重新识别
- 自定义 EDID 支持删除
- 全屏双模式：工具栏全屏（`F11`）与画面全屏（`Ctrl+F11`），可随时切换
- 串口终端支持在独立标签页打开（`/terminal`），断开时提示具体原因，瞬时断开自动重连
- HTTPS 证书体系升级：自签名模式自动生成 CA+叶子证书，支持下载 CA 证书导入浏览器信任，支持导入部署者签发的用户子 CA
- 文件上传支持取消，失败时按原因分类提示
- 鼠标移动节流：默认开启（125Hz），频率 10~500Hz 可调，降低高回报率鼠标下的负载
- 以太网/WiFi 详情面板显示 MTU
- mDNS 服务发现：局域网内用 `flexkvm-xxxx.local` 主机名访问 Web 与 SSH，无需记忆 IP（设置 → 网络 → mDNS 可开关）
- 应用更新：设置 → 应用 → 应用更新可在线检查、下载并安装应用更新（如 Tailscale），失败自动回滚
- PWA 离线支持：断网时仍可打开已缓存的界面
- 登录会话自动续期，长时间不再频繁要求重新登录
- 固件版本变化后页面自动刷新
- SSH 新增 mDNS 管理命令（`mdns status|enable|disable`）

### 改进

- HDMI 热插拔改为事件驱动检测，新增"信号协商中"状态，主动拔出与链路抖动去抖，连接状态更准
- WebRTC 协商改为浏览器主导，按浏览器能力精确协商 H264 参数，响应关键帧请求，弱网提示更及时
- HDMI 重连保留已协商的 H264 profile，重连更快
- USB 键鼠故障自愈升级为三级恢复状态机
- USB 键鼠内置 Logitech 预设身份（K120 键盘 / M100 鼠标），常见系统免驱兼容性更好
- Tailscale 状态显示 DNS 名称（DNSName）
- 审计日志更精准：剔除 HDMI/WebRTC 等高频记录，补齐 WiFi/AP 启停审计
- 鼠标灵敏度、滚动速率等偏好持久化保存，刷新页面不丢失
- 以太网直连网段与 AP 热点网段相同时拒绝启用，避免网络不可达
- AI Agent 与网页用户并发操作键鼠时串行化处理，避免指令交叉
- 应用更新：新增兼容升级路径与固件门槛校验，被固件拦截的新版本会明确提示
- 重启设备时 OLED 显示重启页面
- 界面细节：内存占用改按百分比显示、设置下拉按内容自适应宽度、网络异常自动恢复更稳

### 修复

- 修复首次插入 HDMI 黑屏、分辨率切换后黑屏、断流恢复后黑屏等画面问题
- 修复刷新页面后旧视频连接残留导致新连接无画面
- 修复 TF 传输状态悬挂与下载状态显示问题
- 修复 iOS 全屏异常与长按放大镜干扰
- 修复串口关停时的内存安全问题
- 多项安全加固：TLS 1.2 限用 AEAD 套件、证书私钥权限收紧、下载路径校验、CSRF 存储隔离等
