# 文档写作规范

适用于 FlexKVM 所有中文技术文档。

## 禁止项

- **禁止使用"上图"、"下图"、"如上图所示"** — 改用描述性语句说明图片内容，或直接用标题+图片的结构
- **禁止使用"可以看到"** — 直接陈述事实
- **禁止使用"这个是一个"、"这个是"** — 删除冗余主语
- **禁止使用"会"做填充词** — "点击后会弹出" → "点击后弹出"
- **禁止口语化评价** — "稍微有点麻烦"、"挺方便的"等主观感受不应出现

## 表述原则

- **直接陈述，不铺垫** — "可以看到界面中有两个区块" → 直接说"界面包含两个区块"
- **操作步骤用祈使句** — "用户可以根据自己的需求选择" → "根据需求选择"
- **描述 UI 用名词，不用方位** — "上图的红色框框的位置" → "菜单栏中的屏幕按键"
- **功能说明用"功能 → 效果"结构** — 先说是什么，再说能干什么

## 示例

| 问题写法 | 修正写法 |
|---------|---------|
| 上图的红色框框的位置为屏幕按键，左边的图标为一个显示器的图标 | 菜单栏中的屏幕按键，图标为显示器样式 |
| 可以看到，屏幕菜单中包含了以下选项 | 屏幕菜单包含以下选项 |
| 这个是一个选择器用来切换 flexkvm 的 edid | EDID 选择器用于切换 EDID 配置 |
| 相对模式的话，控制会稍微有点麻烦 | 相对模式需要点击远程画面后才能控制 |
| 点击之后，会弹出一个模态框 | 点击后弹出模态框 |
| 如上图所示，左边的图标表示为显示连接成功 | （删除整句，图片下方自然承接） |
